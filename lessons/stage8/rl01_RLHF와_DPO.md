## 1. 개념 (8분)

### 1-1. 글을 잘 잇는 것과 말을 잘 듣는 것
사전학습한 모델은 **인터넷 글을 그럴듯하게 잇는** 법을 배웠습니다. "김치찌개 끓이는 법 알려 줘"라고 하면 요리법 대신 "라고 친구가 물었다. 나는…" 하고 이야기를 이어 갈 수도 있습니다. 틀린 것은 아니지만 우리가 원한 답은 아닙니다.

문제는 "좋은 답"을 식으로 쓰기 어렵다는 것입니다. 하지만 사람은 두 답을 나란히 보면 **어느 쪽이 나은지**는 쉽게 고릅니다. 이 **비교**를 학습에 쓰는 것이 오늘의 주제입니다.

### 1-2. RLHF의 세 걸음
RLHF는 "사람의 피드백으로 하는 강화학습"의 영어 줄임말입니다. 강화학습은 **점수(보상)를 많이 받는 쪽으로 행동을 고쳐 가는** 학습입니다. 강아지에게 간식을 주며 "앉아"를 가르치는 것과 같습니다.

1. **시범 보이기.** 사람이 쓴 모범 답안으로 [미세조정](#bg01)합니다
2. **채점기 만들기.** 모델의 답 두 개를 사람에게 보여 주고 더 나은 쪽을 고르게 합니다. 이 비교를 모아, 답에 점수를 매기는 신경망(**보상 모델**)을 학습시킵니다
3. **채점기로 다듬기.** 모델이 답을 쓰면 보상 모델이 점수를 줍니다. 점수가 높아지는 쪽으로 모델을 고칩니다. 사람이 매번 채점하지 않아도 됩니다

요리 학원으로 치면 1은 선생님 따라 하기, 2는 맛을 볼 줄 아는 심사위원 키우기, 3은 심사위원 점수를 보며 혼자 연습하기입니다.

### 1-3. 채점기는 비교에서 어떻게 배울까
보상 모델이 답 A에 점수 $r_A$, 답 B에 $r_B$를 줬다고 합시다. "A가 더 낫다"고 볼 확률을 점수 **차이**로 정합니다.

$$P(A \text{가 낫다}) = \sigma(r_A - r_B)$$

σ(시그마)는 **시그모이드**, 어떤 수든 0과 1 사이로 눌러 주는 함수입니다 ([LSTM 게이트](#day11)에서 수도꼭지로 썼습니다). 오늘 쓸 값은 네 개뿐입니다.

| 차이 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|
| σ(차이) | 0.27 | 0.5 | 0.73 | 0.88 |

사람이 정말 A를 골랐다면 손실은 $-\ln P(A\text{가 낫다})$. [크로스엔트로피](#day07)입니다. 점수 차이가 사람의 선택과 같은 방향으로 벌어질수록 손실이 줄어듭니다.

### 1-4. 고삐: 너무 멀리 가지 않게
3번 걸음에서 점수만 쫓으면 모델이 채점기의 허점을 파고들어 이상한 답을 낼 수 있습니다. 그래서 "원래 모델에서 너무 멀어지면 벌점"([KL 발산](#day07))을 붙입니다. 강아지 목줄처럼, 마음껏 움직이되 너무 멀리 가지는 못하게 하는 것입니다. (InstructGPT가 쓴 강화학습 방법의 이름은 PPO입니다. 이름만 알아 두세요.)

결과: 파라미터 13억 개짜리 InstructGPT의 답을, 사람들은 1750억 개짜리 GPT-3의 답보다 더 좋아했습니다. **100배 넘게 작은 모델이 "말을 듣는 법"을 배워 이긴 것**입니다.

### 1-5. DPO: 채점기 없이 바로
RLHF는 모델이 둘(채점기와 본 모델)이고 강화학습은 다루기 까다롭습니다. 2023년의 **DPO**는 "채점기를 따로 만들지 말고, 비교 데이터로 **모델을 바로** 고치자"고 했습니다.

생각은 이렇습니다. 모델이 어떤 답에 주는 [로그 확률](#day05)이 원래 모델보다 얼마나 **올랐는지**를 그 답의 점수로 칩니다.

$$\text{점수}(y) = \ln \pi(y) - \ln \pi_{\text{원래}}(y)$$

π(파이)는 여기서 원주율이 아니라 "모델이 그 답을 쓸 확률"의 이름표입니다. 점수가 0이면 원래 모델과 똑같다는 뜻입니다. 점수가 0보다 크면 그 답을 전보다 더 자주 쓰게 됐다는 뜻입니다. 0보다 작으면 덜 쓰게 됐다는 뜻입니다. 시험 점수 자체가 아니라 "지난 시험보다 몇 점 올랐나"를 보는 것과 같습니다. 이제 1-3의 식에서 채점기 점수 $r_A$, $r_B$ 자리에 이 점수를 넣습니다. 식의 모양은 똑같습니다.

$$\text{손실} = -\ln \sigma\big(\beta \times (\text{점수}(\text{좋은 답}) - \text{점수}(\text{나쁜 답}))\big)$$

β(베타)는 세기를 정하는 수입니다. 좋은 답의 확률은 올리고 나쁜 답의 확률은 내릴수록 손실이 줄어듭니다. 강화학습 없이 **분류 문제처럼** 풀리고, "원래 모델에서 얼마나 달라졌는지"가 식에 들어 있어 고삐 역할도 합니다.

| | RLHF | DPO |
|---|---|---|
| 필요한 데이터 | 답 두 개의 비교 | 답 두 개의 비교 |
| 채점기(보상 모델) | 따로 학습 | **없음** |
| 학습 방법 | 강화학습 | 분류 손실 하나 |

## 2. 예제 따라하기 (6분)

쓸 값: −ln 0.88 ≈ 0.13, −ln 0.73 ≈ 0.31, −ln 0.5 ≈ 0.69, −ln 0.27 ≈ 1.31

**채점기 학습.** 사람이 A를 골랐습니다.

- 채점기가 $r_A$ = 3, $r_B$ = 1을 줬다면: 차이 2 → P = 0.88 → 손실 **0.13** (잘 맞힘)
- 채점기가 $r_A$ = 1, $r_B$ = 2를 줬다면: 차이 −1 → P = 0.27 → 손실 **1.31** (거꾸로 매김, 크게 혼남)

**DPO.** β = 1. 학습 전에는 모델이 원래 모델과 같으므로 두 점수 모두 0.

- 학습 전: 차이 0 → σ(0) = 0.5 → 손실 **0.69**
- 조금 학습해서 좋은 답의 로그 확률이 0.5 오르고 나쁜 답은 0.5 내렸다면: 점수 0.5와 −0.5, 차이 1 → 0.73 → 손실 **0.31**

손실이 0.69에서 0.31로 줄었습니다.

## 3. 능동 연습 (10분)

쓸 값: σ(−1) = 0.27, σ(0) = 0.5, σ(1) = 0.73, σ(2) = 0.88 / −ln 0.88 ≈ 0.13, −ln 0.73 ≈ 0.31, −ln 0.5 ≈ 0.69, −ln 0.27 ≈ 1.31

### ✏️ 손계산
1. 채점기 점수가 $r_A$ = 2, $r_B$ = 1입니다. "A가 낫다"고 볼 확률은?
2. 1번에서 사람이 A를 골랐다면 손실은? B를 골랐다면? (B가 낫다고 볼 확률은 1 − P)
3. 두 답의 점수가 똑같으면 A가 낫다고 볼 확률은?
4. DPO(β = 1)에서 좋은 답의 로그 확률이 원래보다 1.5 오르고, 나쁜 답은 0.5 내렸습니다. 점수 차이와 손실은?
5. DPO에서 좋은 답의 확률이 오히려 내려가 점수가 −0.5, 나쁜 답의 점수가 0.5가 됐습니다. 손실은? 학습 전(0.69)보다 큰가요?
6. RLHF의 세 걸음을 순서대로 쓰세요.

### 🧩 미니 챌린지
사람에게 답 하나를 보여 주고 "10점 만점에 몇 점?"이라고 묻지 않고, 답 두 개를 보여 주고 "어느 쪽이 나아요?"라고 묻는 이유는 무엇일까요? 맛집 별점을 떠올려 보세요.

### 💻 코드 (선택)
```python
import numpy as np
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

for diff in [-1, 0, 1, 2]:
    p = sigmoid(diff)
    print(diff, p.round(2), (-np.log(p)).round(2))
# -1 0.27 1.31
# 0 0.5 0.69
# 1 0.73 0.31
# 2 0.88 0.13

def dpo_loss(up_good, up_bad, beta=1.0):     # 로그 확률이 원래 모델보다 얼마나 올랐는지
    return -np.log(sigmoid(beta * (up_good - up_bad)))
print(dpo_loss(0, 0).round(2), dpo_loss(0.5, -0.5).round(2))   # 0.69 0.31
```
