## 1. 개념 (8분)

### 1-1. 모델은 얼마나 무거울까
[MoE](#moe01)는 "커다란 모델의 일부만 쓰기"였습니다. 오늘은 모델 자체를 **작게 만드는** 방법입니다.

모델의 무게는 이렇게 셉니다.

$$\text{메모리} = \text{파라미터 수} \times \text{숫자 하나의 바이트 수}$$

1바이트는 8비트입니다. 비트는 0 또는 1을 담는 칸 하나입니다.

| 숫자 하나 | 32비트 | 16비트 | 8비트 | 4비트 |
|---|---|---|---|---|
| 바이트 | 4 | 2 | 1 | 0.5 |
| 70억(7B) 모델 | 28GB | **14GB** | 7GB | **3.5GB** |

70억 × 2바이트 = 140억 바이트 = **14GB**입니다. 여기서 GB는 10⁹바이트 기준이고([큰 수 읽기](#prep03)), 컴퓨터가 쓰는 GiB(2³⁰바이트)로 세면 약 13입니다. 또 이것은 **가중치만** 센 값입니다. 실제로 돌릴 때는 계산 중간값을 담을 메모리가 더 필요합니다.

16비트 그대로면 보통 노트북(16GB)에 빠듯하지만, 4비트면 3.5GB라 휴대폰에도 들어갈 수 있습니다.

### 1-2. 양자화: 저울 눈금 바꾸기
**양자화**는 숫자를 더 적은 비트로 줄여 저장하는 것입니다. 0.001g까지 재는 저울 대신 1g 눈금 저울을 쓰는 것과 같습니다. 가볍고 빠르지만 아주 작은 차이는 못 잽니다.

8비트 정수는 −127부터 127까지를 담는다고 칩시다(실제로는 −128도 되지만 양쪽을 똑같이 맞춰 씁니다). 방법은 세 단계입니다.

1. **눈금 정하기.** 가장 큰 절댓값을 127칸에 맞춥니다: 눈금 $s$ = (가장 큰 절댓값) ÷ 127
2. **정수로 저장.** 값 ÷ $s$를 반올림합니다
3. **쓸 때 되돌리기.** 정수 × $s$

$s$는 오늘 새로 쓰는 기호이고, 눈금(scale) 한 칸의 크기입니다. 9단계 강화학습의 상태 s와는 글자만 같습니다. 파라미터 **개수는 그대로**이고, 숫자 하나가 차지하는 칸만 줄어든다는 점에 주의하세요.

### 1-3. 반올림 오차
눈금 사이에 떨어진 값은 가까운 눈금으로 옮겨집니다. 이 차이가 **반올림 오차**입니다. 눈금이 0.01이면 0.004는 0.4칸 → 반올림해 **0**이 됩니다. 작은 값이 사라지는 것이죠.

신경망은 가중치 하나하나가 조금씩 틀려도 전체 결과는 크게 변하지 않는 경우가 많습니다. 그래서 8비트, 심지어 4비트까지 줄여도 쓸 만합니다.

> **(선택) 이상치 문제.** 값 중 하나가 유난히 크면 어떨까요? [0.50, −1.27, 0.02, 12.7]이면 눈금이 12.7 ÷ 127 = 0.1로 커져서, 0.02는 0.2칸 → **0**이 됩니다. 큰 언어 모델에는 이런 튀는 값(이상치)이 실제로 생깁니다. Dettmers 외(2022)의 LLM.int8()은 튀는 부분만 16비트로 따로 계산하고 나머지 대부분은 8비트로 계산해 이 문제를 피했습니다.

### 1-4. 지식 증류: 해설 노트로 가르치기
두 번째 방법은 **작은 모델을 새로 학습**시키는 것입니다. 큰 모델(선생)의 답을 작은 모델(학생)이 따라 하게 합니다. 이것이 **지식 증류**입니다.

고양이 사진의 정답은 원-핫 [고양이 1, 개 0, 자동차 0]입니다. 그런데 잘 배운 선생은 [0.87, 0.12, 0.02] 같은 확률을 냅니다. 여기에는 정답에 없는 정보가 있습니다. "이 사진은 개와는 **조금** 닮았고, 자동차와는 **전혀** 안 닮았다." Hinton은 강연에서 이런 정보를 **dark knowledge**(숨은 지식)라고 불렀습니다(2015년 논문 본문에는 이 말이 없고, 논문은 "soft targets"라고 씁니다). 과외 선생님의 해설 노트가 정답만이 아니라 "이 보기도 꽤 그럴듯했지?"까지 알려 주는 것과 같습니다.

### 1-5. 온도로 숨은 지식 드러내기
선생의 확률이 0.87처럼 한쪽에 몰려 있으면 0.02 같은 작은 값은 잘 보이지 않습니다. 그래서 [온도](#smp01) T를 올립니다. 로짓을 T로 나눈 뒤 소프트맥스를 하면 확률이 고르게 퍼져 작은 값이 드러납니다. (smp01에서 본 그 온도입니다.)

학생은 같은 온도에서 자기 확률이 선생 확률과 비슷해지도록 학습합니다. 두 분포가 얼마나 다른지는 [KL 발산](#day07)으로 잽니다. 똑같으면 0입니다. 보통은 진짜 정답에 대한 손실도 함께 더합니다.

결과: DistilBERT(Sanh 외 2019)는 BERT를 증류해 크기를 **40%** 줄이고, 언어 이해 성능의 **97%**를 지키며, **60%** 빨라졌습니다.

| | 양자화 | 지식 증류 |
|---|---|---|
| 바꾸는 것 | 숫자 하나의 비트 수 | 모델 자체 (더 작은 학생) |
| 파라미터 개수 | 그대로 | 줄어듦 |
| 새로 학습 | 대개 필요 없음 | 필요함 |

둘은 함께 쓸 수도 있습니다. [LoRA](#lr01)와 섞은 QLoRA(Dettmers 외 2023)는 원래 모델을 4비트로 얼려 두고 얇은 행렬 A, B만 학습합니다.

## 2. 예제 따라하기 (6분)

쓸 값: e² ≈ 7.39, e¹ ≈ 2.72, e⁰ = 1, e⁴ ≈ 54.6

**메모리.** 70억 개 × 2바이트 = 140억 바이트 = **14GB**. 4비트(0.5바이트)면 70억 × 0.5 = **3.5GB**.

**양자화.** 가중치 [0.50, −1.27, 0.02]

| 단계 | 계산 | 결과 |
|---|---|---|
| 눈금 | 1.27 ÷ 127 | $s$ = **0.01** |
| 정수로 | 0.50 ÷ 0.01, −1.27 ÷ 0.01, 0.02 ÷ 0.01 | **[50, −127, 2]** |
| 되돌리기 | 정수 × 0.01 | [0.50, −1.27, 0.02] (그대로!) |

값 0.004가 끼어 있었다면 0.4 → 0 → 되돌려도 0. 오차 0.004가 생깁니다.

**증류의 온도.** 선생의 로짓 [고양이 4, 개 2, 자동차 0]

- T = 1: 합 54.6 + 7.39 + 1 ≈ 63.0 → **[0.87, 0.12, 0.02]** (반올림 때문에 합이 1.01)
- T = 2: 로짓 ÷ 2 = [2, 1, 0] → 복습 문제와 같아서 **[0.67, 0.24, 0.09]**

개의 확률이 0.12에서 0.24로, 자동차가 0.02에서 0.09로 커져 "숨은 지식"이 잘 보입니다. 1등은 여전히 고양이입니다.

## 3. 능동 연습 (10분)

쓸 값: e² ≈ 7.39, e¹ ≈ 2.72, e⁰ = 1

### ✏️ 손계산
1. 130억(13B) 파라미터 모델을 16비트로 저장하면 몇 GB? (가중치만, 10⁹ 기준)
2. 1번 모델을 4비트로 줄이면?
3. 가중치 [0.30, −2.54, 0.06]을 8비트(−127~127)로 양자화하세요. 눈금과 정수 세 개는?
4. 3번의 눈금에서 값 0.006은 어떤 정수가 되고, 되돌리면 얼마인가요? 오차는?
5. 선생의 로짓이 [6, 3, 0]입니다. T = 3이면 확률은? (로짓 ÷ 3을 먼저)
6. 양자화하면 파라미터 개수가 줄어드나요?

### 🧩 미니 챌린지
선생의 확률이 [1.00, 0.00, 0.00]처럼 완전히 한쪽으로 몰려 있다면, 학생이 이것을 따라 하는 것은 원-핫 정답으로 배우는 것과 무엇이 다를까요? 이때 온도를 올리면 무엇이 좋아지나요?

### 💻 코드 (선택)
```python
import numpy as np
w = np.array([0.50, -1.27, 0.02, 0.004])
s = np.abs(w).max() / 127            # 눈금
q = np.round(w / s).astype(int)      # 저장할 정수
print(s.round(4), q, q * s)          # 0.01 [50 -127 2 0] [0.5 -1.27 0.02 0.]

def softmax(z, T=1.0):
    e = np.exp(np.array(z) / T)
    return e / e.sum()
print(softmax([4, 2, 0], T=1).round(2), softmax([4, 2, 0], T=2).round(2))
# [0.87 0.12 0.02] [0.67 0.24 0.09]
print(7e9 * 2 / 1e9, 7e9 * 0.5 / 1e9)   # 14.0 3.5 (GB, 가중치만)
```
