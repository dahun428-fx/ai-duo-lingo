# 3단계. 역전파를 손으로

⏱ 30분 · 📄 논문 연결: Rumelhart, Hinton, Williams (1986) "오차를 거꾸로 전파해 배운다". 지금의 모든 신경망이 쓰는 학습 방법

## 🎯 오늘의 목표
1. 신경망 계산을 "작은 계산 상자들이 이어진 그림"(계산 그래프)으로 그릴 수 있다.
2. 이어진 변화율은 곱한다는 연쇄법칙으로, 뒤에서 앞으로 기울기를 구할 수 있다.
3. 구한 기울기로 가중치를 한 번 고치고 손실이 줄어드는 걸 확인할 수 있다.

**복습 (1분):** w = 5, 기울기 4, 학습률 0.1이면 경사하강 한 걸음 후 w는? (답: 4.6. [기울기를 숫자로 느끼기](#dx01))

## 1. 개념 (8분)

### 1-1. 문제: 가중치가 수억 개인데 기울기는 어떻게 구하지
[기울기를 숫자로 느끼기](#dx01)에서는 w를 0.01 움직여 보고 손실 변화를 쟀습니다. 가중치가 하나면 괜찮지만, 3억 8천4백만 개라면 그만큼 다시 계산해야 합니다. 불가능하죠.

**역전파**는 계산을 **딱 한 번 거꾸로 훑어서** 모든 가중치의 기울기를 한꺼번에 구하는 방법입니다.

### 1-2. 계산 그래프: 계산을 상자로 쪼개기
가장 작은 신경망 하나를 봅시다. 입력 x, 가중치 w, 편향 b, 정답 t.

```
x ─┐
   ├─[ × ]─ wx ─┐
w ─┘            ├─[ + ]─ y ─[ (y − t)² ]─ L
b ──────────────┘
```

- 예측: $y = wx + b$
- 손실: $L = (y - t)^2$ (정답에서 벗어난 거리의 제곱)

왼쪽에서 오른쪽으로 값을 계산하는 것이 **순전파**입니다.

### 1-3. 연쇄법칙: 이어진 변화율은 곱한다
1시간에 4 km를 걷고 1 km마다 50 kcal를 쓰면, 1시간에 4 × 50 = 200 kcal. "시간 → 거리 → 칼로리"로 이어지면 변화율을 **곱합니다.**

신경망도 "w → y → L"로 이어져 있습니다.

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial y} \times \frac{\partial y}{\partial w}$$

"w가 L에 주는 영향 = (y가 L에 주는 영향) × (w가 y에 주는 영향)".

### 1-4. 상자마다 외워 둘 기울기 세 개
| 상자 | 기울기 | 말로 |
|---|---|---|
| $L = (y - t)^2$ | $\frac{\partial L}{\partial y} = 2(y - t)$ | 틀린 만큼의 2배 |
| $y = wx + b$ 에서 w | $\frac{\partial y}{\partial w} = x$ | w를 1 늘리면 y는 x만큼 는다 |
| $y = wx + b$ 에서 b | $\frac{\partial y}{\partial b} = 1$ | b를 1 늘리면 y도 1 는다 |

첫 줄은 [기울기를 숫자로 느끼기](#dx01)의 표에서 본 "2 × (w − 3)"과 같은 모양입니다.

### 1-5. 역전파: 뒤에서부터 곱해 오기
1. **순전파**로 y와 L을 구한다
2. 맨 뒤 상자의 기울기 $\frac{\partial L}{\partial y}$를 구한다
3. 앞 상자로 넘어가며 그 상자의 기울기를 **곱한다**
4. 모든 가중치의 기울기가 나오면 경사하강으로 고친다

식당 음식이 짜게 나왔다고 합시다. 손님의 불만이 서빙, 요리사, 재료 담당으로 거꾸로 전해지며 저마다 "내 탓은 얼마인가"를 계산합니다. 역전파는 이 책임 나누기입니다.

뒤에서 구한 값을 앞에서 **다시 씁니다.** 이 재활용 덕분에 가중치가 아무리 많아도 한 번 훑으면 끝납니다.

## 2. 예제 따라하기 (6분)

x = 2, w = 3, b = 1, 정답 t = 5.

**순전파**
- y = 3 × 2 + 1 = **7**
- L = (7 − 5)² = **4**

**역전파**
- $\frac{\partial L}{\partial y}$ = 2 × (7 − 5) = **4**
- $\frac{\partial L}{\partial w}$ = 4 × x = 4 × 2 = **8**
- $\frac{\partial L}{\partial b}$ = 4 × 1 = **4**

**고치기** (학습률 0.05)
- w ← 3 − 0.05 × 8 = **2.6**
- b ← 1 − 0.05 × 4 = **0.8**

**확인:** 새 y = 2.6 × 2 + 0.8 = 6.0, 새 L = (6 − 5)² = **1**. 손실이 4에서 1로 줄었습니다.

> 검산: w만 3.01로 바꾸면 y = 7.02, L = 4.0804. 변화량 0.0804 ÷ 0.01 ≈ 8. 역전파로 구한 8과 같습니다.

### 층이 둘이면
$h = w_1 x$, $y = w_2 h$, $L = (y - t)^2$. x = 1, $w_1$ = 2, $w_2$ = 3, t = 4.

- 순전파: h = 2, y = 6, L = 4
- $\frac{\partial L}{\partial y}$ = 2 × (6 − 4) = 4
- $\frac{\partial L}{\partial w_2}$ = 4 × h = **8**
- $\frac{\partial L}{\partial h}$ = 4 × $w_2$ = 12 ← 앞 층으로 넘겨줄 값. $y = w_2 h$에서 h를 1 늘리면 y는 $w_2$만큼 늡니다. 곱셈 상자에서는 "곱해진 상대방"이 기울기입니다
- $\frac{\partial L}{\partial w_1}$ = 12 × x = **12**

층이 100개여도 "받은 값 × 내 상자의 기울기 → 앞으로 넘기기"를 반복할 뿐입니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
x = 3, w = 2, b = 0, 정답 t = 4, 손실 $L = (y - t)^2$.

1. 순전파: y와 L은?
2. $\frac{\partial L}{\partial y}$는?
3. $\frac{\partial L}{\partial w}$는?
4. $\frac{\partial L}{\partial b}$는?
5. 학습률 0.01로 고친 새 w와 새 b는?
6. 새 w, b로 다시 순전파한 L은? 줄었나요?
7. (층 둘) $h = w_1 x$, $y = w_2 h$, x = 2, $w_1$ = 1, $w_2$ = 2, t = 3일 때 $\frac{\partial L}{\partial w_1}$은?

### 🧩 미니 챌린지
예측이 정답과 똑같으면(y = t) 모든 기울기는 얼마가 되나요? 그때 가중치는 어떻게 바뀌나요?

### 💻 코드 (선택)
```python
x, w, b, t = 2.0, 3.0, 1.0, 5.0
for step in range(5):
    y = w * x + b                 # 순전파
    L = (y - t) ** 2
    dy = 2 * (y - t)              # 역전파
    dw, db = dy * x, dy * 1
    print(step, round(L, 4), dw, db)
    w, b = w - 0.05 * dw, b - 0.05 * db
```
손실이 4 → 1 → 0.25 → …로 줄어드는 것을 볼 수 있습니다.

## 📝 한 줄 정리
역전파는 손실에서 출발해 뒤에서 앞으로 "받은 기울기 × 내 상자의 기울기"를 곱해 가며, 한 번에 모든 가중치의 기울기를 구한다.

**손계산**
1. y = 2 × 3 + 0 = **6**, L = (6 − 4)² = **4**
2. 2 × (6 − 4) = **4**
3. 4 × x = 4 × 3 = **12**

6. y = 1.88 × 3 − 0.04 = 5.6, L = (5.6 − 4)² = **2.56**. 4에서 줄었습니다.

7. h = 2, y = 4, $\frac{\partial L}{\partial y}$ = 2 × (4 − 3) = 2, $\frac{\partial L}{\partial h}$ = 2 × $w_2$ = 4, $\frac{\partial L}{\partial w_1}$ = 4 × x = **8**

**미니 챌린지**
$\frac{\partial L}{\partial y}$ = 2 × 0 = 0이라 뒤로 곱해 가는 모든 기울기가 **0**입니다. 가중치는 **바뀌지 않습니다.** 틀린 게 없으면 고칠 것도 없습니다.

**퀴즈**
1. 순전파는 입력에서 출력 쪽으로 예측과 손실을, 역전파는 손실에서 입력 쪽으로 기울기를 계산합니다.
2. 이어진 변화율은 곱합니다.
3. X. 한 번 거꾸로 훑으면서 뒤에서 구한 값을 앞에서 다시 씁니다.
4. w를 1 늘리면 wx가 x만큼 늘기 때문입니다. x가 크면 w의 작은 변화도 y를 크게 바꿉니다.
