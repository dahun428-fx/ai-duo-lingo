## 1. 개념 (8분)

### 1-1. 텐서: 기울기를 기억하는 numpy 배열
```python
import torch
x = torch.tensor([1.0, 2.0, 3.0])
print(x * 2)          # tensor([2., 4., 6.])
print(x.shape)        # torch.Size([3])
```
**텐서**는 numpy 배열과 거의 같습니다. 차이는 하나, **자기가 어떤 계산을 거쳤는지 기억**할 수 있습니다. 그 기록이 [역전파](#bp01)에서 그린 계산 그래프입니다.

### 1-2. 역전파를 한 줄로
```python
x, t = torch.tensor(2.0), torch.tensor(5.0)
w = torch.tensor(3.0, requires_grad=True)    # "이 값의 기울기가 필요해"
b = torch.tensor(1.0, requires_grad=True)

y = w * x + b            # 순전파: 7
L = (y - t) ** 2         # 손실: 4
L.backward()             # 역전파!
print(w.grad, b.grad)    # tensor(8.) tensor(4.)
```
`L.backward()` 한 줄이 손으로 하던 "뒤에서부터 곱해 오기"를 전부 합니다. 결과 8과 4는 [역전파를 손으로](#bp01)에서 구한 값과 똑같습니다.

### 1-3. 모델, 손실, 옵티마이저
매번 w, b를 직접 만들지 않도록 부품이 준비돼 있습니다.

| 부품 | 코드 | 하는 일 |
|---|---|---|
| 모델 | `torch.nn.Linear(1, 1)` | y = wx + b (입력 1개, 출력 1개) |
| 손실 | `torch.nn.MSELoss()` | (예측 − 정답)²의 평균 |
| 옵티마이저 | `torch.optim.SGD(model.parameters(), lr=0.05)` | w ← w − η × 기울기 |

`SGD`를 `Adam`으로 바꾸면 [Adam](#opt01)으로 학습합니다.

### 1-4. 학습의 다섯 줄
논문의 학습 코드는 대부분 이 다섯 줄이 뼈대입니다. (③은 ④보다 앞이기만 하면 되어서, 맨 끝에 두는 코드도 있습니다.)

```python
pred = model(x)            # ① 예측 (순전파)
loss = loss_fn(pred, y)    # ② 손실 계산
optimizer.zero_grad()      # ③ 지난 기울기 지우기
loss.backward()            # ④ 역전파
optimizer.step()           # ⑤ 가중치 고치기
```
③이 필요한 이유: PyTorch는 기울기를 **덮어쓰지 않고 더해서 쌓습니다.** 지우지 않으면 지난번 기울기가 섞입니다. 계산기에서 새 계산 전에 C 버튼을 누르는 것과 같습니다.

## 2. 예제 따라하기 (6분)

**첫 모델: 규칙 y = 2x + 1 찾아내기.** 모델은 규칙을 모릅니다. 데이터 4쌍만 보고 w와 b를 찾아야 합니다.

```python
import torch
torch.manual_seed(0)                                  # 매번 같은 결과가 나오게

x = torch.tensor([[0.0], [1.0], [2.0], [3.0]])        # 입력 4개
y = torch.tensor([[1.0], [3.0], [5.0], [7.0]])        # 정답: 2x + 1

model = torch.nn.Linear(1, 1)
loss_fn = torch.nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)

for step in range(500):
    pred = model(x)
    loss = loss_fn(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    if step % 100 == 0:
        print(step, round(loss.item(), 4))

print(model.weight.item(), model.bias.item())         # 2와 1에 아주 가까운 값
print(model(torch.tensor([[10.0]])).item())           # 21에 가까운 값
```

읽는 법
- `[[0.0], [1.0], …]`: shape (4, 1). 데이터 4개, 데이터마다 숫자 1개
- `for step in range(500)`: 다섯 줄을 500번 반복
- `if step % 100 == 0`: 100번에 한 번만 출력 (`%`는 나눈 나머지)
- `.item()`: 텐서에서 숫자 하나만 꺼내기
- `model.parameters()`: 모델 안의 w와 b 전부
- 손실이 줄어들며 w는 2, b는 1에 다가갑니다. 본 적 없는 x = 10에도 21에 가까운 답을 냅니다

이것이 "학습"입니다. 3억 8천4백만 개짜리 Seq2Seq 모델도, 수천억 개짜리 GPT도 **이 다섯 줄을 반복**합니다. 달라지는 것은 모델의 모양과 데이터뿐입니다.

## 📝 한 줄 정리
PyTorch에서 학습은 "예측 → 손실 → 기울기 지우기 → 역전파 → 고치기" 다섯 줄의 반복이고, 역전파는 `backward()` 한 줄이 대신 해 준다.
