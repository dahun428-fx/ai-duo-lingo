## 1. 개념 (8분)

### 1-1. 문제: 층을 지날수록 숫자가 제멋대로 커진다
층마다 곱하고 더하다 보면 값의 크기가 층마다 들쭉날쭉해집니다. 어떤 층은 0.001 근처, 어떤 층은 500 근처. 그러면 [기울기 소실과 폭발](#gv01)이 생기고 학습률 하나로 감당이 안 됩니다.

### 1-2. 정규화: 평균 0, 표준편차 1로 맞추기
[정규분포](#nd01)에서 배운 z 점수를 그대로 씁니다.

$$\hat x = \frac{x - \mu}{\sigma}$$

키(cm)와 몸무게(kg)를 같은 자로 재려고 z 점수로 바꾼 것처럼, 층에 들어가는 숫자들을 **매번 같은 눈금으로 다시 맞춥니다.**

그다음 모델이 배우는 두 숫자 γ(감마), β(베타. Adam의 β와 이름만 같은 다른 숫자)로 크기와 위치를 다시 조절합니다: $y = \gamma \hat x + \beta$. "기본은 평균 0, 표준편차 1. 필요하면 모델이 알아서 바꿔라"라는 뜻입니다.

### 1-3. 배치 정규화 vs 층 정규화
문장 2개(배치)가 있고, 문장마다 숫자 2개로 나타낸다고 합시다. 이 숫자 하나하나를 **특징**이라고 부릅니다.

| | 특징 1 | 특징 2 |
|---|---|---|
| 문장 A | 1 | 3 |
| 문장 B | 3 | 7 |

- **배치 정규화**: **세로줄**(같은 특징, 다른 문장들)마다 평균과 표준편차를 구함. 특징 1의 세로줄 [1, 3]은 평균 2, 표준편차 1이라 [−1, 1]이 됩니다
- **층 정규화**: **가로줄**(한 문장 안의 특징들)마다 구함. 문장 B의 가로줄 [3, 7]은 평균 5, 표준편차 2라 [−1, 1]이 됩니다

층 정규화는 다른 문장이 필요 없어서 배치가 작거나 문장 길이가 제각각이어도 됩니다. 그래서 Transformer와 GPT는 층 정규화를 씁니다.

### 1-4. 잔차 연결: 지름길을 하나 놓자
보통의 층은 $y = F(x)$. 잔차 연결은 입력을 **그대로 더해** 줍니다.

$$y = x + F(x)$$

"입력을 통째로 새로 만들지 말고, **고칠 부분만** 계산해서 원본에 더해라." 글을 처음부터 다시 쓰는 대신 빨간 펜으로 고칠 곳만 표시하는 것과 같습니다.

### 1-5. 왜 기울기의 고속도로인가
역전파에서 층 하나가 곱하는 값을 봅시다.

- 보통 층: F의 기울기. 예를 들어 0.5
- 잔차 층: **1 + F의 기울기**. 예를 들어 1 + 0.05 = 1.05

왜 1이 붙을까요? y = x + F(x)에서 x를 1 늘리면 앞의 x 때문에 y가 1 늘고, F 때문에 F의 기울기만큼 더 늡니다. [역전파](#bp01)에서 본 "b를 1 늘리면 y도 1 는다"와 같은 이유입니다. 잔차 층의 F는 고칠 부분만 맡아서 기울기가 작은 편이라 0.05로 잡았습니다.

| | 10층을 지난 뒤 |
|---|---|
| 보통 층 (0.5씩) | $0.5^{10} \approx 0.001$ |
| 잔차 층 (1.05씩) | $1.05^{10} \approx 1.6$ |

더하기 덕분에 기울기가 지나갈 "1"짜리 길이 항상 열려 있습니다. [LSTM](#day11)의 셀 상태가 더하기로 기억을 지킨 것과 같은 생각입니다. 이 방법으로 ResNet은 152층을 학습했고, Transformer는 모든 층에 "더하고 정규화(Add & Norm)"를 넣습니다.

## 2. 예제 따라하기 (6분)

**정규화.** 숫자 [2, 4, 4, 4, 5, 5, 7, 9]를 정규화합니다.

1. 평균: (2 + 4 + 4 + 4 + 5 + 5 + 7 + 9) ÷ 8 = 40 ÷ 8 = **5**
2. 편차 제곱: 9, 1, 1, 1, 0, 0, 4, 16 → 합 32 → 분산 32 ÷ 8 = 4 → 표준편차 **2**
3. 각 값에서 5를 빼고 2로 나눔: **[−1.5, −0.5, −0.5, −0.5, 0, 0, 1, 2]**

새 숫자들의 평균은 0, 표준편차는 1입니다.

**잔차 연결.** x = 3, F(x) = 0.2라면 y = 3 + 0.2 = **3.2**. F가 아무것도 못 배워 0을 내놓아도 y = 3. 최소한 입력은 그대로 전달됩니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. [1, 3, 5]의 평균은?
2. [1, 3, 5]의 분산과 표준편차는? (√2.67 ≈ 1.633)
3. [1, 3, 5]를 정규화하면? (소수 둘째 자리까지)
4. 정규화한 값 0.5에 γ = 2, β = 1을 적용하면?
5. x = 10, F(x) = −0.5인 잔차 층의 출력은?
6. 층 하나가 기울기에 곱하는 값이 0.9인 보통 층과 1.0인 잔차 길. 20층 뒤 각각 얼마가 남나요? (0.9²⁰ ≈ 0.12)
7. 1-3의 표에서 문장 A의 가로줄 [1, 3]을 층 정규화하면?

### 🧩 미니 챌린지
배치에 문장이 **1개**뿐이면 배치 정규화는 왜 곤란할까요? 층 정규화는 괜찮을까요?

### 💻 코드 (선택)
```python
import numpy as np
x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
z = (x - x.mean()) / x.std()
print(z)                         # [-1.5 -0.5 -0.5 -0.5  0.   0.   1.   2. ]
print(z.mean(), z.std())         # 0.0 1.0

X = np.array([[1.0, 2.0, 3.0],
              [3.0, 6.0, 9.0]])                               # 문장 2개, 특징 3개
print((X - X.mean(axis=0)) / X.std(axis=0))                   # 배치 정규화: 세로줄마다
# keepdims=True는 줄마다 평균을 빼기 위한 옵션. 지금은 주문처럼 봐도 됩니다
print((X - X.mean(axis=1, keepdims=True)) / X.std(axis=1, keepdims=True))   # 층 정규화: 가로줄마다
print(0.5 ** 10, 1.05 ** 10)     # 0.00097...  1.628...
```

## 📝 한 줄 정리
정규화는 층마다 숫자를 평균 0, 표준편차 1로 다시 맞추고, 잔차 연결 y = x + F(x)는 기울기가 줄지 않고 지나갈 길을 열어 준다.

**손계산**
1. (1 + 3 + 5) ÷ 3 = **3**
2. 편차 −2, 0, 2 → 제곱 4, 0, 4 → 분산 8 ÷ 3 ≈ **2.67**, 표준편차 ≈ **1.633**
3. [−2 ÷ 1.633, 0, 2 ÷ 1.633] ≈ **[−1.22, 0, 1.22]**
4. 2 × 0.5 + 1 = **2**
5. 10 + (−0.5) = **9.5**
6. 보통 층은 약 **0.12**, 잔차 길은 $1^{20}$ = **1**
7. 평균 2, 표준편차 1 → **[−1, 1]**

**미니 챌린지**
문장이 1개면 세로줄에 값이 하나뿐이라 표준편차가 0이 되어 나눌 수 없습니다. 층 정규화는 한 문장 안의 특징들로 계산하므로 **괜찮습니다.**

**퀴즈**
1. 평균 0, 표준편차 1
2. 배치 정규화는 같은 특징을 여러 데이터에 걸쳐(세로), 층 정규화는 한 데이터 안의 특징들에 걸쳐(가로) 평균과 표준편차를 구합니다.
3. X. y = x + 0 = x. 입력이 그대로 나옵니다.
4. 더하기 길로 기울기가 1배로 그대로 전달되어, 층이 깊어도 기울기가 사라지지 않습니다.
