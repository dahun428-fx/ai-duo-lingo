## 1. 개념 (8분)

### 1-1. 역전파는 곱셈의 사슬
[역전파](#bp01)는 뒤에서 앞으로 가며 상자마다 기울기를 **곱했습니다.** 층이 10개면 10번, 100개면 100번 곱합니다.

곱하는 수가 매번 비슷하다면

| 곱하는 수 | 10번 | 20번 |
|---|---|---|
| 0.5 | 0.001 | 0.000001 |
| 1.0 | 1 | 1 |
| 1.5 | 58 | 3325 |

- 1보다 작으면 → 앞쪽 층의 기울기가 0에 가까워짐: **기울기 소실**. 앞쪽 층이 거의 배우지 못합니다.
- 1보다 크면 → 기울기가 엄청나게 커짐: **기울기 폭발**. 한 걸음이 너무 커서 가중치가 엉뚱한 곳으로 튑니다.

[LSTM 게이트](#day11)에서 본 "0.9를 50번 곱하기"와 같은 이야기입니다. 그때는 문장의 길이 방향, 오늘은 층의 깊이 방향입니다.

### 1-2. 범인 ①: 시그모이드의 납작한 기울기
시그모이드 σ(x)는 값을 0~1로 누릅니다 ([준비 6](#prep06)). 그 기울기는 가장 가파른 곳(x = 0)에서도 **0.25**밖에 안 됩니다. 양 끝으로 가면 거의 0입니다. 직접 재 봅시다. σ(0) = 0.5, σ(0.01) ≈ 0.5025. 변화량 0.0025 ÷ 0.01 = 0.25. (실제로는 가중치도 함께 곱해지지만, 오늘은 함수의 기울기만 봅니다.)

시그모이드 층을 10개 지나면 기울기에 0.25가 10번 곱해집니다.

$$0.25^{10} \approx 0.000001$$

백만분의 일. 그래서 2010년 무렵까지 깊은 신경망은 잘 학습되지 않았습니다.

### 1-3. 해결 ①: ReLU
ReLU는 "음수면 0, 양수면 그대로"인 함수입니다.

| 입력 | ReLU 출력 | 기울기 |
|---|---|---|
| 양수 | 그대로 | **1** |
| 음수 | 0 | 0 |

켜진 곳에서는 기울기가 정확히 1이라, 몇 번을 곱해도 줄지 않습니다. $1^{10} = 1$.

### 1-4. 해결 ②: 폭발에는 기울기 자르기
기울기가 너무 크면 **방향은 그대로 두고 크기만** 줄입니다.

1. 기울기 벡터 g의 길이 $\|g\|$를 잰다 (제곱해서 더하고 √. [Day 01](#day01))
2. 길이가 한계값보다 크면 $g \leftarrow g \times \dfrac{\text{한계값}}{\|g\|}$
3. 한계값 이하면 그대로 둔다

과속 단속과 같습니다. 가는 방향은 간섭하지 않고 속도만 제한합니다. Seq2Seq 논문은 한계값 **5**를 썼습니다. LSTM은 소실에는 강하지만 폭발은 생길 수 있어서입니다.

### 1-5. (선택) 해결 ③: 시작 숫자를 잘 고르기
가중치의 시작 값이 너무 크면 처음부터 폭발하고, 너무 작으면 소실합니다. 그래서 "평균 0, 너무 크지도 작지도 않은" 무작위 수로 시작합니다. 논문은 −0.08 ~ 0.08 사이의 균등한 무작위 수를 썼습니다. 다음 레슨들의 정규화와 잔차 연결도 같은 문제를 푸는 도구입니다.

## 2. 예제 따라하기 (6분)

**기울기 자르기.** 기울기 g = [6, 8], 한계값 5.

1. 길이: $\sqrt{6^2 + 8^2} = \sqrt{100} = 10$
2. 10 > 5이므로 자른다. 곱할 값 = 5 ÷ 10 = 0.5
3. 새 g = [6 × 0.5, 8 × 0.5] = **[3, 4]**

확인: 새 길이 $\sqrt{9 + 16} = 5$. 방향(6 : 8 = 3 : 4)은 그대로, 크기만 5가 됐습니다.

**소실 비교.** 층 5개를 지날 때
- 시그모이드(최대 기울기 0.25): $0.25^5 \approx 0.001$
- ReLU(켜진 곳 기울기 1): $1^5 = 1$

6. 기울기 [0, 10]을 한계값 5로 자르면?

### 🧩 미니 챌린지
ReLU의 기울기는 음수 쪽에서 0입니다. 어떤 뉴런의 입력이 **항상** 음수가 되면 그 뉴런에는 무슨 일이 생길까요? (이 현상을 "죽은 ReLU"라고 부릅니다.)

### 💻 코드 (선택)
```python
import numpy as np
print(0.25 ** 10, 1.5 ** 20)               # 9.5e-07  3325.2...

def clip(g, limit=5.0):
    norm = np.sqrt((g ** 2).sum())
    return g * limit / norm if norm > limit else g

print(clip(np.array([6.0, 8.0])))          # [3. 4.]
print(clip(np.array([3.0, 4.0])))          # [3. 4.]  (그대로)
```

## 📝 한 줄 정리
역전파는 곱셈의 사슬이라 1보다 작은 수가 이어지면 기울기가 사라지고 큰 수가 이어지면 터진다. ReLU, 좋은 초기화, 기울기 자르기로 막는다.
