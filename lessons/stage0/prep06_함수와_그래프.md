## 1. 개념 (8분)

### 1-1. 함수 = 숫자 기계
$f(x) = 2x + 1$은 "x를 넣으면 2배 하고 1을 더해서 내보낸다"는 기계입니다.

| 넣는 수 x | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|
| 나오는 수 f(x) | −1 | 1 | 3 | 5 | 7 |

- $f(3)$: "f에 3을 넣은 결과" = 7
- **그래프**: 값표의 (x, f(x)) 점을 찍어 이은 그림

### 1-2. 직선과 기울기
$f(x) = 2x + 1$의 점을 이으면 **직선**입니다. x가 1 늘 때마다 f(x)가 항상 2씩 늡니다. 이 "x가 1 늘 때 얼마나 느나"를 **기울기**라고 합니다.

$$\text{기울기} = \frac{\text{세로로 변한 양}}{\text{가로로 변한 양}} = \frac{5 - 3}{2 - 1} = 2$$

- 기울기가 양수: 오른쪽으로 갈수록 올라감
- 기울기가 음수: 내려감
- 0: 평평함

이 기울기 개념이 1단계 "기울기를 숫자로 느끼기"와 2단계 경사하강의 씨앗입니다.

### 1-3. 휘어진 함수 = 비선형
$f(x) = x^2$은 어떨까요?

| x | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| $x^2$ | 4 | 1 | 0 | 1 | 4 |

점을 이으면 U자로 휘어집니다. **곳에 따라 기울기가 다릅니다.** 이렇게 직선이 아닌 함수를 **비선형 함수**라고 부릅니다.

신경망이 비선형 함수를 꼭 쓰는 이유: 직선 함수를 여러 번 겹쳐(차례로) 적용해도 결국 직선 하나와 같아서, 복잡한 패턴을 못 배우기 때문입니다.

### 1-4. 신경망의 단골 함수 세 가지
| 이름 | 하는 일 | 나오는 값의 범위 |
|---|---|---|
| ReLU | 음수는 0으로, 양수는 그대로 | 0 이상 |
| 시그모이드 σ | 어떤 수든 0과 1 사이로 눌러 줌 | 0 ~ 1 |
| tanh | 어떤 수든 −1과 1 사이로 눌러 줌 | −1 ~ 1 |

값표로 보면 이렇습니다 (소수 셋째 자리까지).

| x | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| ReLU(x) | 0 | 0 | 0 | 1 | 2 |
| σ(x) | 0.119 | 0.269 | **0.5** | 0.731 | 0.881 |
| tanh(x) | −0.964 | −0.762 | **0** | 0.762 | 0.964 |

- 시그모이드는 "0~1 사이의 문 열림 정도"로 쓰기 좋습니다. 2단계에서 만날 LSTM(문장을 읽으며 기억을 이어 가는 신경망)은 이 값으로 "기억을 얼마나 남길지" 정하는 문, 즉 **게이트**를 만듭니다.
- tanh는 0을 중심으로 양쪽이 대칭이라 LSTM이 담아 두는 **기억 값**에 씁니다.
- 주의: 시그모이드의 기호 σ는 1단계 기댓값 레슨에서 **표준편차**라는 전혀 다른 뜻으로도 나옵니다. 같은 글자, 다른 뜻이에요.

공식은 지금 외우지 않아도 됩니다. 시그모이드는 $\sigma(x) = \frac{1}{1 + e^{-x}}$, 지난 레슨들의 $e^x$로 만든 함수라는 것만 알아 두세요.

## 2. 예제 따라하기 (6분)

**문제.** $f(x) = 3x - 2$에서 $f(0)$, $f(2)$, 기울기는?
1. $f(0) = 3 \times 0 - 2 = -2$
2. $f(2) = 3 \times 2 - 2 = 4$
3. 기울기 = (4 − (−2)) ÷ (2 − 0) = 6 ÷ 2 = **3** (식의 x 앞 숫자와 같습니다)

**문제.** 입력 [−3, 0.5, 2]에 ReLU를 적용하면?
- 음수는 0, 양수는 그대로: **[0, 0.5, 2]**

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. $f(x) = x + 4$의 값표를 x = −1, 0, 1로 만드세요.
2. 1번 함수의 기울기는?
3. $f(x) = -2x$는 오른쪽으로 갈수록 올라가나요, 내려가나요?
4. $g(x) = x^2$에서 x가 1→2로 갈 때와 2→3으로 갈 때 늘어난 양은 각각? 직선인가요?
5. ReLU([−1, 3, −0.5, 0]) = ?
6. 값표를 보고: σ(0)과 tanh(0)은 각각?

### 💻 코드 (선택)
```python
import math
f = lambda x: 2 * x + 1
print([f(x) for x in [-1, 0, 1, 2, 3]])
relu = lambda x: max(0, x)
sigmoid = lambda x: 1 / (1 + math.exp(-x))
print([relu(x) for x in [-2, -1, 0, 1, 2]])
print([round(sigmoid(x), 3) for x in [-2, -1, 0, 1, 2]])
print([round(math.tanh(x), 3) for x in [-2, -1, 0, 1, 2]])
```
