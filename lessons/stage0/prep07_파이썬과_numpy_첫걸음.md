## 1. 개념 (8분)

### 1-1. 변수와 출력
```python
x = 3            # x라는 이름표에 3을 담는다
y = x * 2 + 1    # 7
print(y)         # 화면에 보여 준다
```
- `=`는 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름에 담아라"**
- `#` 뒤는 사람이 읽는 메모. 컴퓨터는 무시합니다
- `**`는 거듭제곱: `2 ** 3`은 8

### 1-2. 리스트: 숫자 목록
```python
a = [4, 7, 1]
print(a[0])      # 4  ← 번호가 0부터 시작!
print(len(a))    # 3  (칸 수)
print(sum(a))    # 12 (Σ)
```
수학에서는 $a_1$이 첫 칸이지만 파이썬은 **`a[0]`이 첫 칸**입니다. 가장 흔한 함정이에요.

### 1-3. numpy: 숫자 목록을 한꺼번에 계산
```python
import numpy as np        # numpy를 np라는 별명으로 불러온다
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)              # [5 7 9]   칸끼리 더하기
print(a * 2)              # [2 4 6]   모든 칸에 2 곱하기
print(a * b)              # [ 4 10 18] 칸끼리 곱하기
print(a @ b)              # 32        내적 (1×4 + 2×5 + 3×6)
```
`@`는 내적 기호입니다. **내적**은 같은 자리끼리 곱해서 모두 더하는 계산이에요. 1단계 첫 레슨에서 제대로 배우니 지금은 이름만 봐 두세요.

### 1-4. shape: 배열의 모양
```python
M = np.array([[1, 2, 3],
              [4, 5, 6]])
print(M.shape)     # (2, 3)  → 2행 3열
print(M[0, 2])     # 3       → 0번 행, 2번 열
print(a.shape)     # (3,)    → 칸 3개짜리 벡터
```
행은 가로줄, 열은 세로줄입니다. 영화관 좌석 "2줄 3번"처럼 읽으세요. `(3,)`의 쉼표는 "칸 3개짜리 한 줄"이라는 파이썬식 표기입니다. 논문의 "1000차원 벡터"는 shape `(1000,)`입니다.

### 1-5. (선택) axis: 어느 방향으로 더할까
```python
print(M.sum())          # 21        전부
print(M.sum(axis=0))    # [5 7 9]   세로로(행들을 눌러서) 더하기
print(M.sum(axis=1))    # [ 6 15]   가로로(열들을 눌러서) 더하기
```
표의 맨 아래 "합계" 줄이 `axis=0`, 맨 오른쪽 "합계" 칸이 `axis=1`입니다. 지금 헷갈려도 괜찮아요. 필요할 때 다시 오면 됩니다.

### 1-6. 준비편의 계산을 코드로
```python
print(np.sqrt(25))               # 5.0
print(np.exp(1), np.exp(-1))     # 2.718... 0.367...
print(np.log(0.5))               # -0.693...  (자연로그)
print(np.log(np.array([0.5, 0.5, 0.1])).sum())   # -3.689 (준비 4의 예제)
```

## 2. 예제 따라하기 (6분)

**문제.** 화살표 [3, 4]의 길이를 코드로 구하세요.
```python
v = np.array([3, 4])
print(np.sqrt((v ** 2).sum()))   # 5.0
```
읽는 순서: 안쪽부터. ① `v ** 2` → [9, 16] ② `.sum()` → 25 ③ `np.sqrt` → 5.0. 준비 3의 "제곱 → 더하기 → √" 그대로입니다.

**문제.** 주사위 눈의 평균은? (1단계에서 "기댓값"이라고 부릅니다)
```python
x = np.array([1, 2, 3, 4, 5, 6])
p = np.ones(6) / 6               # np.ones(6)은 1이 6개인 배열. 6으로 나누면 [1/6, 1/6, ...]
print((x * p).sum())             # 3.5
```
