# 준비 5. Σ와 ∏ 읽기

⏱ 30분 · 📄 논문 연결: 식 (1)의 $\prod$와 학습 목표의 $\frac{1}{|S|}\sum$ (2장, 3.2절)

---

## 🎯 오늘의 목표
1. $\sum$(시그마)를 보면 "전부 더하기"로 풀어 쓸 수 있다.
2. $\prod$(파이)를 보면 "전부 곱하기"로 풀어 쓸 수 있다.
3. 아래첨자 $a_i$와 평균 $\frac{1}{N}\sum$을 읽을 수 있다.

**복습 (1분):** $\ln(ab)$ = ? (답: $\ln a + \ln b$)

---

## 1. 개념 (8분)

### 1-1. 아래첨자: 번호표
숫자 목록 [4, 7, 1]이 있을 때, 칸마다 번호를 붙여 부릅니다.

- $a_1 = 4$ (첫째 칸), $a_2 = 7$ (둘째 칸), $a_3 = 1$ (셋째 칸)
- $a_i$: "i번째 칸". i는 1, 2, 3 중 아무거나 들어갈 수 있는 자리

### 1-2. Σ = 전부 더하기
$$\sum_{i=1}^{3} a_i = a_1 + a_2 + a_3$$

읽는 법: "i를 1부터 3까지 바꿔 가며 $a_i$를 모두 더하라."
- 아래 $i=1$: 어디서 시작
- 위 3: 어디서 끝
- 오른쪽 $a_i$: 무엇을 더할지

[4, 7, 1]이면 4 + 7 + 1 = **12**.

**펼쳐 쓰기가 핵심입니다.** 처음 보는 Σ가 나오면 i에 1, 2, 3을 넣어 실제로 써 보세요. 무섭던 식이 덧셈 세 개가 됩니다.

### 1-3. Σ 안에 식이 있을 때
$$\sum_{i=1}^{3} 2 a_i = 2a_1 + 2a_2 + 2a_3 = 8 + 14 + 2 = 24$$

$$\sum_{i=1}^{3} a_i b_i = a_1 b_1 + a_2 b_2 + a_3 b_3$$

두 번째 식이 1단계 첫날 배울 **내적**입니다. 같은 번호끼리 곱해서 모두 더하기. 마트 영수증이 바로 이것이에요: 가격 [1500, 3000, 800] × 개수 [2, 1, 3]을 같은 줄끼리 곱해 더하면 총액 8,400원.

### 1-4. ∏ = 전부 곱하기
$$\prod_{t=1}^{3} p_t = p_1 \times p_2 \times p_3$$

Σ와 읽는 법이 같고 **더하기 대신 곱하기**입니다. [0.5, 0.4, 0.9]면 0.5 × 0.4 × 0.9 = **0.18**.

논문의 식 (1)은 "단어 확률을 첫 단어부터 끝 단어까지 전부 곱하라"를 ∏로 쓴 것입니다.

### 1-5. 평균 = Σ를 개수로 나누기
$$\frac{1}{N} \sum_{i=1}^{N} a_i$$

"N개를 다 더해서 N으로 나눈다". [4, 7, 1]의 평균은 12 ÷ 3 = **4**. 논문의 학습 목표 $\frac{1}{|S|}\sum$는 "모든 문장의 로그 확률의 평균"입니다. ($|S|$는 "문장 모음 S에 들어 있는 문장 개수"라는 뜻입니다.)

### 1-6. 로그가 ∏를 Σ로 바꾼다
지난 레슨의 $\ln(ab) = \ln a + \ln b$를 여러 개로 늘리면

$$\ln \prod_{t} p_t = \sum_{t} \ln p_t$$

**곱의 로그 = 로그의 합**. Σ와 ∏의 위아래 범위가 생략되면 "가능한 것 전부"라는 뜻입니다. $\sum_x x \cdot p(x)$처럼 번호 대신 **값 x 하나하나**를 돌며 더하는 Σ도 있어요. 1단계 기댓값에서 바로 씁니다. 2단계에서 논문의 식이 ∏에서 Σ로 바뀌는 장면이 바로 이 한 줄입니다.

## 2. 예제 따라하기 (6분)

**문제.** $a = [2, 3, 5]$, $b = [1, 0, 2]$일 때 $\sum_{i=1}^{3} a_i b_i$는?

1. 펼치기: $a_1 b_1 + a_2 b_2 + a_3 b_3$
2. 넣기: 2×1 + 3×0 + 5×2
3. 계산: 2 + 0 + 10 = **12**

**문제.** $\prod_{t=1}^{2} p_t$에서 $p = [0.5, 0.5]$이면? 로그를 씌우면?
- 곱: 0.25
- 로그: $\ln 0.5 + \ln 0.5 = -0.693 \times 2 = -1.386$ (= $\ln 0.25$ ✓)

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. $a = [3, 1, 4, 1]$일 때 $\sum_{i=1}^{4} a_i$ = ?
2. 같은 a로 $\sum_{i=1}^{4} a_i^2$ = ? (먼저 펼쳐 쓰세요)
3. $a = [1, 2]$, $b = [3, 4]$일 때 $\sum_{i=1}^{2} a_i b_i$ = ?
4. $\prod_{t=1}^{3} p_t$, $p = [0.5, 0.2, 0.5]$ = ?
5. [2, 4, 6, 8]의 평균을 $\frac{1}{N}\sum$으로 계산하세요.
6. $\sum_{i=2}^{3} a_i$ (a = [3, 1, 4, 1])는? 시작이 2라는 데 주의.

### 💻 코드 (선택)
```python
import math
a = [3, 1, 4, 1]
print(sum(a))                       # Σ
print(sum(x * x for x in a))        # Σ a_i^2
print(math.prod([0.5, 0.2, 0.5]))   # ∏
print(sum(a) / len(a))              # 평균
```
