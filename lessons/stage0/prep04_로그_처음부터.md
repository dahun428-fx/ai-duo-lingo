## 🎯 오늘의 목표
1. 로그가 "몇 제곱?"을 묻는 질문이라는 걸 말로 설명할 수 있다.
2. 1보다 작은 수의 로그는 음수라는 것을 이해한다.
3. 로그의 성질 세 가지를 숫자로 확인하고, 왜 AI가 로그를 쓰는지 말할 수 있다.

**복습 (1분):** $2^{-1}$ = ? (답: 0.5)

---

## 1. 개념 (8분)

### 1-1. 로그 = "몇 제곱?"
$2^3 = 8$입니다. 거꾸로 묻습니다. **"2를 몇 제곱하면 8이 되나?"** 답은 3. 이 질문을 기호로 쓴 것이 로그입니다.

$$\log_2 8 = 3 \quad\Leftrightarrow\quad 2^3 = 8$$

| 질문 | 로그로 쓰면 | 답 |
|---|---|---|
| 2를 몇 제곱하면 8? | $\log_2 8$ | 3 |
| 10을 몇 제곱하면 1000? | $\log_{10} 1000$ | 3 |
| 2를 몇 제곱하면 1? | $\log_2 1$ | **0** |
| 2를 몇 제곱하면 1/2? | $\log_2 (1/2)$ | **−1** |
| 2를 몇 제곱하면 1/4? | $\log_2 (1/4)$ | **−2** |

아래 세 줄은 준비 2에서 배운 표($2^0 = 1$, $2^{-1} = 1/2$)를 거꾸로 읽은 것입니다.

**로그 = 자릿수 세기.** $\log_{10}$은 대략 "자릿수 − 1"입니다. $\log_{10} 1000 = 3$이고 1000은 네 자리. 논문의 파라미터 384,000,000은 $\log_{10} \approx 8.6$이라 아홉 자리입니다.

### 1-2. 확률의 로그는 음수
확률은 0과 1 사이입니다. **0보다 크고 1보다 작은 수의 로그는 항상 음수**, 1의 로그는 0입니다. (확률이 딱 0이면 로그를 정의할 수 없어서 −∞로 봅니다.) 그래서 논문에 나오는 "로그 확률"은 늘 0 이하의 숫자입니다. 0에 가까울수록 확률이 높다는 뜻이에요.

### 1-3. 자연로그 ln: 밑이 e인 로그
AI에서는 밑으로 **e ≈ 2.718**을 씁니다. $\ln x$ 또는 그냥 $\log x$라고 씁니다. 뜻은 "e를 몇 제곱하면 x?"

| x | 0.1 | 0.5 | 0.9 | 1 | 2 | 2.718 | 10 |
|---|---|---|---|---|---|---|---|
| $\ln x$ | −2.303 | −0.693 | −0.105 | **0** | 0.693 | **1** | 2.303 |

$\ln 0.5 = -0.693$은 **"e를 −0.693제곱하면 0.5"**라는 뜻입니다. 지수가 소수여도 괜찮아요. 1보다 작은 수로 내려가려면 음수 제곱이 필요하다는 것만 보면 됩니다.

### 1-4. 로그의 성질 세 가지 (숫자로 확인)
| 성질 | 말로 | 값표로 확인 |
|---|---|---|
| $\ln(ab) = \ln a + \ln b$ | 곱은 합이 된다 | $\ln(2 \times 5) = \ln 10$: 0.693 + 1.609 = 2.302 ≈ 2.303 ✓ |
| $\ln(a/b) = \ln a - \ln b$ | 나누기는 빼기가 된다 | $\ln(1/2) = \ln 1 - \ln 2$ = 0 − 0.693 = −0.693 ✓ |
| $\ln(a^n) = n \ln a$ | 제곱은 곱하기가 된다 | $\ln(2^3) = \ln 8$ = 3 × 0.693 = 2.079 ✓ |

($\ln 5 \approx 1.609$, $\ln 8 \approx 2.079$)

### 1-5. AI가 로그를 쓰는 이유
문장의 확률은 단어 확률을 **곱한** 값입니다. 0.5를 50번 곱하면 $8.9 \times 10^{-16}$, 더 길면 컴퓨터에서 0이 됩니다(지난 레슨). 로그를 씌우면 곱이 **합**이 됩니다.

$$\ln(0.5^{50}) = 50 \times \ln 0.5 = 50 \times (-0.693) \approx -34.65$$

−34.66은 컴퓨터가 아주 편하게 다루는 크기입니다. 그래서 논문은 확률 대신 **로그 확률**을 최대화합니다.

> **미리 보기: 놀람 = −로그 확률.** 로그 확률은 음수라 다루기 불편해서, 앞에 마이너스를 붙여 양수로 바꿔 씁니다. $-\ln 0.1 = 2.303$, $-\ln 0.9 = 0.105$. 드문 일(0.1)일수록 값이 커서 "놀람"이라고 부릅니다. 2단계 엔트로피에서 이 값을 그대로 씁니다.

## 2. 예제 따라하기 (6분)

**문제.** 세 단어 확률이 0.5, 0.5, 0.1일 때 문장 확률의 자연로그는?

1. 곱의 로그는 로그의 합: $\ln 0.5 + \ln 0.5 + \ln 0.1$
2. 값표: −0.693 + (−0.693) + (−2.303)
3. 합: **−3.689**
4. 확인: 0.5 × 0.5 × 0.1 = 0.025, $\ln 0.025 \approx -3.689$ ✓

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. $\log_2 16$ = ?
2. $\log_{10} 0.01$ = ?
3. $\log_2 (1/8)$ = ?
4. 값표를 써서 $\ln 4$를 구하세요. (힌트: 4 = 2 × 2)
5. $\ln(0.5^{10})$ = ?
6. 확률 0.9와 0.1 중 로그 확률이 0에 더 가까운 쪽은? 값은?

### 💻 코드 (선택)
```python
import math
print(math.log2(8), math.log10(1000))
print(math.log(0.5))         # 자연로그
print(math.log(2) + math.log(5), math.log(10))
print(50 * math.log(0.5))
```
