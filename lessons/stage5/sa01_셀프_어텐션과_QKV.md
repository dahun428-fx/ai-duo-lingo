## 1. 개념 (8분)

### 1-1. "그것"은 무엇을 가리킬까
"동물이 길을 건너지 않았다. **그것**이 너무 피곤했기 때문이다."

"그것"은 동물일까요, 길일까요? 사람은 "피곤했다"를 보고 동물이라고 압니다. 단어의 뜻은 **같은 문장의 다른 단어들**을 봐야 정해집니다.

[어텐션](#att01)은 디코더가 입력 문장을 보는 방법이었습니다. **셀프 어텐션**은 문장이 **자기 자신**을 봅니다. 모든 단어가 다른 모든 단어를 보고, 관련 있는 단어의 정보를 끌어와 자기 벡터를 고칩니다.

### 1-2. 세 가지 역할: Query, Key, Value
도서관에서 책을 찾는 장면을 떠올리세요.

| 역할 | 도서관 | 셀프 어텐션 |
|---|---|---|
| **Query (질문)** | 내가 적어 낸 검색어 | "나는 이런 정보를 찾고 있어" |
| **Key (열쇠)** | 책등에 붙은 분류 라벨 | "나는 이런 정보를 갖고 있어" |
| **Value (값)** | 책의 실제 내용 | 실제로 건네줄 정보 |

단어마다 원래 벡터 x에 행렬 세 개를 곱해 세 벡터를 만듭니다: $q = W_Q x$, $k = W_K x$, $v = W_V x$. 이 세 행렬이 학습되는 가중치입니다.

### 1-3. 계산: 어텐션과 똑같은 세 단계
단어 i가 문장을 볼 때

1. **점수**: 내 q와 모든 단어의 k를 내적 → $q_i \cdot k_j$. 검색어와 라벨이 얼마나 맞는지
2. **소프트맥스**: 점수를 $\sqrt{d_k}$로 나눈 뒤 가중치로
3. **가중 평균**: 가중치로 모든 단어의 v를 평균 → 단어 i의 새 벡터

단어마다 만든 q를 한 줄씩 쌓은 표가 Q, k를 쌓은 표가 K, v를 쌓은 표가 V입니다. 이 표로 한꺼번에 쓰면 논문의 식이 됩니다. 식이 낯설어도 괜찮습니다. 위의 세 단계를 모든 단어에 대해 한 번에 적은 것일 뿐입니다.

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

- $QK^\top$: 모든 단어 쌍의 점수표 (단어 5개면 5 × 5 표)
- $d_k$: q와 k 벡터의 칸 수. 논문은 64
- $^\top$: 행렬을 눕힌다는 표시. "모든 q와 모든 k를 내적한다"로 읽으면 됩니다

### 1-4. 왜 √d_k로 나눌까
벡터의 칸이 많을수록 내적은 큰 숫자가 되기 쉽습니다. 예를 들어 [1, 1] · [1, 1] = 2지만, 1이 64칸이면 내적은 64입니다. 점수가 [20, 0]처럼 크게 벌어지면 소프트맥스가 [1, 0]에 달라붙어, 한 단어만 보고 나머지는 무시합니다. 그 영역에서는 기울기도 거의 0이라 학습이 멈춥니다 ([기울기 소실](#gv01)).

$\sqrt{d_k}$로 나눠 점수를 적당한 크기로 **식혀 줍니다.** $d_k$ = 64이면 8로 나눕니다.

### 1-5. RNN과 무엇이 다른가
| | RNN / LSTM | 셀프 어텐션 |
|---|---|---|
| 먼 단어와의 거리 | 단어 수만큼의 스텝 | **1** |
| 계산 | 한 단어씩 차례로 | 모든 단어를 **동시에** |
| 순서 정보 | 저절로 있음 | 없음 (다음 레슨의 위치 인코딩이 채움) |

동시에 계산할 수 있어서 GPU로 훨씬 큰 데이터를 학습할 수 있게 됐습니다.

## 2. 예제 따라하기 (6분)

단어 2개, $d_k$ = 4. 첫째 단어의 질문이 $q_1$이고, 점수(내적)가 이미 계산되어 있다고 합시다.

| | 단어 1의 k | 단어 2의 k |
|---|---|---|
| $q_1 \cdot k_j$ | 4 | 0 |

값 벡터는 $v_1$ = [2, 0], $v_2$ = [0, 2].

1. **식히기:** $\sqrt{4} = 2$로 나눔 → [2, 0]
2. **소프트맥스:** $e^2 \approx 7.39$, $e^0 = 1$, 합 8.39 → **[0.88, 0.12]**
3. **가중 평균:** 0.88 × [2, 0] + 0.12 × [0, 2] = **[1.76, 0.24]**

단어 1의 새 벡터는 자기 정보 88%에 단어 2의 정보 12%를 섞은 것입니다.

**식히지 않았다면?** 점수 [4, 0] 그대로면 $e^4 \approx 54.6$ → 가중치 [0.98, 0.02]. 훨씬 한쪽으로 쏠립니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. $d_k$ = 64이면 점수를 얼마로 나누나요?
2. q = [1, 2], k = [3, 1]의 점수(내적)는?
3. 식힌 점수가 [0, 0]이면 가중치는?
4. 식힌 점수가 [1, 0], 값이 $v_1$ = [4, 0], $v_2$ = [0, 4]일 때 새 벡터는? ($e^1 \approx 2.72$)
5. 단어가 6개인 문장의 점수표 $QK^\top$는 몇 행 몇 열인가요?
6. 단어 1000개인 글의 점수표에는 칸이 몇 개 있나요? 글이 2배 길어지면 칸은 몇 배가 되나요?

### 🧩 미니 챌린지
"나는 은행에서 돈을 찾았다"와 "나는 은행을 구워 먹었다". 두 문장의 "은행"은 처음에 같은 벡터로 시작합니다. 셀프 어텐션을 지나면 두 벡터는 어떻게 달라질까요?

### 💻 코드 (선택)
```python
import numpy as np
def softmax(z):
    e = np.exp(z - z.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

Q = np.array([[2.0, 0.0, 0.0, 0.0],        # 단어 2개, d_k = 4
              [0.0, 2.0, 0.0, 0.0]])
K = Q.copy()
V = np.array([[2.0, 0.0], [0.0, 2.0]])

scores = Q @ K.T                           # [[4. 0.] [0. 4.]]
A = softmax(scores / np.sqrt(4))           # 가중치 표
print(A.round(2))                          # [[0.88 0.12] [0.12 0.88]]
print((A @ V).round(2))                    # [[1.76 0.24] [0.24 1.76]]
```

## 📝 한 줄 정리
셀프 어텐션은 단어마다 질문(Q)을 내고 모든 단어의 열쇠(K)와 맞춰 본 뒤, 그 가중치로 값(V)을 평균 내어 문맥이 담긴 새 벡터를 만든다.
