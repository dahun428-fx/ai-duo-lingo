1. 3×3 필터를 그림 위로 미끄러뜨리며 "같은 자리끼리 곱해서 더하기"를 손으로 할 수 있다.

## 1. 개념 (8분)

### 1-1. 문제: 그림을 통째로 층에 넣으면
흑백 그림은 점(픽셀)마다 밝기 숫자 하나가 있는 표입니다. 28 × 28 그림이면 숫자 784개입니다. [Day 02](#day02)의 층에 그대로 넣으면 두 가지가 곤란합니다.

- **파라미터가 너무 많습니다.** 컬러 사진 224 × 224 × 3(빨강, 초록, 파랑)이면 입력이 150,528개. 출력 1000칸짜리 층 하나에 가중치가 약 1억 5천만 개입니다.
- **위치가 바뀌면 처음부터 다시 배워야 합니다.** 같은 고양이라도 왼쪽에 있을 때와 오른쪽에 있을 때를 따로 배웁니다. 완전연결층(입력의 모든 칸이 출력의 모든 칸과 이어진, 지금까지 써 온 보통 층)은 자리마다 다른 가중치를 쓰기 때문입니다.

### 1-2. 필터: 작은 돋보기 하나
**필터**(커널이라고도 함)는 3 × 3 같은 작은 숫자 판입니다. 그림의 3 × 3 조각 위에 올려 **같은 자리끼리 곱해서 모두 더합니다.** 숫자 9개짜리 [내적](#day01)입니다.

돋보기를 그림의 한 자리에 대고 "여기 세로선 있나?"만 묻는다고 생각하세요. 세로선 탐지 필터는 이렇게 생겼습니다.

| −1 | 0 | 1 |
|---|---|---|
| **−1** | **0** | **1** |
| **−1** | **0** | **1** |

왼쪽이 어둡고(0) 오른쪽이 밝은(1) 곳에서 큰 값이 나오고, 고르게 밝은 곳에서는 0이 나옵니다.

### 1-3. 미끄러뜨리기와 출력 크기
필터를 한 칸씩 오른쪽으로, 줄이 끝나면 한 줄 아래로 옮기며 매번 곱해서 더합니다. 이 계산 전체가 **합성곱**, 결과 표가 **특징 지도**입니다.

5칸짜리 줄 위에서 3칸짜리 필터는 몇 자리에 놓일까요? 처음 자리에서 오른쪽으로 2번 옮길 수 있으니 자리는 2 + 1 = **3**개입니다. 그래서 5 × 5 그림에 3 × 3 필터를 쓰면 출력은 **3 × 3**입니다.

$$\text{출력 크기} = (\text{입력} - \text{필터}) + 1$$

### 1-4. 가중치 공유: 같은 돋보기를 어디서나
여기가 핵심입니다. **모든 자리에서 같은 필터 9칸을 씁니다.** 그래서 이 필터가 배울 숫자는 9개 + 편향 1개 = **10개**뿐입니다.

| 28 × 28 → 26 × 26 | 배울 숫자 |
|---|---|
| 완전연결층 | 784 × 676 = **529,984개** (편향 빼고) |
| 3 × 3 합성곱 | **10개** |

게다가 같은 필터가 그림 전체를 훑으니, 세로선이 왼쪽에 있든 오른쪽에 있든 **같은 방식으로** 찾습니다. 1-1의 두 문제가 함께 풀립니다.

### 1-5. 패딩과 스트라이드
- **패딩**: 그림 둘레에 0을 한 겹 두릅니다. 출력이 줄어드는 것을 막고, 가장자리도 필터 가운데에 오게 합니다.
- **스트라이드**: 필터를 한 번에 몇 칸씩 옮기나. 2칸씩 옮기면 출력이 약 절반이 됩니다.

$$\text{출력 크기} = \frac{\text{입력} - \text{필터} + 2 \times \text{패딩}}{\text{스트라이드}} + 1$$

외우지 않아도 됩니다. "패딩을 붙인 길이에서 필터가 몇 번 옮겨 갈 수 있나 + 1"입니다. 예: 32 × 32에 3 × 3 필터, 패딩 1, 스트라이드 1 → (32 − 3 + 2) ÷ 1 + 1 = 32. 크기가 그대로입니다.

### 1-6. 채널: 색 필름 3장
컬러 그림은 빨강, 초록, 파랑 투명 필름 3장을 겹친 것과 같습니다(채널 3개). 그래서 필터도 3 × 3 × **3** 두께를 가집니다. 27칸을 곱해 더해 숫자 **하나**를 냅니다.

필터를 16개 쓰면 특징 지도 16장, 곧 다음 층의 채널 16개가 나옵니다. 하나는 세로선, 하나는 가로선, 하나는 빨간 점… 필터의 숫자는 사람이 정하지 않고 [역전파](#bp01)로 학습합니다.

### 1-7. 최대 풀링: 요약해서 줄이기
특징 지도를 2 × 2 칸씩 나눠 **가장 큰 값만** 남깁니다. 가로세로가 절반이 됩니다.

"이 구역 어딘가에 세로선이 있었다"는 사실만 남기고 정확한 자리는 흐리게 합니다. 그래서 그림이 한 칸쯤 밀려도 결과가 잘 안 바뀝니다. 풀링에는 배울 숫자가 **없습니다.**

> (선택) 수학 교재의 "합성곱"은 필터를 뒤집어서 곱합니다. 딥러닝 라이브러리는 뒤집지 않고 그대로 곱하는데(교차상관), 필터 숫자를 어차피 학습하므로 결과에 차이가 없습니다. 이름만 합성곱으로 부릅니다(Goodfellow 외 9.1절).

## 2. 예제 따라하기 (6분)

**쓸 값**

| 그림 (5 × 5) | 세로선 필터 (3 × 3) |
|---|---|
| 줄마다 [0, 0, 1, 1, 1] (왼쪽 두 칸 어둡고 나머지 밝음) | 줄마다 [−1, 0, 1] |

**1. 첫 자리 (왼쪽 위).** 그림의 1~3열은 줄마다 [0, 0, 1]. 필터와 곱하면 줄마다 (−1)×0 + 0×0 + 1×1 = 1. 세 줄이니 **3**.

**2. 한 칸 오른쪽.** 2~4열은 줄마다 [0, 1, 1]. 줄마다 0 + 0 + 1 = 1 → **3**.

**3. 또 한 칸 오른쪽.** 3~5열은 줄마다 [1, 1, 1]. 줄마다 −1 + 0 + 1 = 0 → **0**.

아래 줄들도 똑같으니 특징 지도는

| 3 | 3 | 0 |
|---|---|---|
| **3** | **3** | **0** |
| **3** | **3** | **0** |

어둠과 밝음의 **경계가 걸친 자리에서 3**, 고르게 밝은 자리에서 0. 필터가 세로 경계를 찾았습니다.

**최대 풀링.** 4 × 4 특징 지도 [[1, 3, 2, 0], [5, 2, 1, 1], [0, 1, 4, 6], [2, 0, 3, 1]]을 2 × 2씩 나누면 왼쪽 위 {1, 3, 5, 2} → 5, 오른쪽 위 {2, 0, 1, 1} → 2, 왼쪽 아래 {0, 1, 2, 0} → 2, 오른쪽 아래 {4, 6, 3, 1} → 6. 결과 **[[5, 2], [2, 6]]**.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 6 × 6 그림 "7" 위로 필터를 한 칸씩 옮겨 보세요. 필터를 세로선, 가로선, 흐림으로 바꾸면 특징 지도가 어떻게 달라지는지, 풀링 단추를 누르면 4 × 4가 2 × 2로 어떻게 줄어드는지 확인하세요.

### ✏️ 손계산
1. 그림 조각 [[1, 2, 0], [0, 1, 0], [2, 0, 1]]에 대각선 필터 [[1, 0, 0], [0, 1, 0], [0, 0, 1]]을 쓰면?
2. 7 × 7 그림에 3 × 3 필터, 스트라이드 2. 출력 크기는?
3. 32 × 32 그림에 5 × 5 필터, 패딩 2, 스트라이드 1. 출력 크기는?
4. 컬러 그림(채널 3)에 3 × 3 필터 16개를 쓰는 층. 배울 숫자는 모두 몇 개? (필터마다 편향 1개)
5. 특징 지도 [[2, 0, 1, 1], [1, 3, 0, 2], [4, 1, 0, 0], [0, 2, 5, 1]]에 2 × 2 최대 풀링을 하면?
6. 28 × 28 그림 → 3 × 3 합성곱(패딩 0) → 2 × 2 최대 풀링. 최종 크기는?

### 🧩 미니 챌린지
숫자 "7" 그림을 오른쪽으로 한 칸 민 그림이 있습니다. 완전연결층과 "합성곱 + 최대 풀링" 중 어느 쪽이 두 그림을 더 비슷하게 볼까요? 이유를 한 문장으로 써 보세요.

### 💻 코드 (선택)
```python
import numpy as np
img = np.array([[0, 0, 1, 1, 1]] * 5)         # 5 × 5 그림
f = np.array([[-1, 0, 1]] * 3)                # 세로선 필터
out = np.zeros((3, 3), dtype=int)
for i in range(3):                            # 아래로 옮기기
    for j in range(3):                        # 오른쪽으로 옮기기
        out[i, j] = (img[i:i+3, j:j+3] * f).sum()   # 같은 자리끼리 곱해서 더하기
print(out)                                    # [[3 3 0] [3 3 0] [3 3 0]]

```

## 📝 한 줄 정리
합성곱은 작은 필터 하나를 그림 전체에 미끄러뜨리며 곱해서 더하고(가중치 공유), 최대 풀링은 구역마다 가장 큰 값만 남겨 그림을 줄인다.

다음 챕터에서는 이 부품을 쌓아 만든 유명한 CNN들을 봅니다. (예고: 11단계의 ViT가 그림을 16 × 16 조각으로 자르는 일은 16 × 16 필터를 16칸씩 옮기는 합성곱과 같습니다.)

**손계산**
1. 대각선 자리 1, 1, 1만 남습니다 → 1 + 1 + 1 = **3**

6. 28 − 3 + 1 = 26 → 26 ÷ 2 = **13 × 13**

**미니 챌린지**
합성곱 + 최대 풀링입니다. 같은 필터가 모든 자리를 훑으니 밀린 그림에서도 같은 특징이 한 칸 옆에서 나오고, 최대 풀링이 2 × 2 구역 안의 작은 이동을 흡수합니다. 완전연결층은 자리마다 가중치가 달라 한 칸만 밀려도 완전히 다른 입력으로 봅니다.

**퀴즈**
1. 필터와 그 아래 그림 조각을 같은 자리끼리 곱해서 모두 더합니다(내적).
2. 필터가 몇 번 옮겨 갈 수 있는지 세고 1을 더합니다. 패딩은 길이에 더하고, 스트라이드로 나눕니다.
3. X. 모든 자리에서 같은 필터를 씁니다(가중치 공유).
4. 0개. 정해진 규칙(최댓값 고르기)만 씁니다.
5. 배울 숫자가 훨씬 적고(가중치 공유), 같은 무늬를 어느 자리에서나 같은 방식으로 찾습니다.
