## 1. 개념 (8분)

### 1-1. 정답 붙은 데이터는 귀하고, 그냥 글은 넘친다
번역 데이터처럼 사람이 정답을 달아 준 데이터는 적습니다. 반면 인터넷에는 글이 끝없이 있습니다.

**생각:** 글 자체에서 문제와 정답을 만들자. 글의 일부를 가리고 맞히게 하면 사람이 정답을 달 필요가 없습니다. 이렇게 큰 모델을 미리 학습시키는 것이 **사전학습**입니다. 그 뒤에 원하는 일(감정 분류, 질문 답하기)에 맞춰 조금 더 학습시키는 것이 **미세조정**입니다.

국어를 폭넓게 읽어 둔 사람이 계약서 검토를 금방 배우는 것과 같습니다.

### 1-2. BERT: 빈칸 맞히기
문장의 단어 중 **15%를 가리고** 맞히게 합니다.

"나는 [가림] 밥을 먹었다" → 정답 "아침에"

빈칸의 **왼쪽과 오른쪽을 모두** 보고 풉니다. Transformer의 **인코더** 블록만 쌓은 모델이고, 문장을 **이해**하는 일(분류, 검색, 질문에서 답 찾기)에 강합니다.

### 1-3. GPT: 다음 단어 맞히기
앞 단어들만 보고 **다음 단어**를 맞힙니다.

"나는 아침에 밥을" → 정답 "먹었다"

[Day 03](#day03)의 연쇄법칙 그대로, 문장의 확률을 "앞 단어들이 주어졌을 때 다음 단어의 확률"의 곱으로 학습합니다. Transformer의 **디코더** 블록만 쌓은 모델이고, 한 단어씩 이어 쓰면 되므로 글을 **생성**하는 일에 강합니다.

### 1-4. 미래를 가리는 마스크
GPT가 학습할 때 문장 전체가 한꺼번에 들어갑니다. 그런데 셀프 어텐션은 모든 단어를 보니, 그대로 두면 **정답(다음 단어)을 미리 훔쳐봅니다.**

그래서 자기보다 **뒤에 있는 단어의 점수를 −∞로** 바꿉니다. −∞는 "끝없이 작은 수"라는 표시입니다. $e^{-10} \approx 0.00005$처럼 지수가 작아질수록 0에 가까워지니, −∞를 넣으면 0으로 봅니다. 그래서 소프트맥스 뒤의 가중치가 0이 됩니다.

| 보는 단어 → | 1번 | 2번 | 3번 |
|---|---|---|---|
| 1번 단어가 볼 수 있나 | ✓ | ✗ | ✗ |
| 2번 단어 | ✓ | ✓ | ✗ |
| 3번 단어 | ✓ | ✓ | ✓ |

시험지에서 아직 풀지 않은 문제의 답을 종이로 가려 두는 것입니다. BERT에는 이 마스크가 없습니다.

### 1-5. 크기와 쓰는 법
| 모델 | 해 | 파라미터 수 | 쓰는 법 |
|---|---|---|---|
| Seq2Seq | 2014 | 3.8억 | 번역만 |
| BERT (large) | 2018 | 3.4억 | 일마다 미세조정 |
| GPT-3 | 2020 | **1750억** | 미세조정 없이 **글로 부탁**(프롬프트) |

GPT-3는 예시 몇 개를 입력에 적어 주기만 해도 새 일을 해냈습니다(few-shot). 예: "사과 → apple, 포도 → grape, 수박 → "까지만 적어 주면 "watermelon"을 이어 씁니다. 번역하라고 따로 가르친 적이 없는데도요. 지금 Claude에게 직접 해 보세요. 가중치를 고치지 않고 입력만으로 일을 시키는 방식, 지금 Claude나 ChatGPT를 쓰는 방식의 시작입니다.

## 2. 예제 따라하기 (6분)

**마스크 계산.** 단어 3개 문장에서 2번 단어의 점수가 [1, 1, 1]입니다.

- **BERT (마스크 없음):** 소프트맥스 → [1/3, 1/3, 1/3]. 세 단어를 고루 봅니다
- **GPT (미래 가림):** 3번을 가려 [1, 1, −∞] → $e^1, e^1, 0$ = 2.72, 2.72, 0. 합 5.44 → 2.72 ÷ 5.44 = 0.5씩 → **[0.5, 0.5, 0]**. 1번과 2번만 봅니다

**문제 수 세기.** "나는 아침에 밥을 먹었다" (4단어)

- GPT: "나는" → 아침에, "나는 아침에" → 밥을, "나는 아침에 밥을" → 먹었다. 문장 하나에서 **3문제**
- BERT: 100단어짜리 글이면 15%인 **15개**를 가리고 맞힘

**손실.** 둘 다 [크로스엔트로피](#day07)입니다. 모델이 정답 단어에 준 확률이 0.25면 손실은 −ln 0.25 ≈ 1.39.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. 200단어짜리 글에서 BERT는 몇 단어를 가리나요?
2. 6단어 문장에서 GPT는 다음 단어 맞히기 문제를 몇 개 만드나요?
3. 4단어 문장에서 3번 단어는 몇 번 단어까지 볼 수 있나요? (GPT)
4. 4단어 문장에서 3번 단어의 점수가 [2, 2, 2, 2]일 때 GPT의 가중치는?
5. 같은 점수에서 BERT의 가중치는?
6. 모델이 정답 단어에 확률 0.5를 줬을 때 손실 −ln 0.5는? (ln 0.5 ≈ −0.69)

### 🧩 미니 챌린지
"이 영화 리뷰가 긍정인지 부정인지 분류하기"와 "이야기의 뒷부분 이어 쓰기". 각각 BERT와 GPT 중 어느 쪽 구조가 자연스러울까요? 그런데 요즘은 왜 GPT 방식 하나로 둘 다 할까요?

### 💻 코드 (선택)
```python
import numpy as np
scores = np.ones((3, 3))                       # 단어 3개, 모든 점수 1
mask = np.triu(np.ones((3, 3)), k=1) == 1      # 대각선 위쪽(미래)이 True
scores[mask] = -np.inf                         # 미래를 가림
A = np.exp(scores) / np.exp(scores).sum(axis=1, keepdims=True)
print(A.round(2))
# [[1.   0.   0.  ]
#  [0.5  0.5  0.  ]
#  [0.33 0.33 0.33]]
```

## 📝 한 줄 정리
BERT는 양쪽을 다 보고 빈칸을 맞히며 이해를, GPT는 앞만 보고 다음 단어를 맞히며 생성을 배운다. 둘 다 정답 없는 글로 사전학습한 Transformer다.
