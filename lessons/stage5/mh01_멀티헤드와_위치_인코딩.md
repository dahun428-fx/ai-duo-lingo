## 1. 개념 (8분)

### 1-1. 한 번에 한 가지만 볼 수는 없다
"나는 어제 친구가 추천한 영화를 봤다"에서 "봤다"는 **누가**(나는), **무엇을**(영화를), **언제**(어제)를 모두 알아야 합니다. 어텐션 하나는 가중치 한 벌만 만들기 때문에 이 여러 관계를 한꺼번에 담기 어렵습니다.

### 1-2. 멀티헤드: 어텐션을 여러 벌 나란히
**헤드** 하나 = [Q·K·V 셀프 어텐션](#sa01) 한 벌. 헤드마다 $W_Q, W_K, W_V$가 따로 있어서 **서로 다른 관계**를 봅니다. 한 헤드는 주어를, 다른 헤드는 목적어를, 또 다른 헤드는 바로 옆 단어를 보는 식입니다.

회의에서 한 사람은 일정만, 한 사람은 예산만, 한 사람은 위험만 듣고 나중에 메모를 합치는 것과 같습니다.

논문의 숫자: 단어 벡터 512칸, 헤드 **8개**. 헤드마다 $W_Q, W_K, W_V$가 512칸 벡터를 512 ÷ 8 = **64칸**으로 줄여서 작은 어텐션을 합니다. 결과 8개를 옆으로 나란히 이어 붙이면(64 × 8) 다시 512칸입니다. 그래서 전체 계산량은 헤드 하나짜리와 비슷합니다.

### 1-3. 문제: 셀프 어텐션은 순서를 모른다
셀프 어텐션은 "모든 단어 쌍의 내적"입니다. 단어를 섞어도 쌍은 그대로라 결과가 같습니다.

영어의 "dog bites man"(개가 사람을 문다)과 "man bites dog"(사람이 개를 문다)은 단어가 완전히 같고 순서만 다릅니다. 단어 카드를 주머니에 넣고 흔든 것처럼, 셀프 어텐션은 어느 카드가 앞에 있었는지 모릅니다. 순서 정보를 따로 넣어 주지 않으면 두 문장을 구별할 수 없습니다.

### 1-4. 위치 인코딩: 자리 번호를 벡터로 더하기
단어 벡터에 **"몇 번째 자리인지"를 나타내는 벡터**를 더합니다.

$$\text{입력} = \text{단어 벡터} + \text{위치 벡터}$$

논문은 위치 벡터를 sin과 cos 물결로 만들었습니다. sin과 cos는 처음 보셔도 괜찮습니다. 숫자를 넣으면 −1과 1 사이를 물결처럼 오르내리는 값을 돌려주는 함수이고, 값은 계산기가 구해 줍니다. 오늘은 아래 표를 그대로 가져다 쓰기만 합니다. 가장 작은 경우(2칸)를 보면

| 자리 pos | sin(pos) | cos(pos) |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 0.84 | 0.54 |
| 2 | 0.91 | −0.42 |

자리마다 다른 벡터가 됩니다. 실제로는 512칸에 **빠르기가 다른 물결**을 여러 개 씁니다. 시계의 초침, 분침, 시침처럼 빠른 바늘은 가까운 자리를, 느린 바늘은 먼 자리를 구별합니다.

> 요즘 모델은 위치 벡터를 학습시키거나 다른 방식(회전 위치 인코딩 등)을 쓰기도 합니다.

### 1-5. Transformer 블록 조립
지금까지 배운 부품이 모두 모입니다.

1. **멀티헤드 셀프 어텐션**: 단어들이 서로 정보를 주고받음
2. **더하고 정규화**: 어텐션에 들어가기 전의 벡터를 결과에 다시 더하고([잔차 연결](#norm01)), 크기를 고르게 맞춥니다(층 정규화)
3. **작은 신경망**(영어로 feed-forward): 어텐션으로 모은 정보를 단어마다 혼자 곱씹는 단계입니다. [Day 02](#day02)의 층 두 개(`Wx + b` → ReLU → `Wx + b`)입니다
4. **더하고 정규화**

논문의 Transformer는 이 블록을 두 종류로 씁니다. 입력 문장을 읽는 쪽이 **인코더 블록**, 번역문을 한 단어씩 쓰는 쪽이 **디코더 블록**입니다. 디코더 블록은 "아직 쓰지 않은 뒤쪽 단어를 못 보게 가린다"는 점이 다릅니다. 다음 레슨에서 다시 만납니다.

> (선택) 논문은 인코더 블록과 디코더 블록을 각각 **6번** 쌓았습니다. 더 큰 버전(1024칸, 헤드 16개)은 영어→독일어 BLEU 28.4, 영어→프랑스어 41.8로 당시 최고 기록을 냈습니다. RNN이 하나도 없어서 제목이 "어텐션만 있으면 된다"입니다.

## 2. 예제 따라하기 (6분)

**헤드 크기.** 단어 벡터 768칸, 헤드 12개인 모델이라면 헤드 하나는 768 ÷ 12 = **64칸**.

**위치 더하기.** 단어 "cat"의 벡터가 [0.5, 0.2]이고 1번 자리에 있다면

입력 = [0.5, 0.2] + [0.84, 0.54] = **[1.34, 0.74]**

같은 "cat"이 2번 자리에 있다면 [0.5, 0.2] + [0.91, −0.42] = **[1.41, −0.22]**. 같은 단어도 자리에 따라 다른 벡터로 들어갑니다.

**두 헤드 합치기.** 어떤 단어에 대해 헤드 A의 출력이 [1, 0], 헤드 B의 출력이 [0.3, 0.7]이면, 이어 붙여 **[1, 0, 0.3, 0.7]**. 평균이 아니라 **나란히 붙입니다.**

## 3. 능동 연습 (10분)

### ✏️ 손계산

4. 같은 단어가 2번 자리에 있을 때는?
5. 헤드 3개의 출력이 각각 [1, 2], [3, 4], [5, 6]이면 합친 벡터는?
6. 블록을 6번 쌓고 블록마다 헤드가 8개면 어텐션 헤드는 모두 몇 개?

### 🧩 미니 챌린지
위치 인코딩 없이 "dog bites man"과 "man bites dog"을 넣으면 "bites"의 셀프 어텐션 출력은 두 문장에서 어떻게 될까요? 그 이유는?

### 💻 코드 (선택)
```python
import numpy as np
pos = np.arange(3)                                   # 자리 0, 1, 2
pe = np.stack([np.sin(pos), np.cos(pos)], axis=1)    # 2칸짜리 위치 벡터
print(pe.round(2))             # [[ 0.    1.  ] [ 0.84  0.54] [ 0.91 -0.42]]

cat = np.array([0.5, 0.2])
print((cat + pe[1]).round(2), (cat + pe[2]).round(2))   # [1.34 0.74] [ 1.41 -0.22]

print(np.concatenate([[1, 0], [0.3, 0.7]]))             # [1.  0.  0.3 0.7]
```
