## 1. 개념 (8분)

### 1-1. 병목: 쪽지 한 장으로 책 한 권을 전하기
Seq2Seq는 입력 문장을 **벡터 하나 v**로 압축하고, 디코더는 그 v만 보고 번역했습니다. 5단어 문장도, 50단어 문장도 같은 크기의 벡터 하나입니다.

책을 읽고 쪽지 한 장에 요약한 뒤, 쪽지만 보고 번역하는 셈입니다. 문장이 길수록 빠지는 내용이 생깁니다. 실제로 초기 번역 신경망은 긴 문장에서 성적이 뚝 떨어졌습니다.

### 1-2. 생각: 번역하다가 원문을 다시 보면 되잖아
사람은 번역할 때 원문을 계속 다시 봅니다. "지금 쓰려는 단어와 관련 있는 부분"을 골라서요.

인코더는 단어를 하나 읽을 때마다 기억 h를 만들었는데, Seq2Seq는 마지막 h만 쓰고 나머지는 버렸습니다. 어텐션은 버리던 h를 모두 보관해 둡니다.

**어텐션**은 디코더가 단어 하나를 만들 때마다, 인코더의 **모든 단어의 기억**($h_1, h_2, \dots$)을 다시 보게 합니다. 다만 똑같이 보지 않고, 관련 있는 곳에 **더 큰 가중치**를 줍니다.

### 1-3. 세 단계
디코더의 지금 상태를 s라고 합시다.

1. **점수 매기기**: 입력 단어마다 "지금 얼마나 관련 있나" 점수를 준다. 가장 간단한 방법은 [내적](#day01) $s \cdot h_i$
2. **소프트맥스**: 점수들을 합이 1인 **가중치** $\alpha_i$로 바꾼다
3. **가중 평균**: $c = \sum_i \alpha_i h_i$. 이것이 **문맥 벡터**

[기댓값](#ev01)에서 "확률로 가중한 평균"을 구한 것과 같은 계산입니다. 값 대신 벡터를 평균 낼 뿐입니다.

디코더는 이제 고정된 v 대신, **단어마다 새로 만든 c**를 보고 다음 단어를 예측합니다.

### 1-4. 무엇이 좋아졌나
- **병목이 사라짐**: 문장이 길어도 필요한 곳을 직접 봅니다. 긴 문장에서도 성적이 떨어지지 않았습니다
- **먼 단어도 한 걸음**: 아무리 먼 단어도 한 번에 연결됩니다. [LSTM](#day11)처럼 50스텝을 건너 기억을 실어 나를 필요가 없습니다
- **들여다볼 수 있음**: 가중치 표를 그리면 "이 프랑스어 단어를 쓸 때 영어의 어디를 봤는지"가 보입니다

| | The | cat | sat |
|---|---|---|---|
| chat(고양이)을 쓸 때 | 0.1 | **0.8** | 0.1 |

모델이 어디를 봤는지 이렇게 숫자로 드러납니다.

> (선택) 원 논문은 점수를 내적이 아니라 작은 신경망으로 계산했습니다. 이듬해 Luong 외(2015)가 내적 방식을 정리했고, Transformer가 이를 이어받았습니다.

## 2. 예제 따라하기 (6분)

입력 세 단어의 기억이 $h_1$ = [1, 0], $h_2$ = [0, 1], $h_3$ = [1, 1]입니다.

**가중치가 주어졌을 때.** α = [0.7, 0.2, 0.1]이면

c = 0.7 × [1, 0] + 0.2 × [0, 1] + 0.1 × [1, 1] = [0.7 + 0.1, 0.2 + 0.1] = **[0.8, 0.3]**

첫 단어를 70% 반영한 섞음입니다.

**가중치를 직접 구할 때.** 디코더 상태 s = [1, 0].

1. 점수(내적): $s \cdot h_1$ = 1, $s \cdot h_2$ = 0, $s \cdot h_3$ = 1
2. 소프트맥스: $e^1 \approx 2.72$, $e^0 = 1$, $e^1 \approx 2.72$. 합 6.44
   - α ≈ [2.72 ÷ 6.44, 1 ÷ 6.44, 2.72 ÷ 6.44] = **[0.42, 0.16, 0.42]**
3. 문맥 벡터: 0.42 × [1, 0] + 0.16 × [0, 1] + 0.42 × [1, 1] = **[0.84, 0.58]**

s와 같은 방향 성분이 큰 $h_1$, $h_3$에 가중치가 몰렸습니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
$h_1$ = [2, 0], $h_2$ = [0, 2]

1. α = [0.5, 0.5]일 때 문맥 벡터 c는?
2. α = [0.9, 0.1]일 때 c는?
3. s = [1, 0]일 때 두 점수 $s \cdot h_1$, $s \cdot h_2$는?
4. 3번 점수 [2, 0]의 소프트맥스 가중치는? ($e^2 \approx 7.39$)
5. 4번 가중치로 구한 c는?
6. 점수가 모두 같으면(예: [1, 1, 1]) 가중치는 어떻게 되나요?

### 🧩 미니 챌린지
"The cat sat on the mat"을 프랑스어로 번역하며 "chat"(고양이)을 쓸 차례입니다. 가중치가 가장 클 영어 단어는 무엇일까요? 한국어처럼 어순이 다른 언어로 번역할 때 어텐션이 특히 도움이 되는 이유는?

### 💻 코드 (선택)
```python
import numpy as np
H = np.array([[1, 0], [0, 1], [1, 1]])       # 입력 단어 3개의 기억
s = np.array([1, 0])                          # 디코더 상태

scores = H @ s                                # [1 0 1]
alpha = np.exp(scores) / np.exp(scores).sum() # 소프트맥스
c = alpha @ H                                 # 가중 평균
print(alpha.round(2), c.round(2))             # [0.42 0.16 0.42] [0.84 0.58]
```
