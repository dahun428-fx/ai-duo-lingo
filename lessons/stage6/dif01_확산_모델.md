## 1. 개념 (8분)

### 1-1. 잉크 한 방울
물컵에 잉크를 떨어뜨리면 서서히 퍼져 온 물이 뿌옇게 됩니다. 이 과정은 쉽습니다. **거꾸로**, 뿌연 물에서 잉크 방울을 되살리는 것은 어렵습니다.

확산 모델은 이 거꾸로 가는 법을 배웁니다. 한 번에 되돌리기는 어려우니 **아주 조금씩, 여러 번** 되돌립니다.

### 1-2. 정방향: 조금씩 잡음 더하기 (학습 없음)
그림 $x_0$에 잡음을 조금씩 섞어 $x_1, x_2, \dots, x_T$를 만듭니다.

$$x_t = \sqrt{1 - \beta}\; x_{t-1} + \sqrt{\beta}\; \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, 1)$$

- β(베타): 한 걸음에 섞는 잡음의 양 (0과 1 사이의 작은 수)
- 원래 그림은 $\sqrt{1 - \beta}$배로 **옅어지고**, 잡음이 $\sqrt{\beta}$배만큼 **더해집니다**

루트는 섞은 뒤에도 전체 크기(분산)가 1로 유지되게 하는 장치입니다. 지금은 "제곱해서 더하면 1이 되는 두 비율"(0.8² + 0.6² = 1)로만 기억하세요. T는 마지막 걸음 번호입니다.

걸음을 거듭하면 원래 그림은 사라지고 **순수한 잡음**만 남습니다. DDPM은 T = 1000걸음을 썼습니다.

### 1-3. 한 번에 건너뛰기
걸음마다 계산할 필요 없이, 원본에서 t번째로 **바로** 갈 수 있습니다.

$$x_t = \sqrt{\bar\alpha_t}\; x_0 + \sqrt{1 - \bar\alpha_t}\; \varepsilon$$

α = 1 − β라고 부릅니다. 이것을 t번 곱한 것이 $\bar\alpha_t$(알파 바)이고, 위의 줄은 "지금까지 다 곱했다"는 표시입니다. β = 0.2로 2걸음이면 0.8 × 0.8 = 0.64. 원본에 실제로 곱해지는 수는 그 제곱근 $\sqrt{\bar\alpha_t}$ = 0.8입니다.

### 1-4. 역방향: 잡음을 맞혀서 지우기 (여기를 학습)
신경망에게 잡음 섞인 그림 $x_t$와 걸음 번호 t를 주고, **"여기에 섞인 잡음 ε이 무엇이었는지"** 맞히게 합니다.

$$\text{손실} = (\varepsilon - \hat\varepsilon)^2$$

학습 한 번의 순서
1. 진짜 그림 $x_0$을 고른다
2. 걸음 t와 잡음 ε을 무작위로 뽑는다
3. 1-3의 식으로 $x_t$를 만든다
4. 모델이 $\hat\varepsilon$을 예측하고, 실제 ε과의 차이를 줄인다

정답(ε)을 **우리가 직접 섞었으니** 사람이 정답을 달 필요가 없습니다. [GAN](#gan01)처럼 두 모델이 싸우지도 않아 학습이 안정적입니다.

### 1-5. 그림 만들기
1. 순수한 잡음 $x_T$에서 시작
2. 모델이 잡음을 예측 → 조금 지움 → $x_{T-1}$
3. 1000번 반복 → 새 그림 $x_0$

조각가가 돌덩이에서 "그림이 아닌 부분"을 조금씩 깎아 내는 것과 같습니다.

| | VAE | GAN | 확산 모델 |
|---|---|---|---|
| 배우는 법 | 압축 후 복원 | 생성자 대 판별자 | 잡음 맞히기 |
| 학습 안정성 | 안정 | 불안정 | 안정 |
| 그림 품질 | 흐릿한 편 | 선명 | 선명하고 다양 |
| 만드는 속도 | 한 번에 | 한 번에 | **여러 걸음 (느림)** |

글로 그림을 주문하는 서비스들은 확산 모델에 글의 뜻을 [어텐션](#att01)으로 넣어 줍니다.

## 2. 예제 따라하기 (6분)

그림의 점 하나의 값이 $x_0$ = 1.0이라고 합시다.

**한 걸음 더하기.** β = 0.36 (그러면 √0.64 = 0.8, √0.36 = 0.6), 뽑힌 ε = 0.5

$x_1$ = 0.8 × 1.0 + 0.6 × 0.5 = 0.8 + 0.3 = **1.1**

**건너뛰기.** 한 걸음이라 $\bar\alpha$ = 1 − 0.36 = 0.64. ε = 0.5이면 같은 계산입니다: 0.8 × 1.0 + 0.6 × 0.5 = **1.1**

**손실.** 실제 ε = 0.5, 모델 예측 $\hat\varepsilon$ = 0.3 → (0.5 − 0.3)² = **0.04**

**되돌리기.** 모델이 잡음을 정확히 맞혔다면($\hat\varepsilon$ = 0.5)

$x_0$ ≈ (1.1 − 0.6 × 0.5) ÷ 0.8 = 0.8 ÷ 0.8 = **1.0**. 원본이 되살아납니다. 건너뛰기 식을 $x_0$에 대해 거꾸로 푼 것입니다. 잡음을 정확히 맞혔을 때만 이렇게 한 번에 됩니다. 실제 모델의 예측은 조금씩 틀리므로, 조금만 지우고 다시 묻기를 반복합니다.

**원본이 사라지는 속도.** 원본에 곱해지는 수가 걸음마다 0.8배가 되면 10걸음 뒤 $0.8^{10} \approx 0.11$. 원본 성분은 0.11배만 남습니다.

## 3. 능동 연습 (10분)

β = 0.36 (√(1 − β) = 0.8, √β = 0.6)으로 계산하세요.

### ✏️ 손계산

2. $x_0$ = 0.5, ε = −1.0일 때 $x_1$은?
3. 실제 잡음 ε = 1.0, 예측 $\hat\varepsilon$ = 0.7일 때 손실은?
4. $x_1$ = 2.2이고 모델이 $\hat\varepsilon$ = 1.0이라고 맞혔습니다. 되돌린 $x_0$은?
5. β = 0.2로 3걸음 가면 $\bar\alpha$는? (0.8을 세 번 곱하기)
6. $x_0$ = 1.0에서 걸음마다 ε = 0.5가 뽑혔다고 하고 두 걸음 가 보세요. $x_2$는? 원본에 곱해진 수는 얼마가 됐나요?

### 🧩 미니 챌린지
왜 "잡음에서 그림으로 한 번에" 가지 않고 1000걸음으로 나눌까요? [기울기 소실](#gv01)의 "0.9를 50번 곱하기"와는 반대로, 여기서는 여러 걸음이 왜 도움이 되는지 생각해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
rng = np.random.default_rng(0)
x = np.array([1.0, -1.0, 0.5])              # "그림" (점 3개)
beta = 0.2
for t in range(1, 11):
    x = np.sqrt(1 - beta) * x + np.sqrt(beta) * rng.normal(size=3)
print(x.round(2))                            # 잡음이 많이 섞인 값
print(0.8 ** 10, np.sqrt(0.8 ** 10))         # 0.107... 0.327...  알파 바와, 원본에 곱해진 수(그 제곱근)

x0, eps, abar = 1.0, 0.5, 0.64
xt = np.sqrt(abar) * x0 + np.sqrt(1 - abar) * eps
print(xt, (xt - np.sqrt(1 - abar) * eps) / np.sqrt(abar))   # 1.1 1.0
```

## 📝 한 줄 정리

**미니 챌린지**
순수한 잡음에서 완성된 그림까지는 너무 먼 길이라 한 번에 맞히기 어렵습니다. "잡음이 조금 섞인 그림에서 그 조금을 지우기"는 훨씬 쉬운 문제입니다. 쉬운 문제 1000개로 나누면 걸음마다 작은 실수는 다음 걸음이 고칠 수 있습니다.

**퀴즈**
1. 정방향은 그림에 잡음을 조금씩 더해 순수한 잡음으로 만들고, 역방향은 잡음을 조금씩 지워 그림으로 되돌립니다.
2. 지금 그림에 섞여 있는 잡음 ε
3. X. 정방향은 정해진 식대로 잡음을 섞을 뿐입니다. 학습은 역방향에서만 합니다.
4. 그림 하나를 만들 때 신경망을 여러 번(수십~1000번) 돌려야 해서 느립니다.
