## 1. 개념 (8분)

### 1-1. 싸우면서 큰다
- **생성자 G** (위조범): 무작위 숫자 z를 받아 가짜 그림 G(z)를 만든다. 목표는 **감별사를 속이기**. z는 [VAE](#vae01)의 잠재 벡터와 같은 역할, 곧 그림의 씨앗입니다. 씨앗이 다르면 다른 그림이 나옵니다
- **판별자 D** (감별사): 그림을 보고 "진짜일 확률" D(x)를 0~1로 답한다. 목표는 **가짜를 가려내기**

위조범이 솜씨를 키우면 감별사도 눈이 높아지고, 감별사가 깐깐해지면 위조범은 더 정교해집니다. 이 경쟁이 **적대적**(adversarial) 학습입니다.

[VAE](#vae01)는 "원본과 얼마나 다른가"를 식으로 정해 놓고 배웠습니다. GAN은 "얼마나 진짜 같은가"를 재는 **자를 통째로 신경망(D)에게 맡깁니다.**

### 1-2. 판별자의 손실
판별자는 분류기입니다. 진짜에는 1, 가짜에는 0에 가까운 답을 내고 싶습니다. [크로스엔트로피](#day07) 그대로입니다.

$$L_D = -\ln D(\text{진짜}) - \ln\big(1 - D(\text{가짜})\big)$$

- 진짜를 진짜라고 할수록(D(진짜) → 1) 첫 항이 0에 가까워짐
- 가짜를 가짜라고 할수록(D(가짜) → 0) 둘째 항이 0에 가까워짐

### 1-3. 생성자의 손실
생성자는 판별자가 가짜를 **진짜라고 답하게** 만들고 싶습니다.

$$L_G = -\ln D(\text{가짜})$$

D(가짜)가 1에 가까울수록 손실이 0에 가까워집니다. 생성자는 진짜 그림을 **한 번도 직접 보지 않습니다.** 판별자의 답에서 흘러오는 기울기([역전파](#bp01))만으로 배웁니다.

### 1-4. 번갈아 학습
1. D를 한 걸음 학습 (G는 고정): 진짜와 가짜를 더 잘 가리게
2. G를 한 걸음 학습 (D는 고정): D를 더 잘 속이게
3. 반복

**균형점:** 가짜가 진짜와 구별이 안 되면 판별자는 무엇을 보든 **0.5**라고 답할 수밖에 없습니다. 동전 던지기와 다를 바 없는 상태입니다. 생성자는 1을 원하지만 판별자도 계속 배웁니다. 가짜가 진짜와 똑같아지면 판별자가 낼 수 있는 가장 좋은 답이 0.5라서, 생성자가 갈 수 있는 끝도 여기입니다.

### 1-5. 어려운 점
- **불안정**: 두 모델의 실력이 맞아야 합니다. 판별자가 너무 잘하면 생성자가 배울 실마리(기울기)가 사라지고, 너무 못하면 배울 게 없습니다
- **모드 붕괴**: 생성자가 판별자를 잘 속이는 **몇 가지 그림만** 반복해서 만드는 현상. 숫자 0~9를 배웠는데 1만 그리는 식입니다. 모드는 데이터의 "종류"(숫자 0, 1, …)라고 생각하세요
- **평가가 어려움**: 손실이 줄었다고 그림이 좋아졌다는 보장이 없습니다

그래도 선명한 그림을 한 번에 만들어 내서 2014~2020년 이미지 생성의 주역이었습니다. 지금은 다음 레슨의 확산 모델이 많이 쓰입니다.

## 2. 예제 따라하기 (6분)

쓸 로그 값: ln 0.9 ≈ −0.105, ln 0.8 ≈ −0.223, ln 0.5 ≈ −0.693, ln 0.2 ≈ −1.609

**학습 초반.** 판별자가 잘 가려냅니다: D(진짜) = 0.9, D(가짜) = 0.2

- $L_D$ = −ln 0.9 − ln(1 − 0.2) = 0.105 + 0.223 = **0.328** (작음: 판별자가 잘하는 중)
- $L_G$ = −ln 0.2 = **1.609** (큼: 생성자가 못 속이는 중)

**균형점.** D(진짜) = 0.5, D(가짜) = 0.5

- $L_D$ = −ln 0.5 − ln 0.5 = 0.693 + 0.693 = **1.386**
- $L_G$ = −ln 0.5 = **0.693**

판별자의 손실 1.386(= 2 ln 2)은 "찍는 것과 같다"는 뜻입니다.

## 3. 능동 연습 (10분)

쓸 로그 값: ln 0.6 ≈ −0.511, ln 0.5 ≈ −0.693, ln 0.4 ≈ −0.916, ln 0.1 ≈ −2.303, ln 0.9 ≈ −0.105

### ✏️ 손계산
1. D(진짜) = 0.6, D(가짜) = 0.5일 때 판별자 손실 $L_D$는?
2. 같은 상황의 생성자 손실 $L_G$는?
3. D(가짜) = 0.1일 때와 0.9일 때 $L_G$는 각각? 생성자는 어느 쪽을 원하나요?
4. D(진짜) = 0.9, D(가짜) = 0.1일 때 $L_D$는? 판별자가 잘하고 있나요?
5. 판별자가 모든 그림에 0.5라고 답합니다. 누가 이긴 상태인가요?
6. 생성자가 숫자 "7"만 계속 만듭니다. 이 현상의 이름은?

### 🧩 미니 챌린지
생성자는 진짜 그림을 직접 보지 못하는데 어떻게 진짜 같은 그림을 그리게 될까요? "미술 선생님의 한마디"에 빗대어 설명해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
def d_loss(d_real, d_fake):
    return -np.log(d_real) - np.log(1 - d_fake)
def g_loss(d_fake):
    return -np.log(d_fake)

print(d_loss(0.9, 0.2).round(3), g_loss(0.2).round(3))   # 0.329 1.609
print(d_loss(0.5, 0.5).round(3), g_loss(0.5).round(3))   # 1.386 0.693
```
(손계산 0.328과 끝자리가 다른 것은 로그 값을 반올림해서 더했기 때문입니다.)
