## 1. 개념 (8분)

### 1-1. 생성 모델: 분류가 아니라 만들기
지금까지의 모델은 주로 **맞히는** 일을 했습니다. **생성 모델**은 데이터와 비슷한 **새 것을 만듭니다.** 세상에 없던 얼굴 사진, 새 문장.

### 1-2. 오토인코더: 좁은 문을 지나게 하기
- **인코더**: 입력 x를 작은 벡터 z로 **압축**
- **디코더**: z에서 x를 **복원** → $\hat x$
- 손실: 원본과 복원의 차이 $(x - \hat x)^2$

784칸(28 × 28 점)짜리 손글씨 그림을 2칸짜리 z로 줄였다 되살려야 한다면, 모델은 "어떤 숫자인지, 얼마나 기울었는지" 같은 **핵심만** z에 담을 수밖에 없습니다. z가 사는 공간을 **잠재 공간**이라고 합니다. 잠재는 "겉으로 안 보이게 숨어 있다"는 뜻입니다. 그림 속에 숨은 핵심 특징이라 그렇게 부릅니다. 여행 가방에 꼭 필요한 것만 싸는 것과 같아요. [PCA](#svd01)가 직선 방향으로 줄였다면 오토인코더는 신경망으로 휘어지게 줄입니다.

### 1-3. 문제: 잠재 공간에 구멍이 숭숭
새 그림을 만들려면 아무 z나 골라 디코더에 넣으면 될 것 같습니다. 그런데 보통 오토인코더는 학습 데이터가 놓인 **점들만** 복원할 줄 압니다. 점과 점 사이의 빈 곳을 고르면 엉망인 그림이 나옵니다.

### 1-4. VAE의 생각: 점 대신 구름
VAE의 인코더는 z를 점 하나로 내놓지 않고 **"평균 μ, 표준편차 σ인 정규분포"**로 내놓습니다. 그리고 거기서 z를 **뽑습니다.**

$$z = \mu + \sigma \cdot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, 1)$$

ε(엡실론)은 표준 정규분포에서 뽑은 무작위 수입니다. ~는 "이 분포에서 무작위로 하나 뽑았다"는 뜻이에요. 키 분포에서 사람 한 명을 아무나 고르는 것과 같습니다. 0 근처 값이 자주, ±2 밖은 드물게 나옵니다. (Adam에 나온 ε과는 다른, 여기서만 쓰는 이름입니다.) 같은 그림도 매번 조금씩 다른 z로 바뀌니, 디코더는 **그 주변 전체**를 복원하는 법을 배웁니다. 점이 구름이 되어 빈 곳이 메워집니다.

> 이렇게 "무작위는 ε에 몰아 두고, μ와 σ는 보통 계산으로" 쓰는 것을 재매개변수화 요령이라고 합니다. 덕분에 [역전파](#bp01)가 μ와 σ까지 흘러갑니다.

### 1-5. 손실 = 복원 오차 + KL 벌점
구름들이 제멋대로 흩어지면 또 구멍이 생깁니다. 그래서 모든 구름이 **표준 정규분포 $\mathcal{N}(0, 1)$ 근처에 모이도록** 벌점을 줍니다. 두 분포의 차이를 재는 [KL 발산](#day07)을 씁니다.

$$\text{손실} = \underbrace{(x - \hat x)^2}_{\text{복원 오차}} + \underbrace{\text{KL}\big(\mathcal{N}(\mu, \sigma^2)\,\|\,\mathcal{N}(0, 1)\big)}_{\text{벌점}}$$

z가 숫자 하나일 때 KL 벌점은 다음 식입니다.

$$\text{KL} = \frac{1}{2}\left(\mu^2 + \sigma^2 - 1 - \ln \sigma^2\right)$$

μ = 0, σ = 1이면 정확히 0. 거기서 멀어질수록 커집니다. [Day 07](#day07)의 KL을 건너뛰었어도 괜찮습니다. "표준 정규분포에서 벗어난 만큼 내는 벌금"이라고만 읽으세요. 식은 외우지 말고 숫자만 넣어 봅니다. μ²은 가운데서 벗어난 벌금, 나머지는 폭이 1에서 벗어난 벌금입니다.

두 조각은 **줄다리기**를 합니다. 복원 오차는 "그림마다 구름을 멀리 떨어뜨려 구별하자", KL은 "모두 가운데로 모여라". 그 균형에서 **빈틈없이 정돈된** 잠재 공간이 만들어집니다.

**만들 때:** $\mathcal{N}(0, 1)$에서 z를 뽑아 디코더에 넣으면 새 데이터가 나옵니다.

## 2. 예제 따라하기 (6분)

**z 뽑기.** 인코더가 μ = 2, σ = 0.5를 내놓았고, 뽑힌 ε = −1이면

z = 2 + 0.5 × (−1) = **1.5**

**복원 오차.** x = [1, 0], 복원 $\hat x$ = [0.8, 0.1]

(1 − 0.8)² + (0 − 0.1)² = 0.04 + 0.01 = **0.05**

**KL 벌점.**

| μ | σ | 계산 | KL |
|---|---|---|---|
| 0 | 1 | ½(0 + 1 − 1 − ln 1) | **0** |
| 1 | 1 | ½(1 + 1 − 1 − 0) | **0.5** |
| 2 | 1 | ½(4 + 1 − 1 − 0) | **2** |

(ln 1 = 0) 평균이 0에서 멀어질수록 벌점이 빠르게 커집니다.

**전체 손실.** 복원 오차 0.05, KL 0.5면 0.05 + 0.5 = **0.55**

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. μ = 1, σ = 2, ε = 0.5일 때 z는?
2. μ = 0, σ = 1, ε = −0.3일 때 z는?
3. x = [2, 1], $\hat x$ = [1.5, 1]의 복원 오차는?
4. μ = 3, σ = 1일 때 KL 벌점은?
5. μ = 0, σ = 1일 때 KL 벌점은? 이것이 뜻하는 바는?
6. 복원 오차가 0.2, KL이 0.3이면 전체 손실은?
7. μ = 0, σ = 2일 때 KL 벌점은? (ln 4 ≈ 1.386)

### 🧩 미니 챌린지
KL 벌점을 없애면(보통 오토인코더처럼) 복원은 더 잘 됩니다. 그런데 왜 새 그림 만들기는 더 못할까요? 반대로 KL 벌점만 아주 세게 주면 어떤 일이 생길까요?

### 💻 코드 (선택)
```python
import numpy as np
def kl(mu, sigma):
    return 0.5 * (mu**2 + sigma**2 - 1 - np.log(sigma**2))

print(kl(0, 1), kl(1, 1), kl(2, 1))      # 0.0 0.5 2.0

rng = np.random.default_rng(0)
mu, sigma = 2.0, 0.5
z = mu + sigma * rng.normal(size=5)       # 같은 입력에서 z를 5번 뽑기
print(z.round(2))                         # 2 근처에서 조금씩 다른 값 5개

x, x_hat = np.array([1, 0]), np.array([0.8, 0.1])
print(((x - x_hat) ** 2).sum().round(2))  # 0.05
```
