## 1. 개념 (8분)

### 1-1. 거꾸로 묻기: 어떤 동전이었을까
동전을 10번 던져 앞면이 7번 나왔습니다. 이 동전의 앞면 확률 θ(세타)는 얼마일까요? θ는 여기서 각도가 아니라 "우리가 모르는 설정값"의 이름표입니다. 신경망에서는 가중치 전체를 θ라고 부릅니다.

확률은 보통 "θ를 알 때 데이터가 어떻게 나올까"를 묻습니다. 지금은 **거꾸로**입니다. 데이터를 보고 θ를 맞혀야 합니다. 신경망 학습이 정확히 이 일입니다. 데이터(글)를 보고 파라미터(가중치)를 맞히는 것.

### 1-2. 가능도: 이 설정이라면 이 데이터가 나올 확률
앞면 7번, 뒷면 3번이 나올 확률을 θ로 적으면 (앞앞뒤…처럼 한 줄로 나온 그 순서 그대로의 확률)

$$L(\theta) = \theta^7 (1 - \theta)^3$$

이것이 **가능도**입니다. θ를 바꿔 가며 계산해 봅니다.

| θ | 가능도 $\theta^7 (1-\theta)^3$ |
|---|---|
| 0.5 | 0.00098 |
| 0.6 | 0.00179 |
| **0.7** | **0.00222** |
| 0.8 | 0.00168 |

θ = 0.7일 때 가장 큽니다. 범인을 찾는 탐정처럼, **지금 증거를 가장 잘 설명하는 용의자**를 고르는 것입니다.

### 1-3. 최대가능도 추정 (MLE)
가능도가 가장 큰 θ를 고르는 방법입니다. 동전에서는 답이 단순합니다.

$$\hat\theta_{\text{MLE}} = \frac{\text{앞면 횟수}}{\text{던진 횟수}} = \frac{7}{10}$$

작은 수의 곱은 다루기 어려우니 **로그**를 씌워 합으로 바꿉니다 ([준비 4](#prep04)).

$$\ln L(\theta) = 7 \ln\theta + 3 \ln(1 - \theta)$$

로그 가능도를 **최대화**하는 것은 부호를 바꾼 **−로그 가능도를 최소화**하는 것과 같습니다. 그런데 "정답에 준 확률의 −로그"는 [크로스엔트로피](#day07) 손실이었죠. **신경망이 크로스엔트로피를 줄이는 것 = 최대가능도 추정**입니다.

### 1-4. MLE의 약점: 데이터가 적으면 과신한다
동전을 3번 던져 3번 다 앞면이 나왔습니다. MLE는 θ = 3/3 = **1**. "이 동전은 절대 뒷면이 안 나온다"고 합니다. 겨우 3번 보고 내리기엔 너무 센 결론입니다.

### 1-5. MAP: 사전 믿음을 섞는다
우리는 "동전은 보통 반반에 가깝다"는 **사전 믿음**이 있습니다. [베이즈 정리](#day04)로 섞습니다.

$$\underbrace{p(\theta \mid \text{데이터})}_{\text{사후}} \propto \underbrace{p(\text{데이터} \mid \theta)}_{\text{가능도}} \times \underbrace{p(\theta)}_{\text{사전}}$$

(∝는 "비례한다"는 뜻) 사후 확률이 가장 큰 θ를 고르는 것이 **MAP 추정**입니다.

식을 직접 풀 필요는 없습니다. 사전 믿음을 "미리 본 동전 던지기"로 바꾸면 가능도에 곱해져서, 결국 데이터가 2개 더 있는 것처럼 세기만 하면 됩니다. 이것을 **가짜 관측**이라고 부르겠습니다. "이미 앞면 1번, 뒷면 1번을 본 셈 치자".

$$\hat\theta_{\text{MAP}} = \frac{\text{앞면} + 1}{\text{던진 횟수} + 2}$$

3번 다 앞면: (3 + 1) ÷ (3 + 2) = **0.8**. 1보다 훨씬 조심스러운 답입니다. 데이터가 많아지면 가짜 관측 2개는 묻혀서 MLE와 거의 같아집니다.

> (선택) 신경망에서: "가중치는 0 근처일 것"이라는 사전 믿음을 넣으면 손실에 가중치 제곱의 합이 벌점으로 붙습니다. 이것이 **가중치 감쇠**(weight decay), 곧 가중치가 너무 커지지 않게 매번 살짝 줄이는 규칙이고, AdamW의 W입니다.

## 2. 예제 따라하기 (6분)

**문제.** 동전을 4번 던져 앞, 앞, 뒤, 앞이 나왔습니다.

**가능도 비교**
- θ = 0.5: 0.5 × 0.5 × 0.5 × 0.5 = **0.0625**
- θ = 0.75: 0.75 × 0.75 × 0.25 × 0.75 ≈ **0.105**

0.75 쪽이 데이터를 더 잘 설명합니다.

**MLE:** 3 ÷ 4 = **0.75**

**MAP (가짜 관측 앞 1, 뒤 1):** (3 + 1) ÷ (4 + 2) = 4 ÷ 6 ≈ **0.67**. 사전 믿음(0.5) 쪽으로 조금 당겨졌습니다.

**데이터가 많으면:** 400번 중 300번 앞면이라면 MAP = 301 ÷ 402 ≈ 0.749. MLE(0.75)와 거의 같습니다.

1. 동전을 20번 던져 앞면 12번. MLE는?

5. 가능도가 0.25일 때 로그 가능도는? (ln 0.25 ≈ −1.39) −로그 가능도는?
6. 주사위를 60번 던져 6이 15번 나왔습니다. "6이 나올 확률"의 MLE는? 공정한 주사위의 값(1/6 ≈ 0.167)과 비교해 보세요.

### 🧩 미니 챌린지
새로 연 식당에 리뷰가 딱 1개, 별 5개입니다. 리뷰 500개에 평균 4.6인 식당과 비교해 어디가 더 믿을 만할까요? MLE와 MAP의 말로 설명해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
thetas = np.array([0.5, 0.6, 0.7, 0.8])
L = thetas ** 7 * (1 - thetas) ** 3
print(L.round(5))                    # [0.00098 0.00179 0.00222 0.00168]

grid = np.linspace(0.01, 0.99, 99)   # linspace는 구간을 같은 간격으로 나눈 수들: 0.01, 0.02, ..., 0.99
logL = 7 * np.log(grid) + 3 * np.log(1 - grid)
print(grid[logL.argmax()].round(2))  # 0.7  (로그 가능도가 최대인 θ)

h, n = 3, 3
print(h / n, (h + 1) / (n + 2))      # 1.0 0.8
```

## 📝 한 줄 정리
MLE는 데이터를 가장 잘 설명하는 설정을 고르고, MAP는 거기에 사전 믿음을 섞는다. 신경망의 크로스엔트로피 학습은 MLE, 가중치 감쇠를 더하면 MAP다.
