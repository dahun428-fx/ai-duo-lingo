## 1. 개념 (8분)

### 1-1. 확률의 기본
- P(A): 사건 A가 일어날 확률, 0 ~ 1 사이
- 가능한 모든 경우의 확률을 더하면 1

### 1-2. 결합확률 vs 조건부확률
반 학생 100명을 조사했습니다.

|  | 안경 O | 안경 X | 합계 |
|---|---|---|---|
| 코딩 좋아함 | 30 | 10 | 40 |
| 코딩 안 좋아함 | 20 | 40 | 60 |
| 합계 | 50 | 50 | 100 |

- **결합확률** P(코딩, 안경) = 30/100 = 0.3 → "전체 중에서 둘 다인 사람"
- **조건부확률** P(안경 | 코딩) = 30/40 = 0.75 → "코딩 좋아하는 사람 *중에서* 안경 쓴 사람"
- 전체 비율로 바꿔도 같습니다: (30/100) ÷ (40/100) = 30/40. 같은 분모끼리 나누면 분자끼리의 나눗셈만 남아요 ([준비 1](#prep01)). 아래 공식은 이 한 줄을 기호로 쓴 것입니다.

`|` 기호는 "~가 주어졌을 때", "~라는 걸 이미 알 때"라고 읽습니다. **분모(관심 범위)가 좁아지는 것**이 핵심 직관입니다.

$$P(B\mid A) = \frac{P(A, B)}{P(A)}$$

### 1-3. 곱셈 규칙과 연쇄법칙
위 식을 뒤집으면: $P(A, B) = P(A)\,P(B\mid A)$

사건이 3개, 4개로 늘어나도 계속 쪼갤 수 있습니다:
$$P(A, B, C) = P(A)\,P(B\mid A)\,P(C\mid A, B)$$

이것이 **연쇄법칙**입니다. 근사가 아니라 **항상 정확히 성립하는 등식**이에요.

### 1-4. 문장에 적용하기
"나는 밥을 먹었다"의 확률:
$$P(\text{나는, 밥을, 먹었다}) = P(\text{나는})\cdot P(\text{밥을}\mid\text{나는})\cdot P(\text{먹었다}\mid\text{나는, 밥을})$$

→ "다음 단어 맞히기"를 반복하면 문장 전체의 확률이 나옵니다. **오늘날의 LLM도 정확히 이 구조**입니다.

### 1-5. 논문의 식 (1)
$$p(y_1,\dots,y_{T'}\mid x_1,\dots,x_T) = \prod_{t=1}^{T'} p(y_t\mid v, y_1,\dots,y_{t-1})$$

| 기호 | 뜻 |
|---|---|
| $x_1..x_T$ | 입력 문장 (영어) 단어들, 길이 T |
| $y_1..y_{T'}$ | 출력 문장 (프랑스어) 단어들, 길이 T' ("T 프라임", T와 다른 길이라는 표시. 달라도 됨!) |
| $v$ | 인코더가 입력 문장을 압축한 벡터 |
| $\prod$ | 전부 곱하라 ([준비 5. Σ와 ∏ 읽기](#prep05)) |
| $p(y_t\mid v, y_1..y_{t-1})$ | 입력 의미 v와 지금까지 쓴 단어들이 주어졌을 때, t번째 단어의 확률 |

말로 읽으면: **"번역문 전체의 확률 = 각 단어를, (원문 의미 + 앞에 쓴 단어들)을 보고 맞힐 확률들의 곱."**

## 2. 예제 따라하기 (6분)

입력: "I am hungry" → 출력 후보: "배 고파 <EOS>"

모델이 이렇게 예측했다고 합시다.
- p(배 | v) = 0.6
- p(고파 | v, 배) = 0.9
- p(<EOS> | v, 배, 고파) = 0.8

**문장 확률** = 0.6 × 0.9 × 0.8 = **0.432**

`<EOS>`(End Of Sentence)도 하나의 "단어"로 예측합니다. 그래야 모델이 **언제 멈출지**도 배울 수 있어요. 논문 2장에도 "각 문장 끝에 <EOS>를 붙인다"고 나옵니다.

### 💻 코드: 표에서 확률 계산 + 연쇄법칙 확인
```python
import numpy as np

# 행: 코딩(좋아함, 안좋아함) / 열: 안경(O, X)
counts = np.array([[30, 10],
                   [20, 40]])
P = counts / counts.sum()          # 결합확률표
P_coding = P.sum(axis=1)           # 행 합 = P(코딩)
P_glasses = P.sum(axis=0)          # 열 합 = P(안경)

p_glasses_given_coding = P[0, 0] / P_coding[0]
print("P(안경|코딩) =", p_glasses_given_coding)

# 곱셈 규칙 확인: P(코딩, 안경) == P(코딩) * P(안경|코딩)
print(P[0, 0], "==", P_coding[0] * p_glasses_given_coding)

# 문장 확률
step_probs = [0.6, 0.9, 0.8]
print("문장 확률:", np.prod(step_probs))
```

**도전 과제 (선택: 시간이 남을 때만)**
- (a) `P(코딩 | 안경)`을 계산하는 줄을 직접 추가하세요.
- (b) `step_probs = [0.5] * 50`으로 바꿔 `np.prod`를 출력해 보세요. 그리고 `[0.5] * 2000`으로도 해 보세요. 무슨 일이 생기나요? (→ Day 05의 "로그"가 이걸 해결합니다.)
