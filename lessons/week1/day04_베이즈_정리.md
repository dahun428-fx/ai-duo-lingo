## 1. 개념 (8분)

### 1-1. 유도 (외우지 말고 만들어 내기)
곱셈 규칙은 두 방향으로 쓸 수 있습니다.
$$P(A, B) = P(A)\,P(B\mid A) = P(B)\,P(A\mid B)$$
오른쪽 두 개가 같으니 P(B)로 나누면:

$$\boxed{P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}}$$

### 1-2. 이름 붙이기
"A = 가설(원인), B = 관찰한 증거"라고 생각하세요.

| 항 | 이름 | 뜻 |
|---|---|---|
| P(A) | **사전확률 (prior)** | 증거를 보기 *전* 가설에 대한 믿음 |
| P(B \| A) | **가능도 (likelihood)** | 가설이 맞다면 이 증거가 나올 확률 |
| P(A \| B) | **사후확률 (posterior)** | 증거를 본 *후* 업데이트된 믿음 |
| P(B) | **증거 (evidence)** | 증거 자체가 나올 전체 확률 (정규화 상수) |

한 줄로: **사후 ∝ 가능도 × 사전** (∝는 "비례한다")

### 1-3. P(B) 구하기: 전체 확률의 법칙
$$P(B) = P(B\mid A)P(A) + P(B\mid \text{not }A)P(\text{not }A)$$
"B가 일어나는 모든 경로를 더한다."

### 1-4. argmax에서는 분모가 필요 없다
여러 가설 A₁, A₂, ... 중 가장 그럴듯한 것을 고를 때, 분모 P(B)는 모두에게 똑같습니다. 그래서
$$\arg\max_A P(A\mid B) = \arg\max_A P(B\mid A)\,P(A)$$
`argmax`는 "값이 가장 큰 *것*(값 자체가 아니라 그 후보)"을 돌려준다는 뜻입니다.

### 1-5. 번역 이야기: 옛날 방식 vs 이 논문 (선택)
- **옛날 통계 번역(SMT):** 영어 S를 프랑스어 T로 바꿀 때 베이즈 정리로 뒤집어서
  $\arg\max_T P(T\mid S) = \arg\max_T P(S\mid T)\cdot P(T)$
  "번역 모델 P(S|T)"와 "프랑스어다움을 재는 언어 모델 P(T)"를 따로 만들어 곱했습니다.
- **Seq2Seq (이 논문):** 뒤집지 않고 **P(T | S)를 신경망 하나로 직접** 학습합니다 (식 (1)). 그리고 3.2절에서 그대로 $\hat T = \arg\max_T p(T\mid S)$를 찾습니다.

베이즈 정리를 알면 "왜 이 논문이 새로웠는지"가 보입니다.

## 2. 예제 따라하기 (6분): 검사의 함정

- 어떤 병의 유병률: 1% → P(병) = 0.01
- 병이 있으면 양성 나올 확률: 90% → P(양성 | 병) = 0.9
- 병이 없어도 양성 나올 확률: 5% → P(양성 | 건강) = 0.05

**질문:** 양성이 나왔을 때 실제로 병일 확률은? (먼저 감으로 답을 적어 보세요!)

1. P(양성) = 0.9×0.01 + 0.05×0.99 = 0.009 + 0.0495 = 0.0585
2. P(병 | 양성) = 0.009 / 0.0585 ≈ **0.154 (약 15%)**

90%짜리 검사인데 15%밖에 안 됩니다! 이유: 사전확률(1%)이 너무 작아서, 건강한 99%에서 나오는 오탐이 진짜 양성보다 훨씬 많기 때문.

**🖐 그림으로 확인 (10,000명):** 병 100명 중 양성 90명 / 건강 9,900명 중 양성 495명 → 양성 585명 중 진짜 병은 90명 = 15.4%.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. 위 문제에서 유병률을 10%로 바꾸면 P(병 | 양성)은?
2. 같은 사람이 **두 번째 검사도 양성**이 나왔습니다 (병이 있는지 없는지가 정해지면 두 검사 결과는 서로 독립이라고 가정합니다. 이것을 조건부 독립이라고 부릅니다). 첫 검사 후 사후확률 0.154를 새 사전확률로 삼아 다시 계산하세요.
3. 번역 후보가 두 개 있습니다. 어느 쪽을 고르나요? (P(S)는 모름)
   - T₁: P(S|T₁) = 0.02, P(T₁) = 0.3
   - T₂: P(S|T₂) = 0.05, P(T₂) = 0.1

### 💻 코드: 시뮬레이션으로 베이즈 정리 검증
```python
import numpy as np
rng = np.random.default_rng(0)

N = 1_000_000
sick = rng.random(N) < 0.01                       # 1%가 병
pos = np.where(sick,
               rng.random(N) < 0.90,              # 병이면 90% 양성
               rng.random(N) < 0.05)              # 건강하면 5% 양성

print("시뮬레이션 P(병|양성):", sick[pos].mean())

def bayes(prior, p_pos_given_sick, p_pos_given_healthy):
    evidence = p_pos_given_sick * prior + p_pos_given_healthy * (1 - prior)
    return p_pos_given_sick * prior / evidence

print("공식 P(병|양성):    ", bayes(0.01, 0.9, 0.05))
```
