## 1. 개념 (8분)

### 1-1. 왜 소프트맥스가 필요한가
디코더의 마지막 층은 `z = W h + b`로 단어마다 점수 하나를 냅니다 (Day 02). 이 점수(**logit**)는 음수일 수도, 10일 수도 있어요. 확률로 쓰려면 두 조건을 맞춰야 합니다:
- 모두 0 이상
- 합이 1

### 1-2. 소프트맥스 공식
$$\text{softmax}(\mathbf z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$
1. `e^z`로 모두 양수로 만들고 (지수함수는 항상 양수)
2. 전체 합으로 나눠 합을 1로 만든다.

**직관:** 점수 차이를 "배율"로 바꿉니다. 점수가 1 크면 확률은 e ≈ 2.718배. 가장 큰 점수가 "부드럽게(soft)" 최대(max)를 차지해서 softmax.

### 1-3. 논문 규모로 보기
디코더 맨 위 은닉 벡터 h: (1000,) → W: (80000, 1000) → z: (80000,) → softmax → 80,000개 단어의 확률.
매 단어 위치마다 이걸 계산합니다. (그래서 논문은 계산을 GPU 여러 개에 나눴어요. 3.5절)

### 1-4. 로그 복습
$\log$는 "e를 몇 번 곱해야 이 수가 되나" (자연로그, ln). 핵심 성질:

| 성질 | 식 |
|---|---|
| 곱 → 합 | $\log(ab) = \log a + \log b$ |
| 나눗셈 → 뺄셈 | $\log(a/b) = \log a - \log b$ |
| 거듭제곱 → 곱 | $\log(a^k) = k\log a$ |
| 단조증가 | a > b 이면 log a > log b |
| 특수값 | log 1 = 0, 0<p<1 이면 log p < 0 |

### 1-5. 로그 확률로 underflow 해결
$$\log\prod_t p_t = \sum_t \log p_t$$
0.5를 2000번 곱하는 대신 log 0.5 ≈ −0.693을 2000번 더하면 −1386.3. 컴퓨터가 아주 편하게 다루는 숫자입니다.
그리고 log는 **단조증가**라 argmax 결과도 바뀌지 않아요. 그래서 논문의 학습 목표도 확률 대신 **로그 확률의 합** $\sum \log p(T\mid S)$로 씁니다.

### 1-6. 실전 팁: 최댓값 빼기
$e^{1000}$은 컴퓨터에서 무한대(overflow)가 됩니다. 모든 z에서 같은 값(보통 max)을 빼도 소프트맥스 결과는 같습니다 (분자·분모에 같은 $e^{-c}$가 곱해져 약분). 그래서 실제 구현은 `z - z.max()`부터 합니다.

## 2. 예제 따라하기 (6분)

어휘 3개 [고양이, 개, 차], logit `z = [2, 1, 0]`

1. e^z = [e², e¹, e⁰] ≈ [7.389, 2.718, 1.000]
2. 합 ≈ 11.107
3. softmax ≈ [7.389/11.107, 2.718/11.107, 1/11.107] ≈ **[0.665, 0.245, 0.090]**

확인: 합 = 1.000 ✓, 점수 순서 그대로 ✓

**최댓값 빼기 확인:** z − 2 = [0, −1, −2] → e^ = [1, 0.368, 0.135], 합 1.503 → [0.665, 0.245, 0.090]. 같습니다!

## 3. 능동 연습 (10분)

### ✏️ 손계산 (e ≈ 2.718, e² ≈ 7.389 사용)
1. z = [0, 0, 0]의 소프트맥스는? 이 결과의 의미는?
2. z = [1, 1, 3]의 소프트맥스를 구하세요. (힌트: 최댓값 빼면 [−2, −2, 0])
3. log(0.5) ≈ −0.693일 때, log(0.25)와 log(0.125)를 계산 없이 구하세요.
4. 단어 확률 0.6, 0.9, 0.8 (Day 03 예제)의 로그 확률 합을 구하세요. (log 0.6 ≈ −0.511, log 0.9 ≈ −0.105, log 0.8 ≈ −0.223) 그리고 e^(합)이 0.432인지 확인하세요.

### 💻 코드
```python
import numpy as np

def softmax(z):
    z = z - z.max()                # 최댓값 빼기 (안정성)
    e = np.exp(z)
    return e / e.sum()

z = np.array([2.0, 1.0, 0.0])
p = softmax(z)
print("softmax:", p.round(3), " 합:", p.sum())

# overflow 실험
big = np.array([1000.0, 999.0, 998.0])
print("안전한 softmax:", softmax(big).round(3))
print("순진한 방법:", np.exp(big) / np.exp(big).sum())   # 경고와 nan이 나옵니다

# 로그로 underflow 피하기
probs = np.full(2000, 0.5)
print("곱:", np.prod(probs), "  로그 합:", np.log(probs).sum())
```

**도전 과제 (선택: 시간이 남을 때만)**
- (a) **온도(temperature)**: `softmax(z / T)`를 T = 0.5, 1, 2, 10으로 계산해 보세요. T가 커지면/작아지면 분포가 어떻게 바뀌나요? (ChatGPT·Claude 같은 챗봇의 "temperature" 설정이 바로 이것)
- (b) 논문 규모 흉내: `h = np.random.randn(1000)`, `W = np.random.randn(80000, 1000) * 0.01`로 `softmax(W @ h)`를 만들고 shape, 합, 가장 확률이 큰 단어 번호(`argmax`)를 출력하세요.
