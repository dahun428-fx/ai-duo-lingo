## 1. 논문 지도 (5분)

논문의 아이디어를 한 장 그림으로 먼저 봅니다. **노트에 그대로 따라 그리세요.**

```
입력 (영어, 뒤집어서 넣음)            출력 (프랑스어)
  "C B A"                              "W X Y Z <EOS>"

 C → [LSTM] → [LSTM] → [LSTM] ──v──▶ [LSTM] → [LSTM] → [LSTM] → [LSTM] → [LSTM]
     인코더 (읽기)              │      디코더 (쓰기)  ↓        ↓        ↓        ↓
                               │                    W        X        Y        Z    <EOS>
                     문장 전체를 담은 벡터 v
```

- **인코더**: 입력 문장을 한 단어씩 읽어서, 마지막에 문장 전체의 의미를 담은 벡터 `v` 하나를 만든다.
- **디코더**: `v`에서 출발해 출력 문장을 한 단어씩 만든다. 방금 만든 단어를 다음 칸의 입력으로 다시 넣는다.

여기서 질문: 컴퓨터는 "cat"이라는 글자를 어떻게 계산에 넣을까요? → **벡터로 바꿉니다.** 그게 오늘의 주제입니다.

## 2. 개념: 벡터 (8분)

### 2-1. 벡터는 숫자 목록이다
```
v = [2, 1]          ← 2차원 벡터
w = [0.3, -1.2, 0.8, ...] (1000개)  ← 논문의 단어 벡터는 1000차원
```

### 2-2. 벡터는 화살표이기도 하다
2차원 벡터 `[2, 1]`은 원점에서 오른쪽으로 2, 위로 1 가는 화살표입니다.
**중요한 직관:** 화살표의 *방향*이 비슷하면 비슷한 것.

### 2-3. 단어 임베딩 (word embedding)
단어마다 벡터 하나를 정해 두는 것을 **임베딩**이라고 합니다. 잘 학습되면 의미가 비슷한 단어는 비슷한 방향을 가리킵니다.

```
"고양이" → [0.9, 0.8]
"강아지" → [0.8, 0.9]
"자동차" → [-0.7, 0.2]
```
고양이와 강아지는 거의 같은 방향, 자동차는 딴 방향입니다.

### 2-4. 내적: "얼마나 같은 방향인가"
두 벡터의 같은 자리 숫자끼리 곱해서 모두 더합니다.

$$\mathbf{a}\cdot\mathbf{b} = a_1b_1 + a_2b_2 + \dots + a_nb_n$$

- 같은 방향 → 큰 양수
- 직각 → 0
- 반대 방향 → 음수

길이의 영향을 없애면 **코사인 유사도**가 됩니다.

$$\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|},\qquad \|\mathbf{a}\| = \sqrt{a_1^2 + \dots + a_n^2}$$

값은 −1(정반대) ~ 1(같은 방향) 사이입니다.

> 🧠 **왜 중요한가:** 신경망 안의 거의 모든 계산은 "입력 벡터와 가중치 벡터의 내적"입니다. 내적은 "이 입력이 내가 찾는 패턴과 얼마나 닮았나?"를 묻는 질문이에요.

## 3. 예제 따라하기 (6분)

`a = [0.9, 0.8]` (고양이), `b = [0.8, 0.9]` (강아지), `c = [-0.7, 0.2]` (자동차)

**① a·b** = 0.9×0.8 + 0.8×0.9 = 0.72 + 0.72 = **1.44**

**② a·c** = 0.9×(−0.7) + 0.8×0.2 = −0.63 + 0.16 = **−0.47**

**③ 코사인 유사도 cos(a, b)**
- ‖a‖ = √(0.81 + 0.64) = √1.45 ≈ 1.204
- ‖b‖ = √(0.64 + 0.81) = √1.45 ≈ 1.204
- cos = 1.44 / (1.204 × 1.204) = 1.44 / 1.45 ≈ **0.993** → 거의 같은 방향!

## 4. 능동 연습 (10분)

### ✏️ 손계산
1. `p = [1, 2, 3]`, `q = [4, -5, 6]`일 때 `p·q`를 구하세요.
2. `[3, 4]`의 길이(노름)는?
3. `[1, 0]`과 `[0, 1]`의 내적은? 이 결과가 그림에서 의미하는 것은?
4. `[1, 2]`와 같은 방향이면서 길이가 정확히 1인 벡터를 구하세요. (힌트: 길이로 나누기)

### 💻 코드 (직접 타이핑하고 실행)
```python
import numpy as np

words = {
    "고양이": np.array([0.9, 0.8]),
    "강아지": np.array([0.8, 0.9]),
    "자동차": np.array([-0.7, 0.2]),
}

def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))   # @ 는 내적

for w1 in words:
    for w2 in words:
        if w1 < w2:
            print(f"{w1} vs {w2}: {cosine(words[w1], words[w2]):.3f}")
```

**도전 과제**
- (a) `"트럭"` 벡터를 직접 만들어 넣으세요. 자동차와는 코사인 0.9 이상, 고양이와는 0 이하가 되도록 숫자를 골라 보세요.
- (b) `words["고양이"] * 10`처럼 벡터 길이만 키우면 코사인 유사도는 변할까요? 먼저 예측하고 실행해서 확인하세요.
