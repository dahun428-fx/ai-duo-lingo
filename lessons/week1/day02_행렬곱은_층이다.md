## 1. 개념 (8분)

### 1-1. 행렬 = 벡터를 여러 줄 쌓은 것
```
W = [[1, 0, 2],     ← 1행: 패턴 탐지기 1
     [0, 3, 1]]     ← 2행: 패턴 탐지기 2
```
이 행렬의 shape은 **(2, 3)** = 2행 3열.

### 1-2. 행렬 × 벡터 = 행마다 내적
`x = [1, 2, 3]`일 때
```
Wx = [ 1·1 + 0·2 + 2·3 ,     = [7,
       0·1 + 3·2 + 1·3 ]        9]
```
**직관:** W의 각 행은 "나는 이런 패턴을 찾는다"는 탐지기입니다. 입력 x와 각 탐지기의 내적(닮음 정도)을 계산해 결과 벡터에 줄줄이 적습니다.

### 1-3. shape 규칙 (가장 중요!)
```
 W   ×   x   =   y
(m,n)  (n,)    (m,)
   └─ 같아야 함 ─┘
```
- 안쪽 숫자(n)가 같아야 곱할 수 있다.
- 결과는 바깥 숫자(m) 크기가 된다.
- 즉 **행렬은 n차원 벡터를 m차원 벡터로 바꾸는 기계**.

### 1-4. 신경망의 한 층
$$\mathbf{y} = f(W\mathbf{x} + \mathbf{b})$$
- `W`: 가중치 행렬 (학습되는 값)
- `b`: 편향 벡터 (학습되는 값, 결과를 살짝 밀어줌)
- `f`: 비선형 함수 (예: tanh, sigmoid). 이게 없으면 층을 아무리 쌓아도 행렬 하나와 같아집니다.

파라미터 개수 = `m×n` (W) + `m` (b)

### 1-5. 임베딩 조회 = 원-핫 × 행렬
어휘가 `[나, 너, 밥]` 3개, 임베딩이 2차원이라면 임베딩 행렬 E는 (2, 3):
```
E = [[0.1, 0.5, -0.3],
     [0.7, -0.2, 0.4]]
       나    너    밥
```
"너"는 원-핫 벡터 `[0, 1, 0]`. 그러면 `E @ [0,1,0]` = E의 2번째 **열** = `[0.5, -0.2]`.
→ 실제로는 곱셈 대신 그 열을 "꺼내기"만 합니다. 그래서 160,000단어 어휘도 빠르게 처리할 수 있어요.

## 2. 예제 따라하기 (6분)

**문제:** 입력 3차원, 출력 2차원인 층. `W = [[1, -1, 0], [2, 0, 1]]`, `b = [0.5, -1]`, `x = [3, 1, 2]`. `f = ReLU` (음수면 0, 양수면 그대로).

1. `Wx` = [1·3 + (−1)·1 + 0·2, 2·3 + 0·1 + 1·2] = [2, 8]
2. `Wx + b` = [2.5, 7]
3. `ReLU` → **[2.5, 7]** (둘 다 양수라 그대로)
4. 파라미터 수 = 2×3 + 2 = **8개**

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. `A = [[2, 1], [0, -1], [1, 1]]`, `x = [3, 4]`일 때 `Ax`를 구하세요. 결과 shape은?
2. (5, 7) 행렬 × (7,) 벡터의 결과 shape은? (5, 7) × (5,)는 가능한가요?
3. 논문 규모 계산: 입력 어휘 160,000개, 임베딩 1000차원. 입력 임베딩 행렬의 파라미터는 몇 개? (단위: 백만)
4. 1000차원 입력을 받아 1000차원을 내는 층 하나(W와 b)의 파라미터 수는?

### 💻 코드
```python
import numpy as np

W = np.array([[1, -1, 0],
              [2,  0, 1]])
b = np.array([0.5, -1])
x = np.array([3, 1, 2])

def relu(z):
    return np.maximum(0, z)

y = relu(W @ x + b)
print("W shape:", W.shape, " x shape:", x.shape, " y:", y, " y shape:", y.shape)

# 임베딩 조회 = 원-핫 곱셈
E = np.array([[0.1, 0.5, -0.3],
              [0.7, -0.2, 0.4]])
vocab = ["나", "너", "밥"]
onehot = np.zeros(3); onehot[vocab.index("너")] = 1
print("원-핫 곱:", E @ onehot, "  열 꺼내기:", E[:, 1])
```

**도전 과제**
- (a) `x`를 `np.array([3, 1])`로 바꾸면 어떤 에러가 나나요? 에러 메시지에서 shape 숫자를 찾아 읽어 보세요.
- (b) 2층 신경망 만들기: `W2` (shape (1, 2))를 직접 정해서 `relu(W2 @ y)`를 계산하세요. 전체 흐름의 shape을 `(3,) → (2,) → (1,)`로 적어 보세요.
- (c) 비선형 함수 없이 두 층을 쌓으면 `W2 @ (W @ x)` = `(W2 @ W) @ x`임을 코드로 확인하세요. 왜 비선형 함수가 꼭 필요한지 한 문장으로 적어 보세요.

## 📝 한 줄 정리
> "LSTM의 모든 계산은 `Wx + b`이고, shape만 맞춰 읽으면 논문의 수식이 두렵지 않다."

**손계산**
1. [2·3+1·4, 0·3+(−1)·4, 1·3+1·4] = **[10, −4, 7]**, shape (3,)

**코드 도전**
- (a) `ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0 ... (size 2 is different from 3)` 같은 메시지. 안쪽 숫자가 맞지 않는다는 뜻.
- (b) 예: `W2 = np.array([[1, -0.5]])` → `relu(2.5 − 3.5) = relu(−1) = [0]`
- (c) 선형 층을 몇 개 쌓아도 행렬 하나(W2@W)로 합쳐지므로, 비선형 함수가 없으면 깊게 쌓는 의미가 사라진다.

**퀴즈**
1. n차원 → m차원
2. W의 해당 행과 입력 벡터 x
3. 원-핫 벡터는 한 자리만 1이라, 곱하면 그 자리에 해당하는 열만 남는다.
4. 여러 층이 결국 하나의 선형 변환으로 합쳐져서 복잡한 패턴을 배울 수 없다.
5. 4층, 층마다 1000개 셀
