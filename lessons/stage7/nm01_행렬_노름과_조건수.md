## 1. 개념 (8분)

### 1-1. 노름: 크기를 재는 자
**노름**은 벡터나 행렬의 "크기"를 숫자 하나로 재는 방법입니다. 자가 여러 종류 있습니다.

| 이름 | 계산 | [3, −4]의 값 | 비유 |
|---|---|---|---|
| L2 노름 $\|x\|_2$ | 제곱해서 더하고 √ | 5 | 직선 거리 |
| L1 노름 $\|x\|_1$ | 절댓값을 더함 | 7 | 바둑판 길로 걷는 거리 |
| L∞ 노름 $\|x\|_\infty$ | 절댓값 중 가장 큰 것 | 4 | 가로, 세로 중 더 멀리 간 쪽 |

절댓값은 부호를 뗀 크기입니다. −4의 절댓값은 4입니다. ∞는 "무한대"라고 읽습니다. "L 무한대 노름"이라고 부르면 됩니다.

지금까지 "길이"라고 부른 것이 L2 노름입니다. [기울기 자르기](#gv01)가 쟀던 것, 가중치 감쇠가 벌점을 주는 것도 L2 노름(의 제곱)입니다.

### 1-2. 행렬의 크기 ①: 프로베니우스 노름
행렬의 숫자를 한 줄로 늘어놓고 L2 노름을 구한 것입니다.

$$\|A\|_F = \sqrt{\text{모든 칸의 제곱의 합}}$$

놀라운 사실: 이 값은 **특이값들의 제곱의 합의 제곱근**과 같습니다. [SVD](#svd01)의 저랭크 근사에서 "가장 가깝다"를 잴 때 쓰는 자가 이것입니다.

### 1-3. 행렬의 크기 ②: 스펙트럼 노름
행렬을 변환으로 볼 때 **벡터를 최대 몇 배까지 늘이는가**입니다.

$$\|A\|_2 = \text{가장 큰 특이값 } \sigma_{\max}$$

"이 층을 지나면 신호가 최대 몇 배 커질 수 있나"를 알려 줍니다. 층마다 이 값이 1보다 작으면 신호가 반드시 줄어들어 소실 쪽으로 가고, 1보다 크면 [폭발](#gv01)할 수 있습니다.

### 1-4. 조건수: 가장 많이 늘이는 방향 ÷ 가장 적게 늘이는 방향
$$\kappa(A) = \frac{\sigma_{\max}}{\sigma_{\min}}$$

κ(카파)가 1이면 모든 방향을 똑같이 늘이는 반듯한 변환. κ가 크면 한 방향은 크게, 다른 방향은 거의 안 늘이는 **찌그러진** 변환입니다.

조건수가 크면 생기는 일
- **작은 오차가 크게 번집니다.** 조금 다른 입력이 크게 다른 답을 냅니다. 흐릿한 사진을 확대하면 잡티가 같이 커지는 것과 같습니다
- **경사하강이 느립니다.** 손실의 그릇이 길쭉한 골짜기가 됩니다

### 1-5. 길쭉한 골짜기에서 걷기
손실이 $L = \frac{1}{2}(100\, w_1^2 + w_2^2)$라고 합시다. [헤시안](#sp01)의 고유값이 100과 1, 조건수 100입니다.

- 가파른 방향 $w_1$: 기울기가 $100 w_1$입니다. 한 걸음 가면 $w_1$은 (1 − 100 × 학습률)배가 됩니다. 학습률이 0.01이면 0배라서 한 걸음에 바닥에 닿습니다. 0.02이면 −1배라서 반대편 같은 높이로 건너뛰기만 합니다. 0.02를 넘으면 걸을수록 더 멀어집니다. 그네를 너무 세게 미는 것과 같습니다. 그래서 한계가 2 ÷ 100 = 0.02입니다
- 그래서 학습률을 0.01로 잡습니다. 완만한 방향 $w_2$는 기울기가 $w_2$입니다. 한 걸음 가면 $w_2 - 0.01 \times w_2 = 0.99\, w_2$입니다. 한 걸음에 **1%**만 줄어듭니다

완만한 쪽에서 100걸음을 걸어도 $0.99^{100} \approx 0.37$. 아직 37%가 남습니다. **필요한 걸음 수가 조건수에 비례**합니다.

[Adam](#opt01)이 방향마다 보폭을 따로 맞추고, [정규화](#norm01)가 층의 입력 크기를 고르게 하는 것은 모두 이 조건수를 낮추려는 노력입니다.

## 2. 예제 따라하기 (6분)

**벡터 노름.** x = [1, −2, 2]
- L1: 1 + 2 + 2 = **5**
- L2: √(1 + 4 + 4) = √9 = **3**
- L∞: **2**

**행렬 노름.** A = [[3, 0], [0, 1]] (대각선에만 숫자가 있는 행렬입니다. 가로로 3배, 세로로 1배 늘이므로 특이값은 3과 1입니다)
- 프로베니우스: √(9 + 0 + 0 + 1) = √10 ≈ **3.16**. 특이값으로도 √(3² + 1²) = √10 ✓
- 스펙트럼: 가장 큰 특이값 **3**
- 조건수: 3 ÷ 1 = **3**

**조건수가 큰 경우.** B = [[1, 0], [0, 0.001]] → κ = 1 ÷ 0.001 = **1000**

B는 첫째 칸은 그대로 두고 둘째 칸에 0.001을 곱하는 행렬입니다. 이제 거꾸로 묻습니다. B x = [1, 0.001]이 되는 x는 무엇일까요? 첫째 칸은 그대로 1입니다. 둘째 칸은 0.001 ÷ 0.001 = 1입니다. 그래서 x = [1, 1]입니다. 그런데 오른쪽이 측정 오차로 [1, 0.002]가 되면 x = [1, 2]입니다. (둘째 칸이 0.002 ÷ 0.001 = 2가 되기 때문입니다.) 둘째 칸의 **0.001짜리 오차가 답을 1만큼(1000배)** 바꿨습니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. x = [−6, 8]의 L1, L2, L∞ 노름은?
2. [[1, 2], [2, 4]]의 프로베니우스 노름은?
3. 특이값이 5와 2인 행렬의 스펙트럼 노름과 조건수는?
4. [[4, 0], [0, 4]]의 조건수는? 어떤 변환인가요?
5. 조건수가 10인 그릇과 1000인 그릇. 경사하강이 더 오래 걸리는 쪽은? 대략 몇 배?
6. $L = \frac{1}{2}(100 w_1^2 + w_2^2)$에서 학습률 0.01일 때, $w_2 = 1$에서 한 걸음 후의 $w_2$는? (기울기는 $w_2$)

### 🧩 미니 챌린지
가중치 감쇠에 L2 대신 **L1 노름**을 쓰면 가중치 중 많은 수가 정확히 0이 됩니다. [1, 0]과 [0.7, 0.7]은 L2 노름이 거의 같은데(1과 0.99), L1 노름은 각각 얼마인가요? L1 벌점은 어느 쪽을 더 좋아할까요?

### 💻 코드 (선택)
```python
import numpy as np
x = np.array([3.0, -4.0])
print(np.linalg.norm(x, 1), np.linalg.norm(x), np.linalg.norm(x, np.inf))   # 7.0 5.0 4.0

A = np.array([[3.0, 0.0], [0.0, 1.0]])
print(np.linalg.norm(A, 'fro').round(2), np.linalg.norm(A, 2), np.linalg.cond(A))   # 3.16 3.0 3.0

w = np.array([1.0, 1.0])                  # 길쭉한 골짜기에서 100걸음
for step in range(100):
    w = w - 0.01 * np.array([100 * w[0], w[1]])
print(w.round(3))                         # [0.    0.366]  가파른 쪽은 끝났는데 완만한 쪽은 37% 남음
```
