## 1. 개념 (8분)

### 1-1. 대칭 행렬은 특별하다
**대칭 행렬**은 대각선을 따라 접으면 마주 보는 숫자가 같은 행렬입니다. [[2, 1], [1, 2]]처럼요. 기호로는 $A^\top = A$ (⊤는 행과 열을 맞바꾼다는 표시).

AI에서 중요한 행렬은 대칭인 것이 많습니다.
- 공분산 행렬 (데이터가 어느 방향으로 얼마나 퍼졌는지 적은 표입니다. [PCA](#svd01)에서 "가장 넓게 퍼진 방향"을 찾을 때 쓰는 행렬의 이름입니다)
- 헤시안 (기울기가 얼마나 빨리 변하는지를 적은 표입니다. "기울기의 기울기"라고 생각하면 됩니다. 손실 함수가 방향마다 얼마나 휘었는지 알려 줍니다. 오늘은 계산하지 않고 이름만 씁니다)
- $A^\top A$ 꼴 (어떤 A로든 만들 수 있음)

### 1-2. 스펙트럼 정리
**정리.** 실수로 된 대칭 행렬은
1. 고유값이 모두 **실수**(수직선 위에 찍을 수 있는 보통 수)이고
2. 서로 **직교하는** 고유벡터들로 [기저](#vs01)를 만들 수 있다.

식으로는 $A = Q \Lambda Q^\top$. Q는 길이 1인 고유벡터들을 세로로 세운 행렬(돌리기), Λ(람다 대문자)는 고유값을 대각선에 둔 행렬(늘이기)입니다.

복습의 [[2, 1], [1, 2]]로 확인해 봅시다. 고유벡터 [1, 1]과 [1, −1]의 내적은 1 − 1 = 0입니다. 정말 직교합니다. 이 행렬은 [1, 1] 방향으로 3배, [1, −1] 방향으로 1배 늘입니다. 고무판을 서로 직각인 두 방향으로 잡아당기는 것과 같습니다.

[SVD](#svd01)의 "돌리기 → 늘이기 → 돌리기"에서 **앞뒤 돌리기가 같은 축**인 경우입니다. (고유값이 음수이면 특이값은 그 절댓값이고, 그 축은 방향이 뒤집힙니다.) 일반 행렬은 고유벡터가 비스듬하거나 없을 수 있지만, 대칭 행렬은 **언제나 반듯한 직교 축**이 나옵니다.

### 1-3. 이차형식: 행렬로 만든 그릇
벡터 x를 넣으면 숫자 하나가 나오는 식입니다.

$$x^\top A x$$

계산은 두 걸음입니다. 먼저 Ax를 구합니다. 그다음 그 결과와 x를 내적합니다. 예를 들어 A = [[2, 1], [1, 2]], x = [1, 1]이면 Ax = [3, 3]입니다. x와 내적하면 1 × 3 + 1 × 3 = 6입니다. 이 두 걸음을 글자로 한 번에 정리한 것이 아래 공식입니다.

2×2에서 A = [[a, b], [b, d]], x = [$x_1$, $x_2$]이면

$$x^\top A x = a x_1^2 + 2b\, x_1 x_2 + d\, x_2^2$$

[기울기를 숫자로 느끼기](#dx01)의 U자 함수 $w^2$를 여러 변수로 넓힌 것입니다. 손실 함수는 바닥 근처에서 이 모양으로 보입니다.

### 1-4. 양의 정부호: 어느 쪽으로 가도 오르막
**정의.** 영벡터가 아닌 모든 x에 대해 $x^\top A x > 0$이면 A를 **양의 정부호**라고 한다.

원점에서 어느 방향으로 가도 값이 커지는 **그릇 모양**이라는 뜻입니다.

**정리.** 대칭 행렬 A가 양의 정부호 ⇔ A의 **고유값이 모두 양수**. (⇔는 "양쪽이 같은 말"이라는 뜻)

왜 그럴까요? 고유벡터 방향 v(길이 1)를 넣어 봅니다. 고유벡터의 정의로 Av = λv입니다. 그래서 $v^\top A v = v^\top (\lambda v) = \lambda\,(v^\top v)$입니다. $v^\top v$는 v와 v의 내적, 곧 길이의 제곱이라 1입니다. 결국 값은 λ입니다. 그 방향의 휘어짐이 고유값입니다. 모든 축에서 위로 휘어 있으면 그릇입니다.

| 고유값 | 이름 | 모양 |
|---|---|---|
| 모두 양수 | 양의 정부호 | 그릇 (바닥이 하나) |
| 모두 0 이상 | 양의 준정부호 | 그릇인데 평평한 골이 있을 수 있음 |
| 양수와 음수가 섞임 | 부정부호 | **안장** (한쪽은 오르막, 한쪽은 내리막) |

### 1-5. 딥러닝에서
- 기울기가 0인 곳이 **바닥인지 안장인지**는 헤시안의 고유값 부호로 가립니다. 차원이 높은 신경망에서는 안장이 아주 많습니다
- (선택) $A^\top A$는 항상 양의 준정부호입니다. $x^\top A^\top A x$는 Ax를 자기 자신과 내적한 것, 곧 Ax의 길이의 제곱입니다. 길이의 제곱은 음수가 될 수 없습니다
- (선택) A의 [특이값](#svd01)은 $A^\top A$의 고유값의 제곱근입니다. 지금은 "SVD와 고유값이 이어져 있다"만 알면 충분합니다

## 2. 예제 따라하기 (6분)

**A = [[2, 1], [1, 2]]** (고유값 3, 1)

이차형식: $2x_1^2 + 2x_1x_2 + 2x_2^2$

| x | 계산 | 값 |
|---|---|---|
| [1, 0] | 2 + 0 + 0 | 2 |
| [1, 1] | 2 + 2 + 2 | 6 |
| [1, −1] | 2 − 2 + 2 | 2 |

모두 양수. 고유값이 3, 1로 모두 양수이니 **양의 정부호**(그릇)입니다.

고유벡터 방향 확인: [1, 1]은 길이의 제곱이 2. 값 6 = 고유값 3 × 2 ✓. [1, −1]도 2 = 고유값 1 × 2 ✓.

**B = [[1, 2], [2, 1]]**

고유값: 합 2, 곱 1 − 4 = −3 → **3과 −1**. 음수가 섞여 있으니 양의 정부호가 **아닙니다.**

이차형식: $x_1^2 + 4x_1x_2 + x_2^2$
- x = [1, 1]: 1 + 4 + 1 = 6 (오르막)
- x = [1, −1]: 1 − 4 + 1 = **−2** (내리막)

안장입니다. 말안장처럼 앞뒤로는 올라가고 좌우로는 내려갑니다.

### 🧩 미니 챌린지
기울기가 0인 지점에서 헤시안의 고유값이 [5, 0.01]입니다. 바닥인가요? 경사하강으로 이 그릇을 내려갈 때 어떤 어려움이 있을까요? (다음 레슨의 예고입니다.)

### 💻 코드 (선택)
```python
import numpy as np
A = np.array([[2.0, 1.0], [1.0, 2.0]])
vals, Q = np.linalg.eigh(A)                  # 대칭 행렬용. 작은 고유값부터
print(vals)                                   # [1. 3.]
print((Q @ np.diag(vals) @ Q.T).round(6))     # [[2. 1.] [1. 2.]]  A = QΛQᵀ
print((Q.T @ Q).round(6))                     # [[1. 0.] [0. 1.]]  고유벡터가 서로 직교

x = np.array([1.0, -1.0])
B = np.array([[1.0, 2.0], [2.0, 1.0]])
print(x @ A @ x, x @ B @ x)                   # 2.0 -2.0
```
