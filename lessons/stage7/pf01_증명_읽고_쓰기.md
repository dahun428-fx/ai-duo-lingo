## 1. 개념 (8분)

### 1-1. 왜 증명인가
지금까지는 "예를 계산해 보니 맞더라"로 배웠습니다. 하지만 예 100개가 맞아도 101번째가 틀릴 수 있습니다. **증명**은 "모든 경우에 맞다"를 한 번에 보장하는 글입니다.

증명은 어려운 계산이 아닙니다. **변호사의 변론**과 같습니다. 이미 인정된 사실만 써서, 한 줄씩, 빈틈없이 결론까지 가는 것입니다.

### 1-2. 수학 글의 세 가지 문단
| 이름 | 뜻 | 예 |
|---|---|---|
| **정의** | 낱말의 약속. 맞고 틀림이 없다 | "2로 나누어떨어지는 정수를 짝수라 한다" |
| **정리** | 참이라고 주장하는 문장 | "짝수 둘을 더하면 짝수다" |
| **증명** | 그 주장이 왜 참인지 | 아래 2절 |

읽다가 막히면 대개 **정의를 잊어서**입니다. 증명을 읽는 첫 요령은 낱말이 나올 때마다 정의로 **바꿔 써 보는 것**입니다.

### 1-3. 기호 세 개
| 기호 | 읽기 | 예 |
|---|---|---|
| ∀ | "모든 ~에 대해" | ∀x: 모든 x에 대해 |
| ∃ | "~가 (하나 이상) 있다" | ∃x: 어떤 x가 있어서 |
| P ⇒ Q | "P이면 Q이다" | 비가 오면 ⇒ 땅이 젖는다 |

"P ⇒ Q"가 참이어도 **거꾸로 "Q ⇒ P"는 참이 아닐 수 있습니다.** 땅이 젖었다고 꼭 비가 온 것은 아니죠.

### 1-4. 증명의 세 가지 방법
**① 곧바로 보이기 (직접 증명).** 가정에서 출발해 정의와 계산으로 결론까지 간다. 가장 흔합니다.

**② 모순으로 보이기 (귀류법).** "결론이 틀렸다고 해 보자"에서 출발해 말이 안 되는 상황에 닿으면, 결론이 맞는 것이다. 알리바이와 같습니다. "이 사람이 범인이라고 해 보자. 그러면 그 시각에 현장에 있었어야 한다. 그런데 그때 다른 도시에 있었다. 말이 안 된다. 따라서 범인이 아니다."

**③ 반례 들기.** "모든 ~는 ~이다"가 **틀렸음**을 보이려면 안 맞는 예 **하나**면 충분합니다. "모든 백조는 희다"는 검은 백조 한 마리로 무너집니다.

> 맞음을 보이려면 모든 경우를 덮어야 하고(증명), 틀림을 보이려면 하나면 됩니다(반례). 이 비대칭을 기억하세요.

### 1-5. 증명을 읽는 순서
1. 정리에서 **가정**(주어진 것)과 **결론**(보일 것)을 가른다
2. 낱말을 정의로 바꿔 쓴다
3. 한 줄씩 읽으며 "이 줄은 왜 되지?"에 답한다 (정의, 가정, 앞 줄, 계산 규칙 중 하나)
4. 작은 숫자 예로 확인해 본다

## 2. 예제 따라하기 (6분)

### 직접 증명
**정리.** 짝수 둘을 더하면 짝수다.

**증명.**
1. a, b가 짝수라고 하자. (가정)
2. 그러면 a = 2m, b = 2n인 정수 m, n이 있다. (짝수의 정의)
3. a + b = 2m + 2n = 2(m + n). (계산)
4. m + n은 정수이므로 a + b는 2로 나누어떨어진다. 즉 짝수다. (짝수의 정의) ∎

∎는 "증명 끝" 표시입니다. 예(4 + 6 = 10)를 든 것이 아니라 **모든** 짝수에 대해 보였습니다.

정수는 −2, −1, 0, 1, 2처럼 소수점이 없는 수입니다. 2번 줄의 "~인 정수가 있다"가 바로 ∃입니다. 기호로는 "∃m: a = 2m"이라고 씁니다. 정리 전체는 "모든 짝수 a, b에 대해"이므로 ∀가 숨어 있습니다.

### 선형대수 증명
**정리.** v가 A의 고유벡터이고 고유값이 λ이면, v는 $A^2$의 고유벡터이고 고유값은 $\lambda^2$이다.

**증명.**
1. $Av = \lambda v$. (고유벡터의 정의)
2. $A^2 v = A(Av) = A(\lambda v)$. (1을 대입)
3. $= \lambda (Av) = \lambda (\lambda v) = \lambda^2 v$. (숫자는 행렬 밖으로 꺼낼 수 있음, 다시 1을 대입) ∎

[고유값](#eg01)에서 "행렬을 여러 번 곱하면 고유값의 거듭제곱"이라고 했던 것의 증명입니다.

### 반례
**주장.** 모든 행렬 A, B에 대해 AB = BA이다. → **거짓.**

A = [[1, 1], [0, 1]], B = [[1, 0], [1, 1]]이면 AB = [[2, 1], [1, 1]], BA = [[1, 1], [1, 2]]. 다릅니다. 반례 하나로 끝.

### 🧩 미니 챌린지
"행렬 100개로 실험해 보니 모두 성립했다"는 왜 증명이 아닐까요? 반대로, 논문이 실험 결과만 싣고 증명 없이 주장할 때 우리는 그것을 어떻게 받아들여야 할까요?

### 💻 코드 (선택): 반례는 컴퓨터로 찾을 수 있다
```python
import numpy as np
A = np.array([[1, 1], [0, 1]])
B = np.array([[1, 0], [1, 1]])
print(A @ B)                 # [[2 1] [1 1]]
print(B @ A)                 # [[1 1] [1 2]]
print((A @ B == B @ A).all())   # False → "AB = BA"의 반례
```
