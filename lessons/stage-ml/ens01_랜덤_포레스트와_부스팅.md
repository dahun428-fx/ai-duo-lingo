## 1. 개념 (8분)

### 1-1. 왜 여럿이 더 정확할까
[결정 트리](#tree01)는 읽기 쉽지만, 데이터가 조금 바뀌면 나무 모양이 통째로 바뀌는 불안정한 모델이었습니다. 그렇다면 나무를 여러 그루 키워 **투표**시키면 어떨까요? 이렇게 모델 여럿을 합치는 것을 **앙상블**이라고 합니다.

정확도 60%인 투표자 3명이 **서로 상관없이** 답한다고 합시다. 다수결이 맞으려면 3명 중 2명 이상이 맞으면 됩니다.

- 3명 다 맞음: 0.6 × 0.6 × 0.6 = 0.216
- 딱 2명 맞음: 누가 틀리는지 3가지 × (0.6 × 0.6 × 0.4) = 3 × 0.144 = 0.432
- 합: **0.648**

혼자서는 60%인데 셋이 모이니 약 65%. 사람을 늘릴수록 더 오릅니다.

| 투표자 수 | 1 | 3 | 5 | 11 | 101 |
|---|---|---|---|---|---|
| 다수결 정확도 | 0.60 | 0.65 | 0.68 | 0.75 | 0.98 |

**단, 조건이 둘 있습니다.**
1. 각자 **동전 던지기(50%)보다는 나아야** 합니다. 40%짜리를 모으면 오히려 나빠집니다
2. 서로 **다른 실수**를 해야 합니다. 셋이 한 사람 답을 베끼면 셋이든 백이든 60% 그대로입니다

Seq2Seq 논문에서 LSTM 하나(입력 뒤집기, 빔 12)는 BLEU 30.59였는데, 따로 학습한 5개를 합치자 34.81이 되었습니다. 시작 가중치와 데이터 순서가 달라 서로 다른 실수를 했기 때문입니다. [중심극한정리](#day09)에서 본 "평균을 내면 흔들림이 줄어든다"와 비슷한 원리입니다.

### 1-2. 배깅: 서로 다른 문제집으로 공부시키기
데이터가 하나뿐인데 어떻게 "서로 다른" 나무를 만들까요? **부트스트랩**을 씁니다. 데이터 n개에서 **하나 뽑고 다시 넣기를 n번** 반복해 새 데이터 묶음을 만듭니다. 어떤 데이터는 두세 번 뽑히고, 어떤 데이터는 한 번도 안 뽑힙니다(평균 약 37%가 빠집니다). 묶음마다 나무를 하나씩 키우고 다수결로 답합니다.

이것이 **배깅**(Bagging, Breiman 1996)입니다. 같은 교과서에서 문제를 무작위로 골라 만든 문제집을 학생마다 따로 주고 공부시킨 뒤, 시험에서 다수결로 답을 정하는 것과 같습니다.

### 1-3. 랜덤 포레스트: 질문 후보까지 무작위로
배깅만으로는 나무들이 여전히 닮습니다. 아주 강한 특징이 하나 있으면 모든 나무가 그 질문으로 시작하기 때문입니다. **랜덤 포레스트**(Breiman 2001)는 한 가지를 더 합니다. 질문을 고를 때마다 **특징 몇 개만 무작위로 뽑아 그중에서** 고르게 합니다. 그러면 나무들이 서로 다른 길로 자라 "다른 실수" 조건을 더 잘 지킵니다.

나무 하나하나는 깊게 키워 [과적합](#of01)되어도 괜찮습니다. 따로따로 흔들리는 나무들이 투표에서 서로를 상쇄하기 때문입니다.

### 1-4. 부스팅: 앞 주자가 놓친 만큼 이어 달리기
배깅이 여럿을 **나란히** 세운다면, 부스팅은 **한 줄로** 세웁니다. 이어달리기와 같습니다.

1. 첫 주자(작은 나무)가 대충 예측합니다
2. 정답과의 차이, 곧 **잔차**(남은 오차)를 계산합니다
3. 다음 주자는 정답이 아니라 **그 잔차를 맞히도록** 학습합니다. 앞 주자가 못 간 거리를 이어 달리는 것입니다
4. 최종 예측 = 모든 주자의 예측을 **더한** 값

주자마다 예측에 [학습률](#dx01)(예: 0.1)을 곱해 조금씩만 더합니다. 한 주자가 다 해결하려 들지 않게 해서 과적합을 막습니다. 잔차를 줄이는 방향이 제곱 오차의 [경사하강](#day08) 방향과 같아서 Friedman은 이것을 **그래디언트 부스팅**이라고 불렀습니다.

### 1-5. 둘을 나란히
| | 배깅 · 랜덤 포레스트 | 부스팅 |
|---|---|---|
| 줄 서는 법 | 나란히 (동시에 학습 가능) | 한 줄로 (차례대로) |
| 나무 | 깊은 나무 여러 그루 | 얕은 나무 여러 그루 |
| 주로 줄이는 것 | 흔들림 = [분산](#of01) (나무마다 다른 실수) | 덜 배운 부분 = [편향](#of01) (남은 오차) |
| 합치는 법 | 다수결 · 평균 | 더하기 |
| 조심할 점 | 나무를 늘려도 과적합이 잘 안 됨 | 주자를 너무 많이 두면 과적합 |

부스팅을 빠르고 튼튼하게 다듬은 **XGBoost**(2016)는 논문에 따르면 2015년 Kaggle(데이터 분석 대회 사이트) 블로그에 소개된 대회 우승 해법 29개 중 17개에 쓰였습니다. 엑셀 같은 **표 데이터**에서는 지금도 딥러닝보다 먼저 시도하는 경우가 많습니다.

## 2. 예제 따라하기 (6분)

**부스팅 두 바퀴.** 집 세 채의 가격(억 원)을 맞힙니다. 학습률은 계산을 쉽게 하려고 1로 둡니다.

| 집 | 크기 | 실제 가격 |
|---|---|---|
| ㄱ | 작음 | 3 |
| ㄴ | 작음 | 5 |
| ㄷ | 큼 | 10 |

**1번 주자:** 아무 질문 없이 평균을 말합니다. (3 + 5 + 10) ÷ 3 = **6**
- 잔차 = 실제 − 예측 = [3 − 6, 5 − 6, 10 − 6] = **[−3, −1, 4]**
- 제곱 오차의 합: 9 + 1 + 16 = **26**

**2번 주자:** "큰 집인가?" 질문 하나짜리 나무로 **잔차**를 맞힙니다. 잎마다 잔차의 평균을 답합니다.
- 작은 집(ㄱ, ㄴ): (−3 + (−1)) ÷ 2 = **−2**
- 큰 집(ㄷ): **4**

**합친 예측:** [6 − 2, 6 − 2, 6 + 4] = **[4, 4, 10]**
- 새 잔차: [3 − 4, 5 − 4, 10 − 10] = **[−1, 1, 0]**
- 제곱 오차의 합: 1 + 1 + 0 = **2**

두 번째 주자가 26을 2로 줄였습니다. ㄱ과 ㄴ은 크기가 같아서 이 특징만으로는 더 가를 수 없습니다. 다른 특징(예: 역에서의 거리)이 있다면 3번 주자가 남은 [−1, 1]을 이어받습니다.

## 3. 능동 연습 (10분)

아래 실습 위젯의 "투표단" 탭에서 투표자 수와 "서로 베끼기" 정도를 바꿔 보고, "부스팅" 탭에서 주자를 한 명씩 추가하며 잔차가 줄어드는 모습을 보세요.

### ✏️ 손계산

3. 정확도 60%인 3명이 언제나 한 사람의 답을 그대로 베낀다면 다수결 정확도는?
4. 집값 [10, 20, 60](ㄱ, ㄴ 작음 / ㄷ 큼)을 예제처럼 두 바퀴 돌리세요. 1번 주자의 예측과 잔차, 2번 주자 뒤의 예측과 잔차는?
5. 4번에서 학습률을 0.1로 하면, 2번 주자 뒤 집 ㄱ의 예측은?
6. Seq2Seq 논문에서 LSTM 5개 앙상블은 하나일 때보다 BLEU가 몇 점 올랐나요? (30.59 → 34.81)

### 🧩 미니 챌린지
랜덤 포레스트에서 나무 100그루를 1000그루로 늘리는 것과, 부스팅에서 주자 100명을 1000명으로 늘리는 것. 어느 쪽이 과적합 위험이 더 클까요? 이유는?

### 💻 코드 (선택)
```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

X, y = load_breast_cancer(return_X_y=True)        # 유방암 진단 표 데이터 569개
for name, m in [("나무 한 그루", DecisionTreeClassifier(random_state=0)),
                ("랜덤 포레스트", RandomForestClassifier(n_estimators=200, random_state=0)),
                ("부스팅", GradientBoostingClassifier(random_state=0))]:
    print(name, cross_val_score(m, X, y, cv=5).mean().round(3))   # 5겹 교차 검증 정확도
# 나무 한 그루 0.917 / 랜덤 포레스트 0.96 / 부스팅 0.963 정도 (버전에 따라 조금 다름)
```

## 📝 한 줄 정리
랜덤 포레스트는 서로 다른 데이터와 질문 후보로 키운 나무들을 나란히 세워 투표시키고, 부스팅은 앞 나무가 놓친 잔차를 다음 나무가 이어받아 차례로 더해 나간다.
