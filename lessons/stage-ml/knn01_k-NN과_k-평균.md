## 1. 개념 (8분)

### 1-1. 거리: 두 점을 잇는 화살표의 길이
[Day 01](#day01)에서 벡터의 길이를 피타고라스로 구했습니다. 두 점 사이의 거리도 똑같습니다. 한 점에서 다른 점으로 가는 화살표를 만들고, 그 길이를 잽니다.

$$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

(1, 1)에서 (4, 5)까지: 가로 3, 세로 4 → √(9 + 16) = **5**.

**요령:** "누가 더 가까운가"만 알면 될 때는 제곱근을 씌우기 전의 값(**거리의 제곱**)끼리 비교해도 순위가 같습니다. 오늘은 계산을 줄이려고 이 요령을 씁니다.

### 1-2. k-NN: 가장 가까운 이웃 k명에게 묻기
이사 온 동네에서 어느 야구팀을 응원할지 모르겠다면? 가장 가까이 사는 이웃 3명에게 물어서 **많이 나온 팀**을 따라가면 됩니다.

**k-NN**(k-최근접 이웃, k-Nearest Neighbors)이 정확히 이것입니다.
1. 새 점과 모든 데이터 점 사이의 거리를 잰다
2. 가장 가까운 **k개**를 고른다
3. 그 k개의 이름표로 **다수결**

특이하게도 "학습"이 없습니다. 데이터를 **외워 두기만** 하고, 물어볼 때마다 거리를 잽니다. 그래서 데이터가 많으면 예측이 느립니다.

**k는 어떻게 고를까?**
- k = 1: 바로 옆 한 명만 봅니다. 그 한 명이 별난 사람이면 그대로 따라 틀립니다. 데이터의 잡음까지 외우는 [과적합](#of01)입니다
- k가 너무 크면: 멀리 사는 사람까지 투표해서 동네 특색이 사라집니다
- 그래서 k는 [검증 세트](#split01)로 고르고, 두 팀일 때는 동점을 피하려고 **홀수**를 씁니다

### 1-3. 지도 학습과 비지도 학습
- **지도 학습**: 데이터마다 정답 이름표가 붙어 있음. k-NN, [로지스틱 회귀](#logi01)
- **비지도 학습**: 이름표가 없음. 데이터 안의 무리나 방향을 스스로 찾음. [PCA](#svd01), 그리고 오늘의 k-평균

### 1-4. k-평균: 깃발 옮기기
운동장에 학생들이 흩어져 있습니다. 반 이름표는 없습니다. 깃발 k개를 아무 데나 꽂고 이렇게 합니다.

1. **배정**: 학생마다 가장 가까운 깃발로 간다
2. **이동**: 깃발을 자기 무리의 **한가운데(평균 위치)**로 옮긴다
3. 1–2를 반복한다. 아무도 깃발을 바꾸지 않으면 끝

평균 위치는 좌표마다 평균을 낸 점입니다. (1, 2)와 (3, 4)의 평균은 (2, 3).

이것이 **k-평균**(k-means)입니다. 1957년 벨 연구소 내부 보고서로 처음 쓰였고, 1982년 Lloyd의 논문으로 출판되었습니다. 깃발을 처음에 어디 꽂느냐에 따라 결과가 달라질 수 있어서, 실제로는 여러 번 돌려 가장 좋은 결과를 씁니다.

> **같은 글자, 다른 뜻: k**
> k-NN의 k는 **투표할 이웃 수**, k-평균의 k는 **무리(깃발) 수**입니다. [교차 검증](#split01)의 "k겹"은 데이터를 나눈 조각 수였죠. 모두 "우리가 정하는 개수"라서 같은 글자를 씁니다.

### 1-5. 눈금 맞추기 (한 줄)
키(cm)와 시력처럼 단위가 다른 특징을 그대로 섞으면 숫자가 큰 키가 거리를 혼자 정합니다. 그래서 거리를 재기 전에 특징마다 [z 점수](#nd01)로 바꿔(평균을 빼고 표준편차로 나눠) 눈금을 맞춥니다. [정규화](#norm01)에서 키와 몸무게를 같은 자로 잰 것과 같은 요령입니다.

## 2. 예제 따라하기 (6분)

**k-NN.** 동네 지도에 이웃 6명이 삽니다. 새로 이사 온 집은 **(3, 3)**입니다.

| 이웃 | 위치 | 응원팀 | (3, 3)까지 거리의 제곱 |
|---|---|---|---|
| ㄱ | (4, 3) | 파랑 | 1² + 0² = **1** |
| ㄴ | (2, 4) | 빨강 | 1² + 1² = **2** |
| ㄷ | (1, 1) | 빨강 | 2² + 2² = **8** |
| ㄹ | (3, 0) | 빨강 | 0² + 3² = **9** |
| ㅁ | (6, 4) | 파랑 | 3² + 1² = **10** |
| ㅂ | (5, 6) | 파랑 | 2² + 3² = **13** |

- **k = 1**: 가장 가까운 ㄱ → **파랑**
- **k = 3**: ㄱ(파랑), ㄴ(빨강), ㄷ(빨강) → 2 대 1로 **빨강**

k 하나 바꿨더니 답이 뒤집혔습니다. k가 중요한 이유입니다.

**k-평균 (한 바퀴만).** 이름표 없는 점 6개, 깃발 2개입니다.

점: (1, 2), (2, 1), (3, 3), (6, 6), (7, 5), (8, 7) · 처음 깃발: ①(1, 3), ②(6, 0)

| 점 | ①까지 거리의 제곱 | ②까지 거리의 제곱 | 배정 |
|---|---|---|---|
| (1, 2) | 0 + 1 = 1 | 25 + 4 = 29 | ① |
| (2, 1) | 1 + 4 = 5 | 16 + 1 = 17 | ① |
| (3, 3) | 4 + 0 = 4 | 9 + 9 = 18 | ① |
| (6, 6) | 25 + 9 = 34 | 0 + 36 = 36 | ① |
| (7, 5) | 36 + 4 = 40 | 1 + 25 = 26 | ② |
| (8, 7) | 49 + 16 = 65 | 4 + 49 = 53 | ② |

**이동:**
- 깃발 ①: 점 4개의 평균 → x = (1 + 2 + 3 + 6) ÷ 4 = **3**, y = (2 + 1 + 3 + 6) ÷ 4 = **3** → (3, 3)
- 깃발 ②: 점 2개의 평균 → ((7 + 8) ÷ 2, (5 + 7) ÷ 2) = **(7.5, 6)**

(6, 6)은 깃발을 처음 엉뚱하게 꽂은 탓에 ①로 갔습니다. 한 바퀴 더 돌면 제자리를 찾을까요? 연습 4번에서 확인합니다.

## 3. 능동 연습 (10분)

아래 실습 위젯의 "k-NN" 탭에서 새 집 위치와 k를 바꿔 보고, "k-평균" 탭에서 배정·이동 버튼을 번갈아 눌러 깃발이 멈출 때까지 지켜보세요.

### ✏️ 손계산
1. (0, 0)과 (3, 4) 사이의 거리는?
2. (1, 2)와 (4, 6) 사이의 거리는?
3. 예제의 동네에 새 집 (5, 4)가 생겼습니다. k = 3이면 어느 팀일까요?
4. k-평균 예제의 두 번째 배정: 점 (6, 6)은 깃발 ①(3, 3)과 ②(7.5, 6) 중 어디로 가나요? 그다음 깃발들은 어디로 옮기나요?
5. 수직선 위의 점 1, 2, 3, 10, 11, 12와 깃발 0, 5. 배정과 이동을 한 번 하면 깃발은 어디로 가나요?

### 🧩 미니 챌린지
두 사람의 키 차이는 10cm, 시력 차이는 0.5입니다. 이대로 거리를 재면 어느 특징이 거리를 거의 다 정할까요? 어떻게 고칠까요?

### 💻 코드 (선택)
```python
from sklearn.neighbors import KNeighborsClassifier
from sklearn.cluster import KMeans

X = [[4, 3], [2, 4], [1, 1], [3, 0], [6, 4], [5, 6]]
y = ["파랑", "빨강", "빨강", "빨강", "파랑", "파랑"]
for k in [1, 3]:
    knn = KNeighborsClassifier(n_neighbors=k).fit(X, y)   # fit은 외워 두기만 함
    print(k, knn.predict([[3, 3]]))                       # 1 ['파랑'] / 3 ['빨강']

P = [[1, 2], [2, 1], [3, 3], [6, 6], [7, 5], [8, 7]]
km = KMeans(n_clusters=2, init=[[1, 3], [6, 0]], n_init=1).fit(P)
print(km.cluster_centers_)                                # [[2. 2.] [7. 6.]]
```

## 📝 한 줄 정리
k-NN은 이름표가 있는 가장 가까운 이웃 k명의 다수결로 답하고, k-평균은 이름표 없이 "가장 가까운 깃발로 배정 → 깃발을 무리 평균으로 이동"을 반복해 무리를 찾는다.

> 나중에 11단계 "RAG"에서 "질문 벡터와 가장 가까운 문서 k개"를 찾아 붙이는데, 그것이 바로 k-NN 검색입니다.

**퀴즈**

2. **X.** 반대입니다. 학습은 외우기만 해서 빠르고, 예측할 때마다 모든 점과의 거리를 재서 느립니다.
3. 투표가 동점이 되지 않게 하려고요.
4. 배정을 다시 해도 어떤 점도 깃발을 바꾸지 않을 때(깃발이 더 움직이지 않을 때)입니다.
