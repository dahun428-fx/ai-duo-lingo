## 1. 개념 (8분)

### 1-1. 단순 RNN은 왜 잊어버릴까
[Day 10](#day10)의 RNN은 단어를 하나 읽을 때마다 기억 h에 **곱셈**을 한 번씩 합니다. 문장 맨 앞 단어의 흔적은 뒤로 갈수록 그 곱셈을 계속 맞습니다.

귓속말 전달 게임을 떠올리세요. 한 사람 건널 때마다 소리가 10%씩 작아지면 50번째 사람에게는 거의 안 들립니다. 매 스텝 0.9가 곱해진다고 해 봅시다.

| 스텝 수 | 0.9를 곱한 결과 | 1.1을 곱한 결과 |
|---|---|---|
| 10 | 0.35 | 2.6 |
| 30 | 0.04 | 17 |
| 50 | **0.005** | **117** |

- 1보다 조금 작은 수: 50단어 뒤에는 0.5%만 남습니다. 학습할 때는 "틀렸다"는 신호(기울기)가 문장 끝에서 앞으로 거꾸로 전달되는데, 이 신호도 같은 곱셈을 스텝마다 맞아서 앞 단어에 닿을 즈음엔 거의 사라집니다 → **기울기 소실**. 그래서 앞 단어에 대해서는 못 배웁니다.
- 1보다 조금 큰 수: 117배로 부풉니다 → **기울기 폭발**.

[준비 4](#prep04)에서 작은 확률을 계속 곱하면 0이 되던 것과 같은 구조입니다.

### 1-2. LSTM의 생각: 곱하지 말고 더하자
LSTM(Long Short-Term Memory, 장단기 기억)은 기억 통로를 하나 더 둡니다.

- **셀 상태 c**: 장기 기억. 컨베이어 벨트처럼 문장 끝까지 흘러갑니다.
- **은닉 상태 h**: 지금 바깥에 내보이는 작업 기억.

그리고 c를 고칠 때 **"조금 지우고, 조금 더한다"**만 합니다. 지울지 말지를 정하는 값이 1에 가까우면 기억은 거의 그대로 다음 스텝으로 넘어갑니다. 0.9를 강제로 곱하던 RNN과 달리, **얼마나 남길지를 모델이 스스로 배웁니다.**

### 1-3. 게이트 = 0과 1 사이의 밸브
게이트는 시그모이드로 만든 0~1 사이 숫자입니다. 어떤 값에 곱해서 **얼마나 통과시킬지** 정합니다.

- 게이트 1 → 전부 통과 (값 × 1)
- 게이트 0 → 완전히 막음 (값 × 0)
- 게이트 0.5 → 절반만

| 게이트 | 기호 | 여닫는 것 | 비유 |
|---|---|---|---|
| 망각 (forget) | f | 옛 기억 c를 얼마나 **남길지** | 메모장 지우개 |
| 입력 (input) | i | 새 정보를 얼마나 **적을지** | 연필 |
| 출력 (output) | o | 기억을 얼마나 **내보일지** | 메모장을 보여 주는 손 |

> 이름 주의: 망각 게이트 f가 **1이면 기억을 지킨다**는 뜻입니다. "잊는 정도"가 아니라 "남기는 비율"이에요.

### 1-4. 한 스텝의 식
새로 적을 후보 값을 g라고 부릅니다 (tanh로 만들어 −1 ~ 1 사이).

$$c_t = f \cdot c_{t-1} + i \cdot g$$
$$h_t = o \cdot \tanh(c_t)$$

읽는 법
1. 옛 기억 $c_{t-1}$에 f를 곱해 **남길 만큼 남기고**
2. 새 후보 g에 i를 곱해 **적을 만큼 더합니다** → 새 기억 $c_t$
3. $c_t$를 tanh로 −1 ~ 1 사이로 누른 뒤 o를 곱해 **내보입니다** → $h_t$

게이트 값은 모델이 지금 단어와 직전 기억을 보고 스스로 계산합니다. 오늘은 그 값이 이미 주어졌다고 치고 계산만 연습합니다.

> 논문의 실제 크기: 한 층에 셀 1000개, 4층이니 문장 하나를 **8000개 숫자**(c와 h 각각 4000개)로 기억합니다. 칸마다 게이트가 따로 있어요.

> (선택) 더 알고 싶다면: 게이트는 [Day 02](#day02)의 `Wx + b`에 시그모이드를 씌워 만듭니다. 입력으로 지금 단어 $x_t$와 직전 $h_{t-1}$을 함께 넣습니다. 논문에서 칸끼리 곱하기는 기호 ⊙로 씁니다.

## 2. 예제 따라하기 (6분)

**문제.** 직전 기억 $c_{t-1} = 0.8$. 게이트와 후보가 다음과 같을 때 새 c와 h는?

| f (망각) | i (입력) | g (후보) | o (출력) |
|---|---|---|---|
| 0.9 | 0.5 | 0.6 | 0.7 |

**1) 남기기:** 0.9 × 0.8 = 0.72
**2) 더하기:** 0.5 × 0.6 = 0.30 → $c_t$ = 0.72 + 0.30 = **1.02**
**3) 내보이기:** tanh(1.02) ≈ 0.77 → $h_t$ = 0.7 × 0.77 ≈ **0.54**

옛 기억의 90%가 살아남았고, 새 정보가 절반 세기로 더해졌습니다.

**게이트는 어떻게 나올까?** 시그모이드에 넣는 값이 크면 열리고 작으면 닫힙니다.

| 넣는 값 z | −2 | 0 | 2 |
|---|---|---|---|
| σ(z) | 0.12 | 0.5 | 0.88 |

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. $c_{t-1} = 1.0$, f = 0.5, i = 1.0, g = −0.4일 때 $c_t$는?
2. 1번에서 o = 0.5이면 $h_t$는? (tanh(0.1) ≈ 0.1)
3. f = 1, i = 0이면 $c_t$는 $c_{t-1}$과 어떤 관계인가요?
4. f = 0, i = 1이면 $c_t$는?
5. 0.9를 10번 곱하면 약 0.35입니다. 0.99를 10번 곱하면 대략 얼마일까요? (0.90, 0.50, 0.10 중 고르기)
6. 망각 게이트가 **항상** 1이고 입력 게이트도 항상 열려 있으면 긴 글에서 어떤 문제가 생길까요?

### 🧩 미니 챌린지
문장 "나는 프랑스에서 자랐고 … (30단어) … 그래서 ___를 잘한다." 빈칸을 맞히려면 "프랑스"를 30단어 동안 기억해야 합니다. 그동안 f는 어떤 값이어야 할까요? 문장이 끝나고 새 문장이 시작되면?

### 💻 코드 (선택)
```python
import numpy as np
print(0.9 ** 50, 1.1 ** 50)            # 0.005...  117.39...

c_prev = 0.8
f, i, g, o = 0.9, 0.5, 0.6, 0.7
c = f * c_prev + i * g
h = o * np.tanh(c)
print(c, h)                            # 1.02  0.539...

c = 1.0                                # f = 1, i = 0이면 50스텝 뒤에도 그대로
for t in range(50):
    c = 1.0 * c + 0.0 * 0.3
print(c)                               # 1.0
```

## 📝 한 줄 정리
LSTM은 기억 c를 "f만큼 남기고 i만큼 새로 더하는" 방식으로 고쳐서, 긴 문장에서도 앞 단어를 잊지 않는다.

**손계산**
1. 0.5 × 1.0 + 1.0 × (−0.4) = 0.5 − 0.4 = **0.1**
2. 0.5 × tanh(0.1) ≈ 0.5 × 0.1 = **0.05**
3. **똑같습니다.** 1 × $c_{t-1}$ + 0 × g = $c_{t-1}$. 기억을 그대로 들고 갑니다.
4. $c_t$ = **g**. 옛 기억을 다 지우고 새 정보만 적습니다.
5. 약 **0.90**. 1에 가까울수록 훨씬 천천히 줄어듭니다.
6. 지우지 않고 계속 쌓기만 해서 c가 아주 커질 수 있고, 이미 끝난 문장의 내용이 새 문장에 섞입니다. 그래서 "잊는 능력"도 필요합니다.

**미니 챌린지**
30단어 동안은 "프랑스"를 담은 칸의 f가 **1 가까이**, 문장이 끝나면 **0 가까이**로 내려가 메모장을 비우는 것이 좋습니다. 이런 여닫기를 사람이 정해 주지 않고 학습으로 얻습니다.

**퀴즈**
1. 스텝마다 1보다 작은 수가 계속 곱해져 앞 단어의 신호(기울기)가 0에 가까워지기 때문입니다.
2. 거의 그대로 다음 스텝으로 넘어갑니다.
3. X. 게이트는 시그모이드라 **0과 1 사이**입니다. −1 ~ 1은 tanh(후보 g)입니다.
4. c는 오래 들고 가는 장기 기억, h는 그중 지금 내보이는 부분(다음 층과 예측에 쓰는 값)입니다.
