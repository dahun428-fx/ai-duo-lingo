## 1. 개념 (8분)

### 1-1. 번역을 어떻게 채점할까
번역 수만 문장을 사람이 일일이 채점할 수는 없습니다. 그래서 **사람이 미리 해 둔 번역(참조 번역)**과 기계 번역이 얼마나 겹치는지 자동으로 셉니다. 이 점수가 **BLEU**(블루, 2002년)입니다.

### 1-2. n-gram: 연속한 단어 n개
- **1-gram**: 단어 하나. "the cat sat" → the / cat / sat
- **2-gram**: 연속한 단어 둘. "the cat sat" → the cat / cat sat

단어 N개짜리 문장에는 1-gram이 N개, 2-gram이 N − 1개 있습니다. 1-gram은 **단어를 맞게 골랐는지**, 2-gram 이상은 **순서까지 자연스러운지**를 봅니다.

### 1-3. 정밀도: 내가 쓴 것 중 몇 개가 맞았나
$$\text{n-gram 정밀도} = \frac{\text{참조에도 있는 내 n-gram 수}}{\text{내 n-gram 전체 수}}$$

분모가 **기계 번역 쪽**이라는 점을 기억하세요.

### 1-4. 꼼수 막기 ①: 같은 단어 도배
참조가 "the cat is on the mat"인데 기계가 "the the the the"라고 하면? the는 참조에 있으니 4개 전부 맞은 걸로 치면 정밀도 100%가 됩니다.

그래서 **참조에 나온 횟수까지만** 인정합니다. the는 참조에 2번 → 2개만 인정 → 2/4 = 0.5. 이것을 **클리핑**(잘라 내기)이라고 합니다.

### 1-5. 꼼수 막기 ②: 너무 짧은 번역
기계가 "the cat"만 내놓으면 쓴 단어는 다 맞으니 정밀도 100%입니다. 하지만 번역의 절반 이상이 빠졌죠.

그래서 기계 번역 길이 c가 참조 길이 r보다 짧으면 **짧은 번역 벌점(BP)**을 곱합니다.

$$BP = \begin{cases} 1 & (c \ge r) \\ e^{\,1 - r/c} & (c < r) \end{cases}$$

읽는 법: 기계 번역이 참조만큼 길면 벌점 없음(× 1), 짧으면 짧을수록 많이 깎임.

| 기계 번역 길이 | 참조의 80% | 50% | 33% |
|---|---|---|---|
| 곱하는 값 BP | 0.78 | 0.37 | 0.14 |

c = 2, r = 6이면 $e^{1-3} = e^{-2} \approx 0.14$. 점수가 14%로 깎입니다.

### 1-6. 합치기
$$\text{BLEU} = BP \times (\text{정밀도들의 기하평균})$$

**기하평균**은 n개를 곱해서 n제곱근을 구하는 평균입니다. 둘이면 $\sqrt{p_1 \times p_2}$. 하나라도 0이면 전체가 0이 되어, **모든 항목을 고루 잘해야** 점수가 나옵니다.

표준 BLEU는 1~4-gram 네 개를 씁니다(BLEU-4). 오늘은 손계산을 위해 1~2-gram만 쓰는 **BLEU-2**로 연습합니다. 값은 0~1이고, 논문은 100을 곱해 0~100으로 적습니다.

> 로그로 쓰면: 기하평균 = $\exp\left(\frac{1}{n}\sum \ln p_k\right)$. 로그를 평균 내고 exp로 되돌린 것입니다. Day 08의 perplexity와 같은 모양이에요.

## 2. 예제 따라하기 (6분)

- 참조: **the cat sat on the mat** (6단어)
- 기계: **the cat is on the mat** (6단어)

**1-gram 정밀도**

| 기계의 단어 | the | cat | is | on | the | mat |
|---|---|---|---|---|---|---|
| 참조에 있나 | ✓ | ✓ | ✗ | ✓ | ✓ | ✓ |

the는 참조에도 2번 나오니 둘 다 인정. → **5/6**

**2-gram 정밀도**

| 기계의 2-gram | the cat | cat is | is on | on the | the mat |
|---|---|---|---|---|---|
| 참조에 있나 | ✓ | ✗ | ✗ | ✓ | ✓ |

→ **3/5**

**기하평균:** $\frac{5}{6} \times \frac{3}{5} = \frac{15}{30} = 0.5$, $\sqrt{0.5} \approx 0.707$

**벌점:** 길이가 6으로 같으니 BP = 1

**BLEU-2 ≈ 0.707** (100점 척도로 70.7)

단어 하나(is)만 틀렸는데 2-gram은 두 개가 깨졌습니다. BLEU는 순서와 이웃 단어까지 봅니다.

## 3. 능동 연습 (10분)

참조: **a dog runs very fast** (5단어) · 기계: **a dog runs fast** (4단어)

### ✏️ 손계산
1. 기계 번역의 1-gram 정밀도는?
2. 기계 번역의 2-gram을 모두 적고, 2-gram 정밀도를 구하세요.
3. 두 정밀도의 기하평균은? (√0.667 ≈ 0.816)
4. 짧은 번역 벌점 BP는? ($e^{-0.25} \approx 0.78$)
5. BLEU-2는?
6. 참조가 "I like cats"이고 기계가 "cats cats cats"일 때, 클리핑을 적용한 1-gram 정밀도는?

### 🧩 미니 챌린지
참조 "나는 매우 기쁘다", 기계 "저는 정말 행복합니다". 뜻은 같은데 BLEU는 몇 점일까요? 이것이 BLEU의 어떤 약점을 보여 주나요?

### 📊 논문의 성적표 읽기
| 시스템 | BLEU |
|---|---|
| 기존 통계 번역기 (기준선) | 33.30 |
| LSTM 5개 앙상블, 빔 12 | **34.81** |
| 기존 번역기의 후보 1000개를 LSTM으로 다시 채점 | 36.5 |
| 당시 WMT'14 최고 기록 | 37.0 |

신경망 하나의 구조만으로 수십 년 다듬은 통계 번역기를 처음 넘었다는 것이 이 논문의 뉴스였습니다.

### 💻 코드 (선택)
```python
import math
from collections import Counter

def precision(cand, ref, n):
    c = Counter(tuple(cand[i:i+n]) for i in range(len(cand) - n + 1))
    r = Counter(tuple(ref[i:i+n]) for i in range(len(ref) - n + 1))
    hit = sum(min(cnt, r[g]) for g, cnt in c.items())    # 클리핑
    return hit / sum(c.values())

def bleu2(cand, ref):
    p1, p2 = precision(cand, ref, 1), precision(cand, ref, 2)
    bp = 1 if len(cand) >= len(ref) else math.exp(1 - len(ref) / len(cand))
    return bp * math.sqrt(p1 * p2)

print(bleu2("the cat is on the mat".split(), "the cat sat on the mat".split()))  # 0.707...
print(bleu2("a dog runs fast".split(), "a dog runs very fast".split()))          # 0.635...
```

## 📝 한 줄 정리
BLEU = (참조와 겹치는 n-gram 정밀도의 기하평균) × (짧은 번역 벌점). 높을수록 사람 번역에 가깝다.

2. 같은 단어를 여러 번 써서 정밀도를 부풀리는 것
3. X. 벌점은 **짧을 때만** 받습니다. 길게 쓴 번역은 정밀도의 분모가 커져서 자연히 손해를 봅니다.
