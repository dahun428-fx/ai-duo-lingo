## 1. 개념 (8분)

### 1-1. 지도가 없다면?
[벨만 방정식](#bel01)에서는 "어디로 가면 무슨 일이 생기는지"(전이 확률과 보상)를 **다 안다**고 치고, 목표에서부터 거꾸로 값을 채웠습니다. 지도를 펴 놓고 길을 찾은 셈입니다.

하지만 처음 하는 게임에는 지도가 없습니다. 직접 해 보고, 결과를 보고, 고쳐 가야 합니다. 이렇게 규칙을 모르는 채로 **경험만으로** 배우는 것을 **모델 없는 학습**이라고 부릅니다. Q러닝이 대표 선수입니다.

### 1-2. TD: 하루 뒤의 더 나은 추측으로 고치기
날씨 예보관을 떠올려 보세요. 금요일에 "일요일 비 올 확률 70%"라고 했습니다. 토요일이 되니 먹구름이 몰려와 "90%"로 고칩니다. 일요일까지 기다리지 않고, **하루 뒤의 더 나은 추측**으로 어제의 추측을 고친 것입니다.

Q러닝도 같습니다. 상태 s에서 행동 a를 하고, 보상 r을 받고, 다음 상태 s′에 왔습니다. 이제 한 걸음 더 아는 상태에서 다시 추측합니다.

- **TD 목표** = r + γ × (s′에서 가장 큰 Q) — "방금 받은 보상 + 다음 칸에서 기대하는 최선"
- **TD 오차** = TD 목표 − 지금의 Q(s, a) — **예상보다 얼마나 좋았나**

TD는 Temporal Difference(시간 차이)의 줄임말입니다. "지금의 추측"과 "한 걸음 뒤의 추측"의 차이라는 뜻입니다. TD 목표는 [벨만 최적 방정식](#bel01)의 오른쪽을 **실제로 겪은 한 번**으로 바꿔 넣은 것입니다.

### 1-3. Q러닝 갱신식
$$Q(s,a) \leftarrow Q(s,a) + \alpha \times \text{TD 오차}$$

← 는 "오른쪽 값으로 바꿔 넣어라"라는 뜻입니다. α(알파)는 **학습률**, 한 번에 얼마나 고칠지입니다. [경사하강](#day08)의 η와 같은 역할이고, 0과 1 사이에서 고릅니다.

이 모양, 어디서 봤죠? [슬롯머신](#mab01)의 고치기 공식 "새 평균 = 옛 평균 + (새 결과 − 옛 평균) ÷ 횟수"입니다. "새 결과" 자리에 TD 목표가, "÷ 횟수" 자리에 α가 들어갔을 뿐입니다.

| 고치기 공식 | 옛 값 | 새로 본 값 | 얼마나 고칠까 |
|---|---|---|---|
| 슬롯머신 평균 | 옛 평균 | 이번 결과 | 1 ÷ 횟수 |
| Q러닝 | 옛 Q(s, a) | TD 목표 | α |

### 1-4. 움직일 때는 ε-탐욕
행동은 [슬롯머신](#mab01)에서 배운 **ε-탐욕**으로 고릅니다. 대부분은 Q가 가장 큰 행동, ε의 확률로는 아무 행동이나. 그래야 아직 안 가 본 길도 알게 됩니다.

재미있는 점: 움직일 때는 가끔 엉뚱하게 가도, TD 목표에는 **늘 max(최선)**를 씁니다. 그래서 탐험하며 돌아다니면서도 "최선으로 움직였다면"의 Q를 배웁니다. 이런 성질을 **off-policy**라고 합니다. 남이 둔 기보로도 바둑을 배울 수 있는 것과 같습니다.

### 1-5. DQN: 표를 신경망으로 (말로 3분)
Q표의 칸 수는 **상태 수 × 행동 수**입니다. 아래 실습 위젯의 복도는 4 × 2 = 8칸이면 됩니다. 그런데 게임 화면 한 장이 상태라면? 픽셀 조합은 셀 수 없이 많아 표를 만들 수 없습니다.

그래서 2015년 DQN(Deep Q-Network)은 **표 대신 신경망**에 화면을 넣고 행동마다 Q를 내게 했습니다. 갱신식은 그대로, TD 오차를 줄이도록 [경사하강](#day08)으로 가중치를 고칩니다. 그런데 그냥 하면 학습이 자꾸 무너집니다. 그래서 두 장치를 더했습니다.

1. **경험 재생.** 겪은 일(s, a, r, s′)을 커다란 노트에 적어 두고, 학습할 때는 **무작위로 섞어 꺼내** 씁니다. 오답노트를 순서 없이 섞어 다시 푸는 것과 같습니다. 방금 겪은 비슷한 장면만 연달아 배우면 한쪽으로 쏠리기 때문입니다. 한 경험을 여러 번 쓰니 아끼는 효과도 있습니다.
2. **타깃 네트워크.** TD 목표를 계산하는 신경망을 **사본으로 떼어 잠시 얼려** 둡니다. 정해진 걸음마다 한 번씩만 최신 값으로 바꿉니다. 과녁이 화살을 쏠 때마다 움직이면 맞히기 어려우니, 과녁을 잠깐 고정하는 것입니다.

결과: Atari 게임 **49개**를 **같은 신경망 구조, 같은 설정**으로, 화면 픽셀과 점수만 보고 학습했습니다. 많은 게임에서 사람 전문 테스터에 맞먹는 점수를 냈습니다. (2013년의 첫 DQN 논문은 7개 게임으로 실험했습니다. 49개는 2015년 Nature 논문의 숫자입니다.)

## 2. 예제 따라하기 (6분)

쓸 값: γ = 0.9, α = 0.5

**한 칸 고치기.** 지금 Q(s, a) = 2. 행동을 했더니 보상 r = 1을 받고, 다음 상태에서 가장 큰 Q가 10입니다.

1. TD 목표 = 1 + 0.9 × 10 = 1 + 9 = **10**
2. TD 오차 = 10 − 2 = **8** (예상보다 8만큼 좋았다)
3. 새 Q = 2 + 0.5 × 8 = **6**

목표인 10까지 한 번에 가지 않고 절반(α = 0.5)만 갔습니다. 한 번의 경험은 운일 수도 있으니까요.

**값이 거꾸로 번지는 모습.** 복도 끝 보물 칸에 들어가면 보상 10. 모든 Q는 0에서 시작합니다. 보물 바로 앞 칸을 C, 그 앞을 B라고 합시다.

| | Q(B, →) | Q(C, →) |
|---|---|---|
| 처음 | 0 | 0 |
| 1판 뒤 | 0 + 0.5 × (0 + 0.9 × 0 − 0) = **0** | 0 + 0.5 × (10 − 0) = **5** |
| 2판 뒤 | 0 + 0.5 × (0 + 0.9 × 5 − 0) = **2.25** | 5 + 0.5 × (10 − 5) = **7.5** |

(보물 칸은 끝이라 그 뒤의 Q는 0으로 칩니다.) 1판째엔 보물 바로 앞만 알게 되고, 2판째에 그 소식이 한 칸 뒤로 번집니다. [벨만](#bel01)에서 거꾸로 채우던 일을, 지도 없이 **여러 판에 걸쳐 조금씩** 하는 셈입니다.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 로봇이 한 걸음 갈 때마다 Q표 한 칸이 바뀝니다. 식의 각 부분 색을 따라가 보세요. ε을 0으로 두면 어떻게 되는지도 보세요.

쓸 값: γ = 0.9 (5번만 γ = 0.5)

### ✏️ 손계산
1. Q = 3, r = 2, 다음 상태의 최대 Q = 10, α = 0.5. TD 목표, TD 오차, 새 Q는?
2. Q = 4, r = 1, 다음 상태의 최대 Q = 5, α = 0.1. 새 Q는?
3. Q = 6, r = 0, 다음 상태가 끝(그 뒤 Q는 0), α = 0.5. 새 Q는? TD 오차의 부호는 무슨 뜻일까요?
4. α = 1이면 새 Q는 무엇과 같아지나요? α = 0이면?
5. Q = 5, r = 0, γ = 0.5, 다음 상태의 최대 Q = 4. TD 오차는?
6. ε = 0.1, 행동 4개. 무작위로 고를 때도 최고 행동이 뽑힐 수 있다면, 최고 행동을 고를 확률은?

### 🧩 미니 챌린지
게임 화면을 1초에 30장씩 본다면, 연달아 들어오는 장면들은 거의 똑같습니다. 이 순서 그대로 신경망을 학습시키면 어떤 문제가 생길까요? 경험 재생이 이를 어떻게 막나요?

### 💻 코드 (선택)
```python
gamma, alpha = 0.9, 0.5
def q_update(q, r, max_next, alpha=alpha, gamma=gamma):
    target = r + gamma * max_next
    td_error = target - q
    return q + alpha * td_error, target, td_error

print(q_update(2, 1, 10))       # (6.0, 10.0, 8.0)

QB, QC = 0.0, 0.0               # 복도: B → C → 보물(+10)
for ep in range(1, 4):
    QB = q_update(QB, 0, QC)[0]
    QC = q_update(QC, 10, 0)[0]
    print(ep, round(QB, 3), round(QC, 3))
# 1 0.0 5.0
# 2 2.25 7.5
# 3 4.5 8.75
```

## 📝 한 줄 정리
Q러닝은 "보상 + γ × 다음 칸의 최선"(TD 목표)과 지금 Q의 차이(TD 오차)에 α를 곱해 Q표 한 칸을 고친다. DQN은 그 표를 신경망으로 바꾸고 경험 재생과 타깃 네트워크로 안정시켰다.
