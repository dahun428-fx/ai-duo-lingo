## 1. 개념 (8분)

### 1-1. 슬롯머신 세 대, 당첨 확률은 비밀
카지노에 슬롯머신 A, B, C가 있습니다. 기계마다 당첨 확률이 다르지만 **겉으로는 알 수 없습니다**. 손잡이를 100번 당길 수 있다면, 어떻게 당겨야 점수를 가장 많이 받을까요?

이 문제를 **멀티암드 밴딧**(multi-armed bandit)이라고 부릅니다. 슬롯머신의 별명이 "외팔이 강도(one-armed bandit)"라서, 팔이 여러 개인 강도라는 농담 같은 이름이 붙었습니다.

이 문제가 **강화학습의 첫 질문**인 이유가 있습니다. 강화학습은 정답을 알려 주는 선생님 없이, **해 보고 받은 점수(보상)**만으로 배웁니다. 그런데 해 보지 않은 것은 점수를 알 수 없습니다. 그래서 늘 이 고민이 따라옵니다.

### 1-2. 탐색과 활용: 점심 메뉴 고민
회사 근처 식당으로 생각해 봅시다.

- **활용**(exploitation): 지금까지 가 본 집 중 **제일 맛있었던 단골집**에 간다. 실패는 적지만, 길 건너 더 맛있는 집을 영영 모를 수 있습니다.
- **탐색**(exploration): **안 가 본 집**에 가 본다. 맛없을 수도 있지만, 더 좋은 집을 찾을 기회입니다.

활용만 하면 처음에 운 좋았던 집에 **갇히고**, 탐색만 하면 맛없는 날이 너무 많습니다. 둘 사이의 균형을 잡는 것이 **탐색과 활용의 딜레마**입니다.

### 1-3. 기계의 실력은 "지금까지의 평균"으로 짐작
당첨 확률은 비밀이지만, 당겨 본 결과의 **평균**으로 짐작할 수 있습니다. 당첨 1점, 꽝 0점이라고 합시다.

| 기계 | 지금까지 결과 | 당긴 횟수 | 평균 |
|---|---|---|---|
| A | 0, 1, 0, 0 | 4 | 0.25 |
| B | 1, 0 | 2 | 0.5 |
| C | 0 | 1 | 0 |

여러 번 당길수록 평균은 진짜 당첨 확률에 가까워집니다. 하지만 C는 겨우 한 번 당겨 봤을 뿐입니다. **C가 정말 나쁜 기계인지, 운이 없었던 건지 아직 모릅니다.**

### 1-4. 고치기 공식: 평균을 한 줄로 고치기
새 결과가 올 때마다 처음부터 다 더할 필요는 없습니다.

$$\text{새 평균} = \text{옛 평균} + \frac{\text{새 결과} - \text{옛 평균}}{\text{횟수}}$$

읽는 법: "예상(옛 평균)과 실제(새 결과)의 **차이**만큼, 횟수로 나눈 만큼만 고친다." 횟수는 새 결과까지 센 수입니다.

B를 세 번째로 당겨 1점을 받았다면 새 평균 = 0.5 + (1 − 0.5) ÷ 3 = 0.5 + 0.17 ≈ **0.67**. 직접 더해도 (1 + 0 + 1) ÷ 3 ≈ 0.67로 같습니다.

이 "예상과 실제의 차이만큼 조금 고치기"는 앞으로 계속 나옵니다. 나중에 배울 Q러닝의 핵심 식도 이 모양입니다. 오늘 이름을 붙여 두세요: **고치기 공식**.

### 1-5. ε-탐욕: 열 번에 한 번은 새 집
가장 간단하고 지금도 널리 쓰이는 방법입니다. ε(엡실론)은 작은 확률 하나입니다. 예를 들어 ε = 0.1.

1. 확률 **1 − ε** (0.9)로: 평균이 가장 높은 기계를 고른다 (활용, "탐욕"이라고 부름)
2. 확률 **ε** (0.1)로: 기계 셋 중 **아무거나** 똑같은 확률로 고른다 (탐색)

주의할 점이 있습니다. 2번의 "아무거나"에는 **최고 기계도 들어 있습니다**. 그래서 기계가 3대일 때

- 최고 기계가 뽑힐 확률 = 0.9 + 0.1 × 1/3 = 0.9 + 0.033 ≈ **0.93**
- 나머지 기계 하나하나가 뽑힐 확률 = 0.1 × 1/3 ≈ **0.033**

세 확률을 더하면 0.933 + 0.033 + 0.033 = 1이 됩니다. "90%는 최고, 10%는 나머지"가 아니라는 점을 기억하세요.

> (선택) ε-탐욕은 탐색할 때 정말 아무거나 고릅니다. 더 똑똑한 방법으로 **UCB**가 있습니다. "아직 덜 당겨 본 기계에 덤 점수를 얹어 주는" 방법입니다. 이름과 생각만 알아 두면 충분합니다.

## 2. 예제 따라하기 (6분)

쓸 값: 1/3 ≈ 0.33, 0.1/3 ≈ 0.033, 0.75 ÷ 5 = 0.15

**① 평균 고치기.** A의 평균이 0.25(4번)입니다. 다섯 번째에 1점이 나왔습니다.
- 새 평균 = 0.25 + (1 − 0.25) ÷ 5 = 0.25 + 0.15 = **0.4**
- 확인: 결과는 0, 1, 0, 0, 1 → 2 ÷ 5 = 0.4 ✓

**② 지금 누가 최고?** 표를 고치면 A 0.4, B 0.67, C 0. 활용이라면 **B**를 고릅니다.

**③ ε-탐욕 확률.** ε = 0.1, 기계 3대.
- B(지금 최고): 0.9 + 0.033 ≈ **0.93**
- A, C: 각각 **0.033**

**④ ε = 0만 쓰면?** C는 한 번 꽝이 나왔을 뿐인데 평균이 0이라 다시는 뽑히지 않습니다. 만약 C가 사실 당첨 확률 0.8짜리 기계였다면, 가장 좋은 기계를 영영 놓칩니다. 이것이 "갇히기"입니다.

Sutton과 Barto의 교재 실험(기계 10대짜리 밴딧 문제 2000개)에서도, 탐색 없이 평균만 따른 방법은 약 3분의 1의 문제에서만 최고 기계를 찾았습니다. ε = 0.1이나 0.01로 조금씩 탐색한 방법이 길게 보면 더 많이 땄습니다.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 먼저 **내가 직접** 30번 당겨 보고, 그다음 ε 로봇과 비교해 보세요. 숨은 확률은 0.2, 0.5, 0.8이 기계마다 섞여 들어가 있습니다. 로봇 실험에서 ε = 0일 때 "최고 기계를 절반도 못 쓴 판"이 몇 %나 되는지 꼭 보세요.

쓸 값: 1/3 ≈ 0.33, 1/4 = 0.25, 1/5 = 0.2

### ✏️ 손계산
1. 기계 D를 4번 당겨 평균이 0.5입니다. 다섯 번째에 1점을 받았습니다. 새 평균은?
2. 1번에서 다섯 번째가 0점이었다면 새 평균은?
3. ε = 0.2, 기계가 4대일 때 지금 최고 기계가 뽑힐 확률은? 다른 기계 하나는?
4. ε = 0.3, 기계 3대일 때 최고 기계가 뽑힐 확률은?
5. ε = 0이면 무엇이 문제인가요? ε = 1이면?
6. 진짜 당첨 확률이 0.2, 0.5, 0.8이고, 로봇이 최고 기계(0.8)를 이미 알아냈습니다. ε = 0.1로 한 번 당길 때 점수의 기댓값은? (힌트: 0.9 확률로 0.8짜리, 0.1 확률로 셋의 평균 0.5짜리)

### 🧩 미니 챌린지
유튜브 같은 추천 서비스가 "이 사람이 좋아할 게 확실한 영상"만 계속 보여 주면 어떤 문제가 생길까요? 탐색과 활용으로 설명해 보세요.

### 💻 코드 (선택)
```python
import random
true_p = [0.2, 0.5, 0.8]            # 숨은 당첨 확률
n, avg = [0, 0, 0], [0.0, 0.0, 0.0]  # 당긴 횟수, 평균
eps = 0.1
for t in range(1000):
    if random.random() < eps:
        a = random.randrange(3)                # 탐색: 아무거나
    else:
        a = avg.index(max(avg))                # 활용: 평균이 최고인 기계
    r = 1 if random.random() < true_p[a] else 0
    n[a] += 1
    avg[a] += (r - avg[a]) / n[a]              # 고치기 공식
print(n, [round(x, 2) for x in avg])           # 대부분 세 번째 기계를 당김
```

## 📝 한 줄 정리

**미니 챌린지**
활용만 하면 이미 좋아한 종류의 영상만 계속 나와서, 그 사람이 좋아할 수도 있는 새 주제를 영영 알아낼 수 없습니다. 그래서 추천 시스템은 가끔 새 영상을 섞어 반응을 봅니다(탐색). Li 외(2010)는 야후 뉴스 첫 화면의 기사 추천을 바로 이런 밴딧 문제로 풀었습니다.

2. (새 결과 − 옛 평균)을 횟수로 나눈 만큼. 예상과 실제의 차이에 비례해 조금 고칩니다.
