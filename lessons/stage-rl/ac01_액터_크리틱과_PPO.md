## 1. 개념 (8분)

### 1-1. 액터와 크리틱: 노래 경연
REINFORCE에는 아쉬움이 둘 있었습니다. 판이 끝나야 고칠 수 있고, 베이스라인이 "평균 하나"뿐입니다. 쉬운 상황이든 어려운 상황이든 같은 잣대로 잽니다.

노래 경연을 떠올려 보세요.
- **액터(배우)** 는 가수입니다. 무대에서 노래합니다 = [정책](#mdp01) π, 행동을 고릅니다
- **크리틱(평론가)** 은 심사위원입니다. "이 곡이면 보통 몇 점쯤 나오지" 하고 기대치를 압니다 = [상태 가치](#bel01) V(s)를 배우는 신경망입니다

가수는 점수 자체가 아니라 **"기대보다 잘했다/못했다"** 를 듣고 고칩니다. 어려운 곡에서 7점이면 칭찬이고, 쉬운 곡에서 7점이면 아쉬운 것이죠. 크리틱이 상태마다 다른 베이스라인이 되어 주는 것입니다.

### 1-2. 어드밴티지: 기대보다 얼마나 나았나
$$A = r + \gamma V(s') - V(s)$$

A는 **어드밴티지**(advantage, 이득). 정확히는 "한 걸음만 보고 어림한" 어드밴티지지만, 보통 그냥 어드밴티지라고 부릅니다. 낯익지요? [Q러닝](#ql01)의 **TD 오차**와 같은 모양입니다("받은 보상 + γ × 다음 칸의 값 − 지금 값"). 거기서는 Q와 max로 계산해 Q를 고치는 데 썼고, 여기서는 V로 계산해 **액터를 칭찬할지 말지** 정하는 데 씁니다. 같은 식, 쓰는 곳만 다릅니다.

- A > 0: 기대보다 좋았다 → 그 행동의 확률을 올린다
- A < 0: 기대보다 나빴다 → 내린다

판이 끝날 때까지 기다리지 않고 **한 걸음마다** 고칠 수 있습니다. 크리틱 자신도 TD 오차가 줄어드는 쪽으로 V를 고치며 함께 배웁니다.

> 각주: **A2C**(Advantage Actor-Critic)는 이 방식을 여러 환경에서 동시에 돌려 모은 경험으로 한꺼번에 고치는 것, **A3C**는 그 비동기(각자 따로 고침) 버전입니다(Mnih 외 2016).

### 1-3. 문제: 한 번에 너무 크게 바꾸면 무너진다
정책 경사는 걸음 크기가 까다롭습니다. 칭찬받았다고 창법을 확 바꾸면 노래가 무너지고, **무너진 정책으로 모은 경험**으로 또 배우니 회복하기 어렵습니다. [경사하강](#day08)에서 학습률이 너무 크면 발산한 것과 비슷합니다.

### 1-4. PPO: "한 번에 20% 넘게 바꾸지 마"
PPO(Proximal Policy Optimization, "가까이 머무는 정책 최적화")는 먼저 **확률 비율**을 봅니다.

$$\rho = \frac{\pi_{\text{새}}(a)}{\pi_{\text{옛}}(a)}$$

ρ(로)는 "그 행동을 새 정책이 옛 정책보다 몇 배 자주 하나"입니다. 0.2 → 0.3으로 올렸다면 ρ = 1.5. 바꾸지 않았으면 ρ = 1입니다. 그리고 아래 **목적값**이 커지도록 정책을 고칩니다.

$$\text{목적} = \min\big(\rho A,\ \text{clip}(\rho, 1-\epsilon, 1+\epsilon)\, A\big),\quad \epsilon = 0.2$$

clip은 "ρ를 0.8과 1.2 사이로 잘라라"입니다(1.5 → 1.2, 0.5 → 0.8). 그리고 그대로 계산한 값과 잘라서 계산한 값 중 **작은 쪽**을 씁니다. 이게 실제로 하는 일은 이렇습니다.

- **A > 0 (좋았던 행동):** 확률을 올리되, ρ가 **1.2를 넘으면 더 올려도 점수가 그대로**(평평). 더 밀 이유가 없어집니다. ρ < 1이 되는 쪽(잘못 내린 경우)은 잘리지 않고 직선 그대로입니다
- **A < 0 (나빴던 행동):** 확률을 내리되, ρ가 **0.8 아래로 가면 더 내려도 점수가 그대로**(평평). 이미 충분히 줄였으니까요. ρ > 1이 되는 쪽(잘못 올린 경우)은 그대로 벌을 받습니다

평평한 쪽은 언제나 **한쪽뿐**이고, A의 부호가 정합니다. 코치의 규칙에 비유하면 "칭찬받았어도 한 번에 20% 넘게 바꾼 건 점수로 쳐 주지 않아. 단, 잘못 간 건 끝까지 책임져." 바꾸는 것 자체를 막는 게 아니라, 더 바꿀 **이유(기울기)**를 없애는 것입니다.

> **같은 글자, 다른 뜻: ε.** [슬롯머신](#mab01)과 [Q러닝](#ql01)의 ε-탐욕에서 ε은 "아무 행동이나 해 볼 **확률**"(예: 0.1)이었습니다. PPO의 ε은 "확률 비율을 1에서 얼마나 벗어나게 **허락할지**"(보통 0.2)입니다. 둘 다 작은 수라서 ε을 쓸 뿐, 전혀 다른 손잡이입니다.

### 1-5. 언어 모델에 대응시키기 (짧게)
| 강화학습 | 언어 모델 |
|---|---|
| 상태 | 프롬프트 + 지금까지 쓴 글 |
| 행동 | 다음 토큰 하나 |
| 정책(액터) | 언어 모델 |
| 보상 | 답을 다 쓴 뒤 보상 모델이 준 점수 |

나중에 11단계 RLHF에서 이 표를 다시 만납니다. 그때 PPO는 "보상 점수를 올리되 한 번에 많이 바꾸지 않게"를 맡고, 원래 모델에서 멀어지지 않게 하는 목줄(KL 벌점)과 함께 쓰입니다.

## 2. 예제 따라하기 (6분)

쓸 값: ε = 0.2 → 자르는 구간 [0.8, 1.2], γ = 0.9

**어드밴티지.** V(s) = 7, 보상 r = 0, 다음 상태 V(s′) = 10.
A = 0 + 0.9 × 10 − 7 = 9 − 7 = **+2** (기대보다 2만큼 좋았다)

**PPO 클리핑, 네 가지 경우**

| | A | ρ | 그대로 ρA | 잘라서 clip(ρ)·A | min | 뜻 |
|---|---|---|---|---|---|---|
| ① | +2 | 1.5 | 3 | 1.2 × 2 = 2.4 | **2.4** | 너무 올림 → 평평, 더 이득 없음 |
| ② | −2 | 0.5 | −1 | 0.8 × (−2) = −1.6 | **−1.6** | 이미 충분히 줄임 → 평평 |
| ③ | +2 | 0.5 | 1 | 0.8 × 2 = 1.6 | **1** | 좋은 행동을 줄임 → 직선 그대로 |
| ④ | −2 | 1.5 | −3 | 1.2 × (−2) = −2.4 | **−3** | 나쁜 행동을 늘림 → 그대로 벌 |

①에서 ρ를 1.5에서 1.8로 더 올려도 min은 2.4 그대로입니다. 기울기가 0이라 더 밀지 않습니다. ③과 ④는 잘린 값이 더 커서 min이 그대로 값을 고릅니다. **잘못 간 쪽은 봐주지 않는다**는 뜻입니다.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 A의 부호를 바꿔 가며 ρ를 움직여 보세요. 선이 어느 쪽에서만 평평해지는지 확인하세요.

쓸 값: ε = 0.2, γ = 0.9

### ✏️ 손계산
1. V(s) = 3, r = 1, V(s′) = 5. 어드밴티지는?
2. V(s) = 6.5, r = 0, V(s′) = 5. 어드밴티지는? 이 행동의 확률은 올라가나요, 내려가나요?
3. 옛 정책이 그 행동을 할 확률 0.4, 새 정책 0.5. ρ는?
4. A = +1, ρ = 1.5. PPO 목적값은?
5. A = −1, ρ = 0.6. PPO 목적값은?
6. A = +1, ρ = 0.6. PPO 목적값은? 잘렸나요?

### 🧩 미니 챌린지
PPO에서 ε을 0.2 대신 0.01로 아주 작게 잡으면 어떻게 될까요? 반대로 ε을 10처럼 아주 크게 잡으면요? 노래 경연의 코치 규칙으로 말해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
def advantage(r, v_s, v_next, gamma=0.9):
    return r + gamma * v_next - v_s

def ppo_objective(rho, A, eps=0.2):
    return min(rho * A, np.clip(rho, 1 - eps, 1 + eps) * A)

print(round(advantage(0, 7, 10), 2))          # 2.0
for rho, A in [(1.5, 2), (0.5, -2), (0.5, 2), (1.5, -2)]:
    print(rho, A, round(ppo_objective(rho, A), 2))
# 1.5 2 2.4
# 0.5 -2 -1.6
# 0.5 2 1.0
# 1.5 -2 -3.0
```

## 📝 한 줄 정리
액터-크리틱은 크리틱의 기대치로 어드밴티지("기대보다 얼마나 나았나")를 매겨 액터를 고친다. PPO는 확률 비율을 [1 − ε, 1 + ε]로 잘라, 좋은 쪽으로 너무 많이 바꾸는 이득만 막는다.

**손계산**
1. 1 + 0.9 × 5 − 3 = 1 + 4.5 − 3 = **2.5**

**미니 챌린지**
ε이 너무 작으면 "한 번에 1%만 바꿔"라서 아주 안전하지만 배우는 데 한참 걸립니다. 너무 크면 사실상 자르지 않는 것과 같아, 칭찬 한 번에 창법을 확 바꿔 무너질 수 있습니다. 0.2는 그 사이에서 실험으로 고른 값입니다.

**퀴즈**
1. 액터는 정책(행동 확률), 크리틱은 상태 가치 V(s)
2. 같은 모양 "보상 + γ × 다음 값 − 지금 값"입니다. Q러닝은 Q로(r + γ × max Q(s′) − Q(s, a)) 계산해 Q를 고치고, 액터-크리틱은 V로(r + γV(s′) − V(s)) 계산해 액터를 고치는 신호로 씁니다
3. X. A > 0이면 ρ > 1.2 쪽만 평평하고, ρ < 0.8 쪽은 직선 그대로입니다
4. 아닙니다. ε-탐욕의 ε은 무작위로 행동할 확률, PPO의 ε은 확률 비율을 허락하는 폭입니다
