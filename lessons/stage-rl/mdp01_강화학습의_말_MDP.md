## 1. 개념 (8분)

### 1-1. 슬롯머신에서 한 걸음 더
[슬롯머신](#mab01)에서는 무엇을 당겨도 **다음 판의 상황은 그대로**였습니다. 하지만 대부분의 문제는 다릅니다. 체스에서 말을 하나 옮기면 판이 바뀌고, 바뀐 판에서 다음 수를 둬야 합니다. **지금 행동이 다음 상황을 바꾸는 것**, 이것이 강화학습의 진짜 무대입니다.

강아지에게 "앉아"를 가르치는 장면으로 말을 정리해 봅시다. (나중에 11단계 RLHF에서도 이 강아지가 다시 나옵니다.)

### 1-2. 다섯 낱말: 주고받기 한 바퀴
- **에이전트**(agent): 배우고 행동하는 쪽. 강아지
- **환경**(environment): 에이전트 바깥의 전부. 주인과 거실
- **상태**(state): 지금 상황을 나타낸 정보. "주인이 간식을 들고 '앉아'라고 했다"
- **행동**(action): 에이전트가 고르는 것. 앉기, 짖기, 뛰기
- **보상**(reward): 행동 뒤에 환경이 주는 숫자. 간식이면 +1, 아무것도 없으면 0

한 바퀴는 이렇습니다. **상태를 보고 → 행동하면 → 환경이 보상과 다음 상태를 돌려준다.** 이 바퀴가 끝없이, 또는 게임이 끝날 때까지 돕니다.

| 상황 | 상태 | 행동 | 보상 |
|---|---|---|---|
| 강아지 훈련 | 주인의 말과 손짓 | 앉기, 짖기 | 간식 +1 |
| 아타리 게임 (DQN) | 최근 화면 4장 | 조이스틱 방향, 버튼 | 점수가 오른 만큼 |
| 챗봇 (RLHF) | 질문과 지금까지 쓴 글 | 다음 단어 | 보상 모델의 점수 |

에이전트는 보상을 **많이 모으는 쪽**으로 행동을 고쳐 갑니다. 정답을 알려 주는 사람이 없다는 점이 지금까지 배운 학습(정답과 비교하는 [크로스엔트로피](#day07))과 가장 큰 차이입니다.

### 1-3. 마르코프 성질: 지금 판만 보면 된다
바둑을 두다 친구와 자리를 바꿔도, 친구는 **지금 판만 보고** 다음 수를 고를 수 있습니다. 어떤 순서로 여기까지 왔는지는 몰라도 됩니다. 이처럼 "다음에 무슨 일이 일어날지는 **지금 상태만으로** 정해진다"는 성질을 **마르코프 성질**이라고 합니다. [조건부확률](#day03)로 쓰면 "지금 상태가 주어지면, 과거는 더 알려 주는 게 없다"입니다.

그래서 상태를 잘 정해야 합니다. 아타리 게임에서 화면 **한 장**만 보면 공이 위로 가는지 아래로 가는지 알 수 없습니다. DQN이 **최근 화면 4장**을 묶어 상태로 쓴 이유입니다.

### 1-4. 리턴과 할인율 γ
에이전트가 모으려는 것은 지금 보상 하나가 아니라 **앞으로 받을 보상 전체**입니다. 그런데 오늘의 1만 원과 1년 뒤 1만 원은 같지 않습니다. 먼 미래 것은 조금 덜 쳐 줍니다. 이 비율이 **할인율** γ(감마)입니다. 0과 1 사이의 수입니다.

$$\text{리턴} = r_1 + \gamma\, r_2 + \gamma^2 r_3 + \gamma^3 r_4 + \cdots$$

$r_1, r_2, \ldots$는 첫째, 둘째… 걸음에서 받는 보상입니다. 한 걸음 미룰 때마다 γ를 한 번 더 곱합니다([거듭제곱](#prep02)). γ = 0.9면 무게가 1, 0.9, 0.81, 0.729…로 줄어듭니다.

> 같은 글자, 다른 뜻: [정규화](#norm01)에서 크기를 조절하던 γ와는 상관없는 숫자입니다. 강화학습에서 γ는 늘 할인율입니다.

### 1-5. 할인율은 왜 필요할까
1. **끝없는 합을 막는다.** 매 걸음 1씩 영원히 받으면 그냥 더한 합은 끝없이 커집니다. γ로 줄이면 합이 $\frac{1}{1-\gamma}$로 정해집니다. γ = 0.5면 1 + 0.5 + 0.25 + … = 2
2. **미래는 불확실하다.** 먼 미래의 보상은 정말 받을지 모릅니다
3. **빨리 받는 것을 좋아하게 된다.** 같은 10점이라도 두 걸음 만에 받는 길이 다섯 걸음 걸리는 길보다 리턴이 큽니다

γ의 크기는 **얼마나 멀리 보는지**를 정합니다. γ = 0이면 눈앞의 간식만 보는 강아지, γ = 0.99면 수십 수 앞을 보는 체스 선수입니다. 대략 $\frac{1}{1-\gamma}$걸음 앞까지 본다고 생각하면 됩니다(γ = 0.9 → 약 10걸음). DQN 논문은 γ = 0.99를 썼습니다.

### 1-6. 정책 π, 그리고 MDP
**정책**(policy)은 "이 상태에서는 이 행동을 이 확률로"라는 행동 규칙입니다. 기호는 π(파이). 원주율이 아니라 **policy의 p**입니다. 나중에 11단계 RLHF에서 "모델이 그 답을 쓸 확률"을 π라고 부르는데, 같은 뜻입니다. 언어 모델이 바로 "글(상태)을 보고 다음 단어(행동)를 고르는 정책"이니까요.

이 모든 것을 묶은 틀이 **MDP**(마르코프 결정 과정)입니다. 다섯 가지를 정하면 됩니다: **상태들, 행동들, 보상, 다음 상태로 갈 확률, 할인율 γ.** 강화학습의 목표는 한 줄입니다. **리턴의 기댓값이 가장 큰 정책 π를 찾아라.**

## 2. 예제 따라하기 (6분)

쓸 값: 0.9² = 0.81, 0.9³ = 0.729, 0.5² = 0.25, 0.5³ = 0.125

**① 끝에 10점.** 보상이 차례로 0, 0, 10입니다.

| 걸음 | 1 | 2 | 3 | 리턴 |
|---|---|---|---|---|
| 보상 | 0 | 0 | 10 | |
| γ = 0.9의 무게 | 1 | 0.9 | 0.81 | 0 + 0 + 8.1 = **8.1** |
| γ = 0.5의 무게 | 1 | 0.5 | 0.25 | 0 + 0 + 2.5 = **2.5** |

같은 10점이 γ = 0.5인 에이전트에게는 2.5점짜리로 보입니다. 성미가 급할수록 먼 보상이 작아 보입니다.

**② 걸음마다 벌점.** 미로에서 한 걸음에 −1, 도착하면 +10이라고 합시다. 보상 −1, −1, 10, γ = 0.9:

리턴 = −1 + 0.9 × (−1) + 0.81 × 10 = −1 − 0.9 + 8.1 = **6.2**

걸음 벌점이 있으면 에이전트는 **빨리 도착하는 길**을 좋아하게 됩니다.

**③ 영원히 1점씩.** γ = 0.5면 1 + 0.5 + 0.25 + 0.125 + … 막대를 쌓아 보면 2에 다가갑니다. 식으로 1/(1 − 0.5) = **2**. γ = 0.9면 1/(1 − 0.9) = **10**.

> (선택) 왜 1/(1 − γ)일까? 합을 S라고 하면 S = 1 + γ + γ² + …. 양쪽에 γ를 곱하면 γS = γ + γ² + …. 빼면 S − γS = 1, 그래서 S = 1/(1 − γ).

## 3. 능동 연습 (10분)

아래 실습 위젯의 할인율 다이얼을 돌려, γ에 따라 미래 보상 막대가 줄어드는 모습과 리턴을 확인하세요. 아래쪽 카드 문제에서는 낱말마다 상태, 행동, 보상 중 하나를 탭해 맞혀 보세요.

쓸 값: 0.5² = 0.25, 0.9² = 0.81, 1/(1 − 0.99) = 100

### ✏️ 손계산
1. 보상 1, 1, 1, γ = 0.5. 리턴은?
2. 보상 2, 0, 4, γ = 0.5. 리턴은?
3. 보상 0, 0, 10, γ = 0. 리턴은? 이 에이전트는 어떤 성격인가요?
4. 매 걸음 1점씩 영원히, γ = 0.99. 리턴은?
5. 같은 10점을 두 번째 걸음에 받는 길과 세 번째 걸음에 받는 길(나머지 보상은 0), γ = 0.9에서 리턴은 각각?
6. 자율주행차를 MDP로 받아 적으세요. 상태, 행동, 보상은 각각 무엇이 될까요?

### 🧩 미니 챌린지
청소 로봇에게 "먼지를 빨아들이면 +1"만 보상으로 주었더니, 로봇이 먼지를 쏟았다가 다시 빨아들이기를 반복했습니다. 무엇이 잘못됐고, 보상을 어떻게 바꾸면 좋을까요?

### 💻 코드 (선택)
```python
def ret(rewards, gamma):
    return sum(r * gamma**k for k, r in enumerate(rewards))

print(ret([0, 0, 10], 0.9))     # 8.1 (부동소수점 때문에 8.100000000000001로 보일 수 있음)
print(ret([0, 0, 10], 0.5))     # 2.5
print(ret([-1, -1, 10], 0.9))   # 6.2
print(ret([1] * 1000, 0.9))     # 거의 10 = 1 / (1 - 0.9)
```

## 📝 한 줄 정리
강화학습은 상태를 보고 행동하고 보상을 받는 바퀴를 돌며, 할인율 γ로 줄여 더한 리턴의 기댓값이 가장 큰 정책 π를 찾는다. 이 틀이 MDP다.

**미니 챌린지**
보상이 진짜 목표(방이 깨끗한 상태)가 아니라 행동(빨아들이기)에 붙어 있어서, 로봇이 보상만 늘리는 꼼수를 찾았습니다. "방에 남은 먼지가 줄어든 만큼 +"처럼 원하는 결과에 보상을 주어야 합니다. RLHF에서 모델이 보상 모델의 허점을 파고드는 문제와 같은 뿌리입니다.

**퀴즈**
1. 강아지가 에이전트(배우고 행동하는 쪽), 주인과 거실이 환경(바깥에서 보상과 다음 상황을 주는 쪽)입니다.
2. 다음에 일어날 일은 지금 상태만으로 정해지고, 어떻게 여기 왔는지는 더 알려 주는 게 없다는 성질입니다.
3. X. γ가 클수록 먼 미래 보상의 무게가 커져서 멀리 내다봅니다. γ = 0이 눈앞만 보는 쪽입니다.
4. 끝없는 합이 무한대가 되지 않게 하려고, 그리고 먼 미래일수록 불확실하고 빨리 받는 게 낫기 때문입니다.
