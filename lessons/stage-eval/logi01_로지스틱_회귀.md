## 1. 개념 (8분)

### 1-1. 숫자 맞히기와 예/아니오 맞히기
[PyTorch로 첫 모델](#pt01)에서는 x를 넣으면 **숫자**(y = 2x + 1)를 내는 모델을 만들었습니다. 이런 일을 **회귀**라고 부릅니다. 집값, 기온처럼 답이 숫자인 문제입니다.

그런데 세상의 질문은 **예/아니오**가 많습니다. 이 메일은 스팸인가? 이 사진에 고양이가 있나? 이 학생은 합격할까? 답을 몇 개의 칸 중 하나로 고르는 일을 **분류**라고 합니다. 칸이 2개면 **이진 분류**입니다.

예/아니오를 컴퓨터에 알려 줄 때는 **정답 y**를 1(예, 합격)과 0(아니오, 불합격)으로 적습니다.

### 1-2. 직선 점수를 확률로 누르기
오늘의 예: 공부 시간 x(시간)로 합격을 맞힙니다. 먼저 [층 하나](#day02)처럼 점수를 냅니다.

$$z = wx + b$$

z는 [소프트맥스에서 본 logit](#day05)처럼 아무 실수나 될 수 있습니다. −3일 수도, 10일 수도 있죠. 확률로 쓰려면 0과 1 사이로 눌러야 합니다. 이때 쓰는 것이 **시그모이드** σ입니다.

$$p = \sigma(wx + b)$$

**p**는 "합격(y = 1)일 확률"입니다. 오늘 쓸 값입니다.

| z | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| σ(z) | 0.12 | 0.27 | **0.5** | 0.73 | 0.88 |

공부 시간이 늘수록 합격 확률이 **S자**로 올라갑니다. 처음엔 거의 0이다가, 어느 구간에서 쑥 오르고, 나중엔 1에 가까워져 더는 크게 오르지 않습니다.

**판정:** p가 0.5 이상이면 "합격", 아니면 "불합격"이라고 답합니다. (0.5가 늘 정답은 아닙니다. 놓치면 큰일인 문제에서는 기준을 낮추기도 하는데, 이 이야기는 [혼동 행렬](#cm01)과 그다음 챕터에서 합니다.)

> 이름에 "회귀"가 붙은 이유: 이 모델이 직접 배우는 것은 **확률이라는 숫자**입니다. 확률을 숫자로 맞히는 회귀를 하고, 마지막에 0.5로 잘라 분류에 씁니다. 1958년 Cox가 이 방법을 정리할 때부터 이 이름이었습니다.

### 1-3. 결정 경계: 커트라인은 어디?
p = 0.5가 되는 곳은 σ(z) = 0.5, 즉 **z = 0**인 곳입니다. wx + b = 0을 풀면

$$x = -\frac{b}{w}$$

w = 1, b = −4라면 x = 4시간. 4시간보다 많이 공부한 학생은 "합격", 적게 한 학생은 "불합격"으로 판정됩니다. 이 경계가 **결정 경계**입니다. 합격 커트라인과 같습니다.

- **w**는 S자의 **가파른 정도**입니다. w가 크면 커트라인 근처에서 확률이 확 뛰고, 작으면 완만하게 오릅니다.
- **b**는 S자를 **옆으로 미는** 역할입니다. w = 1일 때 b를 −4에서 −6으로 바꾸면 커트라인이 4시간에서 6시간으로 밀립니다.

### 1-4. 이진 크로스엔트로피: 얼마나 틀렸나 (새 개념)
모델이 p를 냈고 정답이 y입니다. 벌점(손실)을 이렇게 매깁니다.

$$L = -\big[\,y \ln p + (1-y)\ln(1-p)\,\big]$$

겁낼 필요 없습니다. y는 0 아니면 1이라서, 대괄호 속 두 항 중 **하나는 항상 0**이 됩니다.

- 정답이 합격(y = 1)이면: $L = -\ln p$. "합격"에 준 확률이 작을수록 벌점이 큽니다
- 정답이 불합격(y = 0)이면: $L = -\ln(1-p)$. "불합격"에 준 확률 1 − p가 작을수록 벌점이 큽니다

즉 **정답 쪽에 준 확률 q를 찾아서 −ln q**를 하면 됩니다. 칸이 "합격/불합격" 2개뿐인 크로스엔트로피라서 **이진**(binary) 크로스엔트로피라고 부릅니다. 줄여서 BCE. [크로스엔트로피](#day07)에서 본 "−ln(정답에 준 확률)"과 같은 생각인데, 확률이 시그모이드 하나에서 p와 1 − p로 나온다는 점이 새롭습니다.

| 정답 쪽 확률 q | 0.88 | 0.73 | 0.5 | 0.27 | 0.12 |
|---|---|---|---|---|---|
| 벌점 −ln q | 0.13 | 0.31 | 0.69 | 1.31 | 2.13 |

**틀렸는데 자신만만했을수록** 벌점이 크게 뜁니다. 합격할 학생에게 0.12를 주면 2.13, 0.27을 주면 1.31입니다. 학습은 데이터 전체의 **평균 벌점**을 [경사하강](#day08)으로 줄여 w와 b를 찾습니다.

> (선택) 놀랍게 간단한 기울기: 이 손실을 z로 미분하면 **p − y**가 나옵니다. 합격(y = 1)인데 p = 0.73이라면 −0.27, "조금 더 올려라"는 신호입니다. 소프트맥스와 크로스엔트로피를 함께 썼을 때의 기울기 "q − 정답 원-핫"([경사하강](#day08))과 같은 모양입니다.

> (선택) 로그 오즈: 확률 p를 "안 될 확률 대비 될 확률" p/(1 − p)로 바꾼 것을 **오즈**라고 합니다. 로지스틱 회귀는 사실 $\ln\frac{p}{1-p} = wx + b$, 즉 **로그 오즈를 직선으로 맞히는 회귀**입니다. 예: p = 0.73이면 오즈는 0.73 ÷ 0.27 ≈ 2.7, ln 2.7 ≈ 1 = z.

### 1-5. 신경망으로 보면
로지스틱 회귀는 **뉴런 하나짜리 신경망**입니다. 입력에 가중치를 곱하고 편향을 더한 뒤 시그모이드를 씌운 것. 큰 신경망의 마지막 층이 예/아니오를 낼 때도 똑같이 "시그모이드 + 이진 크로스엔트로피"를 씁니다. 나중에 11단계 "RLHF와 DPO"에서 보상 모델이 "A가 B보다 나은가"를 배울 때 쓰는 식 −ln σ(r_A − r_B)도 오늘의 식과 같습니다.

## 2. 예제 따라하기 (6분)

모델: w = 1, b = −4. 학생 4명입니다.

| 학생 | 공부 시간 x | 실제 결과 y |
|---|---|---|
| 가 | 2 | 불합격 (0) |
| 나 | 3 | 합격 (1) |
| 다 | 5 | 합격 (1) |
| 라 | 6 | 합격 (1) |

1. **점수 z = x − 4:** 가 −2, 나 −1, 다 1, 라 2
2. **확률 p = σ(z):** 가 0.12, 나 0.27, 다 0.73, 라 0.88
3. **판정 (0.5 기준):** 가 불합격 ✓, 나 불합격 ✗ (실제 합격), 다 합격 ✓, 라 합격 ✓ → **4명 중 3명** 맞힘
4. **정답 쪽 확률 q:** 가는 불합격이 정답이라 1 − 0.12 = 0.88, 나 0.27, 다 0.73, 라 0.88
5. **벌점 −ln q:** 0.13, 1.31, 0.31, 0.13
6. **평균 손실:** (0.13 + 1.31 + 0.31 + 0.13) ÷ 4 = 1.88 ÷ 4 = **0.47**

벌점의 대부분(1.31)이 틀린 학생 "나"에게서 나왔습니다. 경사하강은 이 벌점을 줄이려고 커트라인을 3시간 쪽으로 조금 당깁니다.

## 3. 능동 연습 (10분)

쓸 값: σ(−2) = 0.12, σ(−1) = 0.27, σ(0) = 0.5, σ(1) = 0.73, σ(2) = 0.88 / −ln 0.88 ≈ 0.13, −ln 0.73 ≈ 0.31, −ln 0.5 ≈ 0.69, −ln 0.27 ≈ 1.31, −ln 0.12 ≈ 2.13

아래 실습 위젯에서 w와 b 슬라이더로 S자 곡선을 움직여, 학생 8명 중 7명을 맞혀 보세요. 맞힌 개수와 평균 손실이 함께 바뀝니다.

### ✏️ 손계산
1. w = 2, b = −6입니다. 공부 시간 4시간인 학생의 점수 z와 합격 확률 p는?
2. 1번 모델의 결정 경계(커트라인)는 몇 시간인가요?
3. w = 1, b = −5라면 커트라인은? b = −4일 때와 비교해 어느 쪽으로 움직였나요?
4. 실제로 합격한 학생에게 모델이 p = 0.88을 줬습니다. 벌점은?
5. 실제로 **불합격**한 학생에게 모델이 p = 0.88을 줬습니다. 벌점은?
6. 학생 두 명의 벌점이 0.31과 0.69입니다. 평균 손실은?
7. 모델이 모든 학생에게 p = 0.5를 준다면, 정답과 상관없이 학생 한 명의 벌점은?

### 🧩 미니 챌린지
w를 아주 크게(예: 100) 키우면 S자 곡선은 어떤 모양이 될까요? 이런 모델이 커트라인 바로 옆에서 틀리면 벌점은 어떻게 될까요?

### 💻 코드 (선택)
```python
import numpy as np
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.array([2, 3, 5, 6])          # 공부 시간
y = np.array([0, 1, 1, 1])          # 실제 결과
w, b = 1.0, -4.0
p = sigmoid(w * x + b)
print(p.round(2))                   # [0.12 0.27 0.73 0.88]
loss = -(y * np.log(p) + (1 - y) * np.log(1 - p))
print(loss.round(2), loss.mean().round(2))   # [0.13 1.31 0.31 0.13] 0.47
print((p >= 0.5).astype(int))       # [0 0 1 1]  판정
```

## 📝 한 줄 정리
로지스틱 회귀는 직선 점수 wx + b를 시그모이드로 눌러 "예일 확률"을 만들고, 정답 쪽 확률의 −ln(이진 크로스엔트로피)을 줄이며 배운다. 확률 0.5가 되는 x = −b/w가 결정 경계다.

<summary>🔑 정답 보기 (먼저 풀고 열기!)</summary>

**손계산**
1. z = 2 × 4 − 6 = **2**, p = σ(2) = **0.88**
2. 2x − 6 = 0 → x = **3시간** (= −b/w = 6/2)
3. x = 5/1 = **5시간**. 4시간에서 5시간으로, **오른쪽으로** 밀렸습니다 (합격이 더 어려워짐)
4. 정답 쪽 확률 0.88 → −ln 0.88 ≈ **0.13**
5. 정답 쪽(불합격) 확률은 1 − 0.88 = 0.12 → −ln 0.12 ≈ **2.13**. 자신 있게 틀려서 크게 혼납니다
6. (0.31 + 0.69) ÷ 2 = **0.5**
7. 정답 쪽 확률이 늘 0.5 → −ln 0.5 ≈ **0.69**. "아무것도 모르는 모델"의 기준 점수로 기억해 두면 좋습니다

**미니 챌린지**
곡선이 커트라인에서 0에서 1로 **수직으로 뚝 떨어지는 계단**처럼 됩니다. 확률이 거의 0 아니면 1이라, 커트라인 바로 옆에서 틀리면 정답 쪽 확률이 0에 가까워져 벌점이 **아주 커집니다**. 그래서 경사하강은 데이터가 섞여 있는 곳에서는 w를 무작정 키우지 않습니다.

**퀴즈**
1. 회귀는 숫자를 맞히고(집값, 기온), 분류는 정해진 칸 중 하나를 고릅니다(스팸/정상).
2. 아무 실수나 되는 점수 z를 0과 1 사이의 확률로 눌러 줍니다.
3. X. 확률을 회귀로 맞힌 뒤 0.5로 잘라 **분류**에 쓰는 모델입니다.
4. 0.12일 때(2.13)가 0.88일 때(0.13)보다 훨씬 큽니다. 틀린 답에 자신만만한 모델을 가장 세게 고치려고요.
