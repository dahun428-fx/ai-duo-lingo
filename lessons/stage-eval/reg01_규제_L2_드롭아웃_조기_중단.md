## 1. 개념 (8분)

### 1-1. 규제: 모델에게 "너무 외우지 마"라고 말하는 법
과적합은 모델이 훈련 세트의 우연한 잡음까지 외워 버린 상태입니다. **규제**(regularization)는 이걸 막으려고 학습에 일부러 거는 제약입니다. 오늘은 세 가지를 봅니다.

| 도구 | 한 줄 요약 | 비유 |
|---|---|---|
| L2 벌점 | 가중치가 크면 벌금 | 너무 튀는 답에 벌금 |
| 드롭아웃 | 매번 뉴런 몇 개를 쉬게 함 | 팀원 몇 명을 빼고 연습하는 팀 |
| 조기 중단 | 검증 손실이 오르기 시작하면 멈춤 | 라면이 퍼지기 전에 불 끄기 |

그리고 가장 확실한 규제는 사실 **데이터를 늘리는 것**입니다. 외울 수 없을 만큼 많이 보여 주면 외우지 못합니다. 사진을 살짝 돌리거나 뒤집어 데이터를 늘리는 **데이터 증강**도 같은 생각입니다.

### 1-2. L2 벌점: 큰 가중치에 벌금
원래 손실(예: [크로스엔트로피](#day07))에 **가중치 제곱의 합**을 벌점으로 더합니다.

$$\text{전체 손실} = \text{원래 손실} + \lambda \times (w_1^2 + w_2^2 + \cdots)$$

λ(람다)는 **규제 세기**, 벌금을 얼마나 무겁게 매길지 정하는 숫자입니다. 우리가 정하는 하이퍼파라미터이고, [검증 세트](#split01)로 고릅니다.

왜 가중치가 작으면 좋을까요? 가중치가 크면 입력이 조금만 바뀌어도 출력이 크게 출렁입니다. 훈련 점 하나하나를 억지로 지나가려는 꼬불꼬불한 곡선이 이런 모양입니다. 가중치를 작게 누르면 곡선이 **매끈해지고**, 처음 보는 데이터에도 덜 흔들립니다.

L2 벌점은 경사하강을 할 때마다 가중치를 0 쪽으로 **살짝 줄이는** 효과를 냅니다. 그래서 **가중치 감쇠**(weight decay)라고도 부릅니다. 요즘 많이 쓰는 옵티마이저 AdamW의 W가 이 weight decay입니다([Adam과 학습률](#opt01)). (Adam에서는 벌점을 손실에 더하는 방식과 가중치를 직접 줄이는 방식이 살짝 달라서, 줄이는 몫을 따로 떼어 적용한 것이 AdamW입니다.)

> **같은 글자, 다른 뜻:** 이 λ는 "규제 세기"입니다. 나중에 5단계 "고유값과 고유벡터"에서는 λ가 **고유값**(늘어나는 배수)이라는 전혀 다른 뜻으로 나옵니다. 논문에서 λ를 보면 앞뒤 문맥으로 구별하세요.

(한 줄 더) 제곱 대신 **절댓값**의 합을 벌점으로 쓰면 L1 벌점입니다. L1은 많은 가중치를 정확히 0으로 만드는 성질이 있습니다. 10단계 행렬 노름 레슨에서 다시 만납니다.

### 1-3. 드롭아웃: 매번 무작위로 팀원 빼고 연습하기
학습할 때 한 걸음마다 층의 뉴런을 **확률 p로 꺼 버립니다**(출력을 0으로). 여기서 p는 "끌 확률"입니다. [로지스틱 회귀](#logi01)의 p(합격 확률)와는 다른 뜻이에요. 어떤 뉴런이 꺼질지는 매번 새로 뽑습니다.

축구팀이 매일 무작위로 몇 명을 빼고 연습한다고 생각해 보세요. 에이스 한 명에게 기대는 작전은 못 씁니다. 누가 빠져도 돌아가도록 **모두가 조금씩 일을 나눠 맡게** 됩니다. 신경망도 특정 뉴런 몇 개가 훈련 세트의 잡음을 외우는 일이 어려워집니다.

**추론 때는?** 끄지 않습니다. 모든 뉴런을 켭니다. 그런데 학습 때는 평균적으로 (1 − p)만큼만 켜져 있었으니, 다 켜면 다음 층에 들어가는 합이 커집니다. 그래서 크기를 맞춰 줍니다.

- **원 논문 방식:** 추론 때 출력에 (1 − p)를 곱합니다 (원 논문은 p를 "남길 확률"로 써서 식이 p를 곱하는 모양입니다. 논문을 읽을 때 헷갈리지 마세요)
- **PyTorch 방식:** 학습 때 살아남은 뉴런의 출력을 미리 (1 − p)로 **나눠** 둡니다. 그러면 추론 때는 아무것도 안 해도 됩니다

둘 다 "학습 때와 추론 때 평균 크기를 같게"가 목적입니다. PyTorch에서 `model.eval()`을 부르면 드롭아웃이 꺼지는 이유입니다.

### 1-4. 조기 중단: 라면이 퍼지기 전에 불 끄기
매 에폭이 끝날 때마다 검증 손실을 잽니다. 검증 손실이 가장 낮았던 순간의 가중치를 저장해 두고, 몇 에폭 동안 더 나아지지 않으면 **학습을 멈추고 저장해 둔 가중치로 돌아갑니다.** "몇 에폭 기다릴지"를 **인내심**(patience)이라고 부릅니다.

라면은 덜 익으면 딱딱하고(과소적합), 너무 끓이면 퍼집니다(과적합). 가장 맛있을 때 불을 끄는 것이 조기 중단입니다. 따로 계산할 것이 없어 거의 모든 학습에 기본으로 들어갑니다.

## 2. 예제 따라하기 (6분)

**L2: λ가 승자를 바꾼다.** 두 모델이 있습니다.

| | 원래 손실 | 가중치 | 제곱의 합 |
|---|---|---|---|
| 모델 A | 0.5 | [3, 4] | 9 + 16 = 25 |
| 모델 B | 0.8 | [1, 1] | 1 + 1 = 2 |

- λ = 0.1: A는 0.5 + 0.1 × 25 = **3.0**, B는 0.8 + 0.1 × 2 = **1.0** → B 승
- λ = 0.01: A는 0.5 + 0.25 = **0.75**, B는 0.8 + 0.02 = **0.82** → A 승

벌금이 무거우면 "훈련 점수는 조금 낮아도 가중치가 얌전한" B를 고릅니다.

**드롭아웃 (p = 0.5).** 뉴런 4개의 출력이 [2, 4, 6, 8]이고, 이번 걸음에 뽑힌 결과가 [켬, 끔, 켬, 끔]이면:
- 끈 뒤: [2, 0, 6, 0]
- PyTorch 방식으로 0.5로 나누면: **[4, 0, 12, 0]**
- 추론 때(원 논문 방식): 모두 켜고 0.5를 곱해 **[1, 2, 3, 4]**

**조기 중단 (인내심 2).**

| 에폭 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 훈련 손실 | 1.00 | 0.70 | 0.50 | 0.40 | 0.32 | 0.26 | 0.21 |
| 검증 손실 | 1.10 | 0.80 | 0.62 | 0.55 | **0.53** | 0.56 | 0.61 |

에폭 5에서 가장 낮습니다. 6, 7에서 두 번 연속 나아지지 않았으니 에폭 7이 끝나면 멈추고 **에폭 5의 가중치**로 돌아갑니다. 훈련 손실은 계속 내려가는 중이었다는 점을 보세요. 훈련 손실만 봤다면 멈출 이유를 몰랐을 겁니다.

## 3. 능동 연습 (10분)

아래 실습 위젯의 첫 탭에서 검증 손실이 가장 낮을 때 "지금 멈춰!"를 눌러 보고, λ를 바꿔 곡선이 어떻게 달라지는지 보세요. 둘째 탭에서는 드롭아웃이 뉴런을 끄고 살아남은 값을 키우는 모습을 볼 수 있습니다.

### ✏️ 손계산
1. 원래 손실 0.4, 가중치 [2, 1], λ = 0.1일 때 전체 손실은?
2. 같은 모델에서 λ = 0이면 전체 손실은? 이때 규제는 어떤 상태인가요?
3. λ = 0.05입니다. 모델 A(원래 손실 0.3, 가중치 [2, 2])와 모델 B(원래 손실 0.5, 가중치 [1, 0]) 중 전체 손실이 더 작은 쪽은?
4. 드롭아웃 p = 0.5. 출력 [1, 3, 5, 7]에서 [끔, 켬, 켬, 끔]이 뽑혔습니다. PyTorch 방식으로 다음 층에 넘어가는 값은?
5. 4번의 층을 원 논문 방식으로 추론하면 넘어가는 값은?
6. 검증 손실이 에폭 1~6에 0.90, 0.70, 0.60, 0.58, 0.61, 0.66이었습니다. 인내심 2라면 몇 에폭 뒤에 멈추고, 몇 번째 에폭의 가중치를 쓰나요?
7. 드롭아웃 p = 0.2, 뉴런 10개. 한 걸음에 평균 몇 개가 꺼지나요?

### 🧩 미니 챌린지
λ를 아주 크게(예: 1000) 하면 어떤 일이 생길까요? 가중치는 어떻게 되고, 모델은 과적합과 과소적합 중 어느 쪽이 될까요?

### 💻 코드 (선택)
```python
import torch, torch.nn as nn
model = nn.Sequential(nn.Linear(10, 32), nn.ReLU(), nn.Dropout(p=0.5), nn.Linear(32, 1))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)   # 가중치 감쇠

drop = nn.Dropout(p=0.5)
x = torch.tensor([2., 4., 6., 8.])
drop.train(); print(drop(x))   # 예: tensor([ 4.,  0., 12.,  0.])  끄고, 살아남은 값은 ÷0.5
drop.eval();  print(drop(x))   # tensor([2., 4., 6., 8.])  추론 때는 그대로
```

> (선택) **왜 "감쇠"인가.** 벌점 λw²의 기울기는 2λw입니다([기울기를 숫자로 느끼기](#dx01)). 경사하강 한 걸음 w ← w − η × (기울기)에 이 몫을 넣으면, 데이터에서 온 기울기와 별개로 매번 w에 (1 − 2ηλ)를 곱하는 셈이 됩니다. η = 0.1, λ = 0.05면 1 − 0.01 = **0.99**. 가중치가 걸음마다 1%씩 0 쪽으로 줄어듭니다.

## 📝 한 줄 정리
L2 벌점(가중치 감쇠)은 큰 가중치에 벌금을, 드롭아웃은 학습 때만 뉴런을 무작위로 쉬게, 조기 중단은 검증 손실이 오르기 전에 멈추게 해서 과적합을 막는다.
