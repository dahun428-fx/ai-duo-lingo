## 1. 개념 (8분)

### 1-1. 모델은 "예/아니오"가 아니라 점수를 낸다
[로지스틱 회귀](#logi01) 같은 분류 모델은 사실 0과 1 사이의 **점수(확률)** 를 냅니다. "예/아니오"는 우리가 기준선을 그어서 만듭니다. 이 기준선이 **임계값**입니다. 점수가 임계값보다 크면 양성, 아니면 음성.

[혼동 행렬](#cm01)의 화재경보기를 그대로 씁니다. 경보기 안의 모델이 상황마다 "불일 것 같은 점수"를 내고, 점수가 임계값을 넘으면 울립니다. 임계값은 경보기의 **민감도 다이얼**입니다.

- 임계값을 **낮추면**(예민하게): 조금만 연기 나도 울림 → 불은 잘 잡지만 괜히 울리는 일도 늘어남
- 임계값을 **높이면**(둔하게): 웬만해선 안 울림 → 괜히 울리진 않지만 불을 놓침

0.5는 흔한 기본값일 뿐, 정답이 아닙니다.

### 1-2. 축 두 개: 불을 잡은 비율, 괜히 울린 비율
다이얼을 하나 정할 때마다 두 숫자를 셉니다.

$$\text{불을 잡은 비율} = \frac{TP}{TP + FN} \qquad \text{괜히 울린 비율} = \frac{FP}{FP + TN}$$

- **불을 잡은 비율**: 진짜 불 중 울린 비율. [혼동 행렬](#cm01)의 **재현율**과 같습니다. 영어로는 TPR(true positive rate, 진짜 양성 비율)
- **괜히 울린 비율**: 불이 아닌 상황 중 울린 비율. 영어로는 FPR(false positive rate, 거짓 양성 비율)

둘 다 분모가 **실제 줄**(가로)입니다. 불 쪽 줄과 불 아닌 쪽 줄을 따로 봅니다.

### 1-3. ROC 곡선: 다이얼 전 구간을 한 장에
가로축에 괜히 울린 비율, 세로축에 불을 잡은 비율을 놓고, 임계값을 1에서 0까지 돌리며 점을 찍어 이은 것이 **ROC 곡선**입니다.

- 임계값이 아주 높으면 아무것도 안 울림 → 점 (0, 0)
- 임계값이 아주 낮으면 전부 울림 → 점 (1, 1)
- 그 사이에서 곡선이 **왼쪽 위**(괜히 안 울리고 불은 다 잡음)로 볼록할수록 좋은 경보기

대각선은 **동전 던지기** 경보기입니다. 점수가 엉터리면 불이든 아니든 같은 비율로 울리니까 두 비율이 늘 같습니다.

(이름의 유래: ROC는 2차 세계대전 레이더 신호를 판별하던 데서 온 말 "receiver operating characteristic"입니다. 뜻보다는 그림을 기억하세요.)

### 1-4. AUC: 곡선 아래 넓이 = 짝 비교 게임의 승률
**AUC**는 ROC 곡선 아래의 넓이입니다(area under the curve). 0과 1 사이의 숫자 하나로 경보기의 실력을 요약합니다.

넓이를 적분으로 구할 필요는 없습니다. AUC에는 멋진 뜻이 있습니다.

> **진짜 불 하나와 불 아닌 상황 하나를 무작위로 뽑았을 때, 불 쪽의 점수가 더 높을 확률**

그래서 짝을 전부 세면 됩니다.

| AUC | 뜻 |
|---|---|
| 1.0 | 모든 불이 모든 불 아닌 상황보다 점수가 높음. 완벽하게 줄 세움 |
| 0.5 | 동전 던지기. 점수가 아무 정보도 없음 |
| 0.5보다 작음 | 거꾸로 매김. 판정을 뒤집으면 오히려 나아짐 |

AUC는 임계값을 정하기 **전에** 모델의 "줄 세우기 실력"을 봅니다. 임계값은 나중에 상황에 맞게(암 검진이면 낮게) 고르면 됩니다.

## 2. 예제 따라하기 (6분)

상황 8개에 모델이 매긴 점수입니다. 진짜 불 4개, 불 아닌 상황 4개.

| | 모델이 매긴 점수 |
|---|---|
| 진짜 불 🔥 | 0.9, 0.8, 0.6, 0.4 |
| 불 아님 (토스트 연기, 샤워 수증기 …) | 0.7, 0.5, 0.3, 0.2 |

**점 찍기.** "점수 > 임계값이면 울림"으로 셉니다.

| 임계값 | 울린 불 | 괜히 울린 것 | 괜히 울린 비율 | 불을 잡은 비율 |
|---|---|---|---|---|
| 1.0 | 없음 | 없음 | 0 | 0 |
| 0.75 | 0.9, 0.8 | 없음 | 0 | 2/4 = 0.5 |
| 0.55 | 0.9, 0.8, 0.6 | 0.7 | 1/4 = 0.25 | 3/4 = 0.75 |
| 0.35 | 네 개 모두 | 0.7, 0.5 | 2/4 = 0.5 | 1 |
| 0 | 네 개 모두 | 네 개 모두 | 1 | 1 |

점 (0, 0) → (0, 0.5) → (0.25, 0.75) → (0.5, 1) → (1, 1)을 이으면 왼쪽 위로 볼록한 곡선이 나옵니다. 임계값을 더 촘촘히 돌리면 계단 모양이 되는데, 아래 실습 위젯에서 직접 볼 수 있습니다.

**AUC 세기.** 불 4개 × 불 아님 4개 = 짝 16개. 불 쪽이 이긴 짝을 셉니다.

- 0.9: 0.7, 0.5, 0.3, 0.2를 모두 이김 → 4
- 0.8: 모두 이김 → 4
- 0.6: 0.5, 0.3, 0.2를 이김 (0.7에 짐) → 3
- 0.4: 0.3, 0.2를 이김 → 2

AUC = (4 + 4 + 3 + 2) ÷ 16 = 13/16 ≈ **0.81**. 계단 곡선 아래 넓이를 직접 재도 정확히 같은 값이 나옵니다.

## 3. 능동 연습 (10분)

예제의 점수 8개를 그대로 씁니다.

### ✏️ 손계산
1. 임계값 0.65일 때 불을 잡은 비율과 괜히 울린 비율은?
2. 임계값 0.45일 때 두 비율은?
3. 임계값을 0.45에서 0.65로 올렸습니다. 두 비율은 각각 오르나요, 내리나요?
4. 불 아닌 상황 20개 중 경보기가 5번 울렸습니다. 괜히 울린 비율은?
5. 다른 경보기: 진짜 불의 점수 [0.9, 0.6], 불 아님 [0.7, 0.2]. 짝 비교로 AUC는?
6. 진짜 불 점수가 [0.9, 0.8, 0.7], 불 아님이 [0.3, 0.2, 0.1]이면 AUC는?
7. 어떤 모델의 AUC가 0.3입니다. 판정을 정반대로 뒤집으면 AUC는?

### 🧩 미니 챌린지
같은 모델로 (가) 암 검진 1차 선별, (나) 스팸 필터를 만듭니다. 임계값을 각각 높게 둘까요, 낮게 둘까요? AUC는 두 경우에 달라지나요?

> (선택) **불이 아주 드물 때는 PR 곡선.** 불 10번, 불 아닌 상황 10,000번. 경보기가 불 9번을 잡고 괜히 100번 울렸다면 괜히 울린 비율은 100 ÷ 10,000 = 0.01로 아주 좋아 보입니다. 하지만 울렸을 때 진짜 불일 확률(정밀도)은 9 ÷ 109 ≈ 0.08입니다. 음성이 압도적으로 많으면 ROC는 너그럽게 보이므로, 가로축에 재현율, 세로축에 정밀도를 놓는 **PR 곡선**을 함께 봅니다.

### 💻 코드 (선택)
```python
from sklearn.metrics import roc_curve, roc_auc_score
y     = [1, 1, 1, 1, 0, 0, 0, 0]                      # 1 = 진짜 불
score = [0.9, 0.8, 0.6, 0.4, 0.7, 0.5, 0.3, 0.2]
fpr, tpr, thr = roc_curve(y, score)                   # 괜히 울린 비율, 불을 잡은 비율, 임계값
print(fpr, tpr)
print(roc_auc_score(y, score))                        # 0.8125
```

## 📝 한 줄 정리
임계값은 경보기의 민감도 다이얼이고, 다이얼 전 구간에서 (괜히 울린 비율, 불을 잡은 비율)을 이은 것이 ROC 곡선, 그 아래 넓이 AUC는 "불이 불 아닌 것보다 높은 점수를 받을 확률"이다.

**미니 챌린지**
(가) 암 검진은 놓치면 안 되니 임계값을 **낮게**(예민하게). (나) 스팸 필터는 정상 메일을 스팸함에 넣으면 곤란하니 **높게**. 모델이 같으니 점수의 줄 세우기도 같고, **AUC는 같습니다.** 달라지는 것은 ROC 곡선 위에서 어느 점을 고르느냐뿐입니다.

**퀴즈**
1. 가로축은 괜히 울린 비율(FPR), 세로축은 불을 잡은 비율(재현율, TPR)
2. 오른쪽 위로. 더 많이 울리니 두 비율이 함께 커집니다.
3. X. AUC 0.5는 동전 던지기와 같아서, 점수가 불과 불 아닌 것을 전혀 구별하지 못한다는 뜻입니다.
4. 정확도는 임계값 하나와 클래스 비율에 따라 크게 흔들리지만, AUC는 임계값을 정하기 전의 줄 세우기 실력을 하나의 숫자로 보여 주기 때문입니다.
