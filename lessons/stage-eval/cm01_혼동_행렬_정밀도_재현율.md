## 1. 개념 (8분)

### 1-1. 정확도만 보면 속는다
환자 100명 중 실제 암 환자는 5명입니다. 아무것도 배우지 않고 **무조건 "정상"이라고 말하는** 모델을 만들었습니다.

- 맞힌 사람: 정상 95명 → 정확도 **95%**
- 찾아낸 암 환자: **0명**

점수는 높은데 병원에서는 쓸모가 없습니다. 한쪽이 훨씬 많은 **불균형 데이터**에서는 정확도가 거짓말을 합니다. 그래서 맞히고 틀린 것을 **종류별로** 나눠 셉니다.

### 1-2. 화재경보기로 보는 네 칸
오늘은 비유를 하나만 씁니다. **화재경보기**입니다. 찾고 싶은 것(불, 암, 스팸)을 **양성**, 아닌 것을 **음성**이라고 부릅니다.

| | 경보기가 울림 (양성 예측) | 경보기가 조용 (음성 예측) |
|---|---|---|
| **진짜 불** (실제 양성) | **TP** 불을 잡음 | **FN** 불을 놓침 |
| **불 아님** (실제 음성) | **FP** 괜히 울림 | **TN** 조용히 잘 있음 |

이 2×2 표가 **혼동 행렬**입니다. 모델이 무엇을 무엇으로 "혼동"했는지 보여 줍니다. 약자 읽는 법: 뒤 글자는 **모델의 말**(P = 양성이라고 함, N = 음성이라고 함), 앞 글자는 **그 말이 맞았나**(T = 맞음, F = 틀림)입니다. FP는 "양성이라고 했는데 틀림" = 괜히 울림.

### 1-3. 정밀도: "울렸을 때 진짜 불이었나"
$$\text{정밀도} = \frac{TP}{TP + FP}$$

분모는 **내가 양성이라고 외친 것 전부**입니다. 경보기가 울린 횟수 중 진짜 불이었던 비율. 정밀도가 낮으면 "또 토스트 때문이겠지" 하고 아무도 경보를 믿지 않습니다. ([BLEU](#day13)의 정밀도도 "내가 쓴 것 중 맞은 비율"로 같은 생각이었습니다.)

### 1-4. 재현율: "진짜 불을 몇 번 잡았나"
$$\text{재현율} = \frac{TP}{TP + FN}$$

분모는 **진짜 양성 전부**입니다. 실제로 난 불 중에 경보기가 잡아낸 비율. 재현율이 낮으면 불이 나도 조용합니다. 1-1의 "무조건 정상" 모델은 재현율이 0입니다.

> 외우는 법: 분자는 둘 다 TP. **분모만** 다릅니다. 정밀도는 "**내가 외친 것** 중", 재현율은 "**진짜인 것** 중".

### 1-5. 둘은 시소를 탄다
경보기를 **예민하게** 만들면(토스트 연기에도 울리게) 불은 거의 다 잡지만 괜히 울리는 일이 늘어납니다. 재현율↑, 정밀도↓. **둔하게** 만들면 반대입니다. 어느 쪽을 중시할지는 상황이 정합니다.

- **암 검진:** 놓치면 큰일 → 재현율 중시 (괜한 재검사는 참을 만함)
- **스팸 필터:** 중요한 메일을 스팸함에 넣으면 큰일 → 정밀도 중시

### 1-6. F1: 약한 쪽 편을 드는 평균
두 숫자를 하나로 합치고 싶을 때 F1을 씁니다. 그냥 평균이 아니라 **조화평균**입니다.

$$F1 = \frac{2 \times \text{정밀도} \times \text{재현율}}{\text{정밀도} + \text{재현율}}$$

정밀도 1.0, 재현율 0.1인 경보기(울리면 확실히 불이지만 열 번에 한 번만 울림)를 봅시다.

- 그냥 평균: (1.0 + 0.1) ÷ 2 = **0.55** (괜찮아 보임)
- F1: 2 × 1.0 × 0.1 ÷ 1.1 ≈ **0.18** (형편없음)

F1은 둘 중 **약한 쪽에 끌려갑니다.** 하나가 0이면 F1도 0입니다. 그래서 한쪽만 잘하는 꼼수 모델을 걸러 냅니다.

## 2. 예제 따라하기 (6분)

환자 20명(실제 환자 12명, 건강한 사람 8명)을 모델이 분류했습니다.

| | 양성 예측 | 음성 예측 | 합 |
|---|---|---|---|
| 실제 환자 | TP = 8 | FN = 4 | 12 |
| 실제 건강 | FP = 2 | TN = 6 | 8 |

1. 정확도: (8 + 6) ÷ 20 = **0.7**
2. 정밀도: 양성이라고 한 사람은 8 + 2 = 10명, 그중 진짜 환자 8명 → 8 ÷ 10 = **0.8**
3. 재현율: 진짜 환자 12명 중 찾은 사람 8명 → 8 ÷ 12 ≈ **0.67**
4. F1: 2 × 0.8 × 0.67 ÷ (0.8 + 0.67) ≈ **0.73**

계산은 언제나 같은 순서입니다. **분모가 어느 줄(가로 = 실제)인지, 어느 칸(세로 = 예측)인지**부터 정하세요. 정밀도는 세로 칸 "양성 예측", 재현율은 가로 줄 "실제 환자"입니다.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 환자 카드를 눌러 판정을 바꿔 보세요. 2×2 표와 네 지표가 바로 다시 계산됩니다. "모두 음성"을 누르면 정확도의 함정이 보이고, 아래쪽 상황 카드에서는 어느 지표를 중시할지 고를 수 있습니다.

### ✏️ 손계산
1. 메일 1,000통 중 스팸 10통. 모든 메일을 "정상"이라고 하는 필터의 정확도와 재현율은?
2. TP 9, FP 1, FN 3, TN 7. 정밀도는?
3. 2번 표의 재현율은?
4. 2번 표의 정확도는?
5. 정밀도 0.5, 재현율 0.5일 때 F1은? 그냥 평균과 비교하면?
6. 정밀도 0.9, 재현율 0.3일 때 F1은? (2 × 0.9 × 0.3 = 0.54)
7. 경보기를 더 예민하게 바꿨더니 FN이 4에서 1로 줄고 FP가 2에서 6으로 늘었습니다(TP 8 → 11). 재현율과 정밀도는 각각 오르나요, 내리나요?

### 🧩 미니 챌린지
공장 불량품 검사, 유튜브 추천, 사기 거래 탐지. 각각 정밀도와 재현율 중 무엇을 더 중시해야 할까요? 정답은 하나가 아닙니다. "무엇을 놓치면 / 무엇을 괜히 잡으면 손해인가"로 이유를 말해 보세요.

### 💻 코드 (선택)
```python
from sklearn.metrics import confusion_matrix, precision_score, recall_score, f1_score
y_true = [1]*12 + [0]*8                        # 실제: 환자 12, 건강 8
y_pred = [1]*8 + [0]*4 + [1]*2 + [0]*6         # 예측
print(confusion_matrix(y_true, y_pred))        # [[6 2]
                                               #  [4 8]]  ← 줄 순서가 음성(0) 먼저!
print(precision_score(y_true, y_pred),         # 0.8
      recall_score(y_true, y_pred),            # 0.666...
      f1_score(y_true, y_pred))                # 0.727...
```

## 📝 한 줄 정리
혼동 행렬의 네 칸으로 정밀도("외친 것 중 진짜", TP ÷ (TP + FP))와 재현율("진짜 중 잡은 것", TP ÷ (TP + FN))을 구하고, 불균형 데이터에서는 정확도 대신 이 둘과 F1을 본다.

**손계산**
1. 정확도 990 ÷ 1,000 = **99%**, 재현율 0 ÷ 10 = **0**

**미니 챌린지 (예시)**
불량품 검사: 불량을 놓치면 고객 손에 들어가니 **재현율**. 유튜브 추천: 엉뚱한 영상을 띄우면 사용자가 떠나고, 좋은 영상 몇 개를 빠뜨려도 큰 손해는 없으니 **정밀도**. 사기 탐지: 놓치면 돈을 잃지만 정상 거래를 너무 막으면 고객이 화를 냅니다. 보통 **재현율**을 높이되 정밀도가 너무 떨어지지 않게 F1이나 비용으로 균형을 봅니다.

**퀴즈**
1. 정밀도는 양성이라고 예측한 것 전부(TP + FP), 재현율은 실제 양성 전부(TP + FN)
2. X. "무조건 음성" 모델은 정확도 99%여도 재현율이 0입니다.
3. 약한 쪽에 끌려가서, 한쪽만 높은 모델이 좋은 점수를 받지 못하게 하려고요.
4. 재현율은 오르고 정밀도는 내립니다.
