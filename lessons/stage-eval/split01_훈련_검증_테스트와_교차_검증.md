## 1. 개념 (8분)

### 1-1. 진짜 목표는 "처음 보는 문제"
[로지스틱 회귀](#logi01)는 학생 몇 명의 데이터로 커트라인을 배웠습니다. 그런데 우리가 정말 궁금한 것은 그 학생들이 아니라 **내년에 올 처음 보는 학생**을 잘 맞히느냐입니다. 처음 보는 데이터에서도 잘하는 능력을 **일반화**라고 합니다.

배운 데이터로 점수를 매기면 안 됩니다. 기출문제를 외운 학생에게 같은 기출문제로 시험을 보면 100점이 나오지만, 그 점수는 실력을 말해 주지 않습니다.

### 1-2. 세 무더기: 문제집, 모의고사, 수능
그래서 데이터를 처음부터 셋으로 나눠 둡니다.

| 무더기 | 시험 비유 | 하는 일 | 흔한 비율 |
|---|---|---|---|
| **훈련 세트** | 연습문제집 | 모델이 보고 w, b를 배움 | 60~80% |
| **검증 세트** | 모의고사 | 여러 설정 중 무엇이 나은지 고름 | 10~20% |
| **테스트 세트** | 수능 | 맨 마지막에 **딱 한 번** 실력을 잼 | 10~20% |

예: 데이터 1,000개를 60:20:20으로 나누면 600 / 200 / 200개입니다.

### 1-3. 하이퍼파라미터는 검증 세트로 고른다
모델이 데이터에서 **스스로 배우는** 숫자(w, b)가 있고, 학습 전에 **사람이 정해 주는** 숫자가 있습니다. [학습률](#opt01), 층의 개수, 학습을 몇 바퀴 돌릴지 같은 것들입니다. 이런 설정값을 **하이퍼파라미터**라고 부릅니다. ("파라미터를 정하는 파라미터"라는 뜻입니다.)

하이퍼파라미터는 이렇게 고릅니다.
1. 후보마다 **훈련 세트로** 모델을 학습시킨다
2. 각 모델을 **검증 세트로** 채점한다
3. 검증 점수가 가장 좋은 후보를 고른다

### 1-4. 검증과 테스트는 왜 따로 둘까?
둘 다 "모델이 안 본 데이터"인데 왜 둘일까요? 모의고사 점수를 보고 공부법을 이리저리 바꿨다면, 그 모의고사 점수는 이제 **내 공부법에 맞춰진 점수**입니다. 실력보다 높게 나오기 쉽습니다.

숫자로 보면 더 분명합니다. 실력이 똑같이 80%인 설정 20개를 검증 세트로 채점하면, 운에 따라 76%, 83%, 79%… 처럼 흩어집니다. 그중 **최고점**을 고르면 운 좋게 85%가 나온 후보일 가능성이 큽니다. 이 85%를 그대로 보고하면 실제 실력(80%)보다 부풀린 셈입니다.

그래서 고르는 데 **한 번도 쓰지 않은** 테스트 세트가 따로 필요합니다. 테스트 점수를 보고 다시 설정을 바꾸면, 테스트 세트도 모의고사가 되어 버립니다. 그래서 **마지막에 한 번만** 씁니다.

### 1-5. 데이터가 적으면: k겹 교차 검증
데이터가 100개뿐이면 20개만 검증에 떼어 두기도 아깝고, 어떤 20개를 떼느냐에 따라 점수가 크게 흔들립니다. 그래서 **돌아가며** 검증합니다.

**5겹 교차 검증:**
1. 데이터를 5조각(겹)으로 나눈다. 100개라면 20개씩
2. 1번 조각을 검증, 나머지 80개로 학습 → 점수 1
3. 2번 조각을 검증, 나머지로 학습 → 점수 2 … 5번까지
4. 점수 5개를 **평균** 낸다

모든 데이터가 한 번씩 검증에 쓰이고, 다섯 번의 평균이라 운이 덜 섞입니다. 대신 학습을 **5번** 해야 합니다. 조각 수 k는 5나 10을 많이 씁니다. 교차 검증도 **설정을 고르는 일**(검증 세트의 역할)을 하는 것이고, 테스트 세트는 그와 별도로 아껴 둡니다.

### 1-6. 데이터 누수: 시험지가 새는 사고
**데이터 누수**는 실제로 예측할 때는 알 수 없는 정보가 학습이나 채점에 몰래 섞이는 것입니다. 점수는 놀랍게 좋은데 실전에서는 무너집니다. 흔한 세 가지:

- **미래 정보가 든 특징:** 집값을 예측하는데 "거래 후에 매긴 취득세"를 입력에 넣음. 세금은 거래 가격으로 계산하니 정답을 거의 그대로 알려 주는 셈입니다
- **나누기 전에 전체로 계산:** [정규화](#norm01)의 평균과 표준편차를 테스트 세트까지 포함한 전체 데이터로 구한 뒤 나눔. 테스트 세트의 정보가 훈련에 스며듭니다. 평균·표준편차는 **훈련 세트로만** 구해야 합니다
- **같은 대상이 양쪽에:** 같은 환자의 엑스레이 사진 여러 장이 훈련과 테스트에 나뉘어 들어감. 모델이 병이 아니라 "그 환자"를 알아봐도 점수가 나옵니다

판별 질문 하나: **"실제로 예측하는 그 순간에, 이 정보를 알 수 있나?"** 모르면 빼야 합니다.

## 2. 예제 따라하기 (6분)

데이터 100개, 5겹 교차 검증으로 하이퍼파라미터 후보 A와 B를 비교합니다.

| 검증 조각 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 후보 A 정확도 | 0.80 | 0.85 | 0.75 | 0.90 | 0.80 |
| 후보 B 정확도 | 0.88 | 0.86 | 0.84 | 0.90 | 0.87 |

1. **조각 크기:** 100 ÷ 5 = 20개. 매번 80개로 학습, 20개로 검증
2. **A의 평균:** (0.80 + 0.85 + 0.75 + 0.90 + 0.80) ÷ 5 = 4.10 ÷ 5 = **0.82**
3. **B의 평균:** (0.88 + 0.86 + 0.84 + 0.90 + 0.87) ÷ 5 = 4.35 ÷ 5 = **0.87**
4. **고르기:** B가 높으므로 B를 고릅니다. B는 조각마다 점수가 고르게 나와 더 믿음직합니다 (A는 0.75~0.90, B는 0.84~0.90)
5. **마무리:** B 설정으로 데이터 전체를 다시 학습하고, 따로 떼어 둔 테스트 세트로 **한 번** 채점해 보고합니다

모두 몇 번 학습했나요? 후보 2개 × 5겹 = **10번**, 마지막 학습 1번까지 11번입니다.

## 3. 능동 연습 (10분)

아래 실습 위젯의 "누수 탐정"에서 집값 예측에 쓰면 안 되는 특징 카드를 골라내 보세요. 두 번째 탭에서는 5겹 교차 검증이 돌아가는 모습을 한 겹씩 볼 수 있습니다(선택).

### ✏️ 손계산
1. 데이터 2,000개를 70:15:15로 나누면 훈련·검증·테스트는 각각 몇 개인가요?
2. 데이터 50개로 5겹 교차 검증을 합니다. 한 번 학습할 때 훈련에 쓰는 데이터는 몇 개인가요?
3. 5겹 점수가 0.70, 0.75, 0.80, 0.85, 0.90이면 교차 검증 점수는?
4. 하이퍼파라미터 후보 4개를 10겹 교차 검증으로 비교합니다. 학습은 모두 몇 번 하나요? (마지막 재학습은 빼고)
5. 다음 중 하이퍼파라미터는? (가) 가중치 w (나) 학습률 (다) 편향 b (라) 층의 개수
6. 다음 중 누수인 것은? (가) 학생의 공부 시간으로 합격 예측 (나) "합격자 오리엔테이션 참석 여부"로 합격 예측 (다) 집 면적으로 집값 예측

### 🧩 미니 챌린지
어떤 팀이 "검증 세트에서 정확도 99%!"라며 기뻐합니다. 알고 보니 설정을 300번 바꿔 가며 같은 검증 세트로 채점했고, 테스트 세트는 없습니다. 이 99%를 믿기 어려운 이유와, 지금이라도 할 수 있는 일을 말해 보세요.

### 💻 코드 (선택)
```python
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True)
# 테스트 세트는 처음에 떼어 두고 끝까지 건드리지 않기
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)

for C in [0.01, 1.0]:      # 하이퍼파라미터 후보 두 개 (C가 작을수록 규제가 셈. 규제는 다음다음 챕터에서)
    m = LogisticRegression(C=C, max_iter=5000)
    scores = cross_val_score(m, X_tr, y_tr, cv=5)   # 5겹 교차 검증 (훈련 세트 안에서만)
    print(C, scores.round(2), scores.mean().round(3))

best = LogisticRegression(C=1.0, max_iter=5000).fit(X_tr, y_tr)
print("테스트 정확도:", best.score(X_te, y_te))     # 마지막에 한 번만
# 0.01 → 평균 0.943, 1.0 → 평균 0.956 → C = 1.0을 고름. 테스트 정확도 약 0.947
```

## 📝 한 줄 정리
훈련 세트로 배우고, 검증 세트(또는 k겹 교차 검증)로 설정을 고르고, 테스트 세트는 마지막에 한 번만 쓴다. 예측하는 순간에 알 수 없는 정보가 섞이면 데이터 누수다.
