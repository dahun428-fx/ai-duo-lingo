## 1. 개념 (8분)

### 1-1. 실패는 두 가지
기출문제집으로 공부하는 두 학생을 떠올려 봅시다.

- **덜 배운 학생:** 공부를 대충 해서 기출문제도 60점, 새 문제도 60점
- **외운 학생:** 기출문제의 답을 **번호째 외웠습니다**. 기출문제는 100점, 그런데 숫자만 바꾼 새 문제는 40점

첫째가 **과소적합**, 둘째가 **과적합**입니다. 모델도 똑같습니다. 과소적합은 데이터의 규칙을 다 담지 못한 상태, 과적합은 규칙뿐 아니라 **우연한 잡음까지 외운** 상태입니다. 우리가 원하는 것은 규칙만 배워 새 문제도 잘 푸는 **일반화**입니다.

### 1-2. 모델의 용량: 얼마나 구불구불할 수 있나
점 10개에 곡선을 맞춘다고 합시다. 쓸 수 있는 곡선의 종류가 모델의 **용량**(복잡도)입니다.

- **1차식** (직선, a + bx): 아무리 해도 휘지 못함
- **3차식** (x, x², x³까지 섞음): 한두 번 휠 수 있음
- **9차식** (x⁹까지): 점 10개를 **모두 정확히 지나는** 곡선도 만들 수 있음

차수를 올릴수록 용량이 커집니다. 신경망에서는 층과 뉴런이 많을수록 용량이 큽니다.

아래 실습 위젯의 점 10개(훈련 세트)와 그 사이의 다른 점 10개(검증 세트)로 잰 평균제곱 손실([pt01의 MSE](#pt01))입니다.

| 차수 | 훈련 손실 | 검증 손실 | 진단 |
|---|---|---|---|
| 1 | 0.17 | 0.17 | 둘 다 높음 → **과소적합** |
| 3 | 0.02 | 0.03 | 둘 다 낮고 가까움 → **딱 좋음** |
| 9 | 0.00 | 1.10 | 훈련만 완벽, 검증은 폭망 → **과적합** |

9차식은 훈련 점을 모두 지나지만, 점과 점 **사이**에서 크게 출렁여 처음 보는 점을 엉뚱하게 예측합니다.

### 1-3. 진단표: 두 숫자를 같이 본다
| 훈련 손실 | 검증 손실 | 상태 | 처방 |
|---|---|---|---|
| 높음 | 높음 (비슷) | 과소적합 | 용량 늘리기 (차수, 층), 더 오래 학습 |
| 낮음 | **훨씬 높음** | 과적합 | 데이터 늘리기, 용량 줄이기, 규제 |
| 낮음 | 낮음 (비슷) | 적당 | 테스트 세트로 마지막 확인 |

핵심은 **두 손실의 차이**(검증 − 훈련)입니다. 크게 벌어지면 외우고 있다는 신호입니다. 훈련 손실만 보면 9차식이 최고로 보이니 꼭 둘을 같이 보세요.

### 1-4. 학습 곡선: 시간에 따라 그리기
같은 모델이라도 **오래 학습할수록** 훈련 데이터에 더 딱 맞춰집니다. 데이터 전체를 한 바퀴 다 보는 것을 **에폭**이라고 합니다([Adam과 학습률](#opt01)에서 본 그 단어). 에폭마다 두 손실을 찍은 그래프가 **학습 곡선**입니다.

- **훈련 손실:** 거의 계속 내려갑니다
- **검증 손실:** 처음엔 같이 내려가다가, 어느 순간부터 **다시 올라갑니다**. U자 모양

검증 손실이 바닥을 찍고 오르기 시작하는 곳부터가 과적합입니다. 그 바닥에서 멈추는 방법은 다음 챕터 [규제](#reg01)에서 "조기 중단"으로 배웁니다.

### 1-5. 편향-분산 트레이드오프: 과녁 그림
같은 모델을 **다른 훈련 데이터**로 여러 번 학습시켰다고 상상해 봅시다. 결과를 과녁에 화살로 찍습니다. 과녁 한가운데가 정답입니다.

- **편향**: 화살들의 **평균 위치**가 한가운데서 얼마나 비켜났나. 모델이 너무 단순해 늘 같은 쪽으로 틀리는 정도
- **분산**: 화살들이 **얼마나 흩어졌나**. 훈련 데이터가 조금만 바뀌어도 결과가 출렁이는 정도. [기댓값과 분산](#ev01)의 분산과 **같은 뜻**입니다

| 모델 | 편향 | 분산 | 상태 |
|---|---|---|---|
| 1차식 (너무 단순) | 큼 | 작음 | 과소적합 |
| 9차식 (너무 복잡) | 작음 | 큼 | 과적합 |

용량을 키우면 편향은 줄고 분산은 늘어납니다. 둘을 한꺼번에 0으로 만들 수 없어서 **트레이드오프**(주고받기)라고 부릅니다. 실제 오차는 대략 **편향² + 분산**(+ 어떤 모델도 없앨 수 없는 잡음)이라, 둘의 합이 가장 작은 중간 용량이 좋습니다.

> **같은 글자, 다른 뜻: "편향"**
> - [day02](#day02)의 **편향 b**: Wx + b의 b. 모델이 배우는 숫자 하나 (bias 항)
> - [day10](#day10)의 **노출 편향**: 학습 땐 정답만 보다가 추론 땐 자기 예측을 봐서 생기는 불일치
> - 오늘의 **편향**: 모델이 평균적으로 정답에서 비켜난 정도 (편향-분산의 편향)
>
> 영어로는 모두 bias지만 셋은 서로 관계가 없습니다. 문맥으로 구별하세요.

> (선택) **이중 하강:** 아주 큰 신경망에서는 훈련 데이터를 완벽히 외우는 지점을 **훨씬 넘겨** 용량을 더 키우면 검증 손실이 **다시 내려가는** 현상이 관찰됩니다. U자 뒤에 두 번째 내리막이 붙어서 이중 하강(double descent)이라고 부릅니다 (Belkin 외 2019). 거대한 언어 모델이 과적합으로 무너지지 않는 이유와 이어지는 연구 주제로, 나중에 11단계 "스케일링 법칙"에서 다시 떠올리면 됩니다. 지금은 "U자 그림에도 예외가 있다"만 알아 두세요.

## 2. 예제 따라하기 (6분)

**① 학습 곡선 읽기.** 에폭별 손실입니다.

| 에폭 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 훈련 손실 | 2.0 | 1.2 | 0.8 | 0.5 | 0.3 | 0.2 |
| 검증 손실 | 2.1 | 1.4 | 1.1 | 1.0 | 1.2 | 1.5 |

1. 훈련 손실은 끝까지 내려갑니다
2. 검증 손실은 에폭 **4**에서 가장 낮고(1.0), 5부터 올라갑니다 → 에폭 5부터 과적합
3. 차이(검증 − 훈련): 에폭 4는 1.0 − 0.5 = **0.5**, 에폭 6은 1.5 − 0.2 = **1.3**. 점점 벌어집니다
4. 고를 모델: 검증 손실이 가장 낮은 **에폭 4**의 모델

**② 과녁 숫자로 편향과 분산.** 정답은 0입니다. 같은 모델을 훈련 데이터만 바꿔 4번 학습시킨 예측값입니다.

- 모델 A: 3, 3, 3, 3 → 평균 **3** (편향 3), 모두 같은 곳이라 분산 **0**
- 모델 B: −2, 2, −2, 2 → 평균 **0** (편향 0), 평균에서 모두 2씩 떨어져 분산 2² = **4**

오차(정답에서 떨어진 거리의 제곱의 평균)는 A가 3² = 9, B가 2² = 4. 편향² + 분산으로도 A는 9 + 0 = **9**, B는 0 + 4 = **4**로 같습니다. A는 늘 같은 쪽으로 틀리는 단순한 모델, B는 맞을 듯 말 듯 흔들리는 복잡한 모델입니다.

## 3. 능동 연습 (10분)

아래 실습 위젯에서 차수 다이얼(1~9)을 돌려 보세요. 곡선 모양과 훈련 손실·검증 손실 막대가 함께 바뀝니다. 검증 손실이 가장 낮은 차수를 찾으면 성공입니다.

### ✏️ 손계산
1. 훈련 손실 0.9, 검증 손실 1.0인 모델은 어떤 상태일 가능성이 큰가요? (참고로 비슷한 문제에서 다른 모델들은 훈련 손실 0.2까지 내려갑니다)
2. 훈련 손실 0.05, 검증 손실 0.80인 모델의 차이(검증 − 훈련)는? 어떤 상태인가요?
3. 검증 손실이 에폭마다 1.5, 1.1, 0.9, 0.95, 1.2였습니다. 몇 번째 에폭에서 멈추는 게 좋을까요?
4. 정답이 0일 때 예측값 1, 1, 1, 1의 편향과 분산은?
5. 정답이 0일 때 예측값 −3, 3, −3, 3의 편향과 분산은? 편향² + 분산은?
6. 과적합 상태인 모델에 도움이 되지 않는 것은? (가) 훈련 데이터 늘리기 (나) 차수를 9에서 3으로 줄이기 (다) 차수를 9에서 15로 늘리기

### 🧩 미니 챌린지
점이 10개뿐일 때는 9차식이 과적합했습니다. 같은 모양의 데이터를 1,000개 모은다면 9차식은 어떻게 될까요? 9차식이 점 1,000개를 모두 지날 수 있을지 생각해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
x_tr = np.linspace(-1, 1, 10)
y_tr = np.array([-0.16, -1.01, -0.9, -0.56, -0.46, 0.51, 0.56, 1.05, 0.71, 0.51])
x_va = np.array([-0.9, -0.7, -0.5, -0.3, -0.1, 0.1, 0.3, 0.5, 0.7, 0.9])
y_va = np.array([-0.66, -0.77, -1.19, -0.65, -0.08, 0.13, 0.85, 0.94, 1.12, 0.46])

for d in [1, 3, 9]:
    c = np.polyfit(x_tr, y_tr, d)                       # 훈련 세트로 d차식 맞추기
    tr = np.mean((np.polyval(c, x_tr) - y_tr) ** 2)     # 훈련 손실
    va = np.mean((np.polyval(c, x_va) - y_va) ** 2)     # 검증 손실
    print(d, round(tr, 2), round(va, 2))
# 1 0.17 0.17
# 3 0.02 0.03
# 9 0.0 1.1
```

## 📝 한 줄 정리
훈련 손실과 검증 손실이 둘 다 높으면 과소적합, 훈련만 낮고 검증이 높으면 과적합이다. 용량을 키우면 편향은 줄고 분산은 늘어서, 검증 손실이 가장 낮은 중간에서 멈춘다.

**손계산**

6. **(다).** 용량을 더 키우면 더 잘 외울 뿐이라 과적합이 심해집니다

**미니 챌린지**

**퀴즈**
1. 과소적합: 모델이 너무 단순하거나 덜 배워서 훈련 데이터조차 잘 못 맞힘. 과적합: 훈련 데이터의 잡음까지 외워서 새 데이터를 못 맞힘
2. 훈련 손실은 계속 내려가는데 검증 손실은 바닥을 찍고 다시 올라가, 두 곡선 사이가 벌어집니다
3. X. 훈련 데이터를 외웠을 수 있습니다. 검증 손실을 같이 봐야 합니다
4. 아닙니다. 편향-분산의 편향은 "평균적으로 정답에서 비켜난 정도"이고, Wx + b의 b는 모델이 배우는 숫자 하나입니다. 영어 단어(bias)만 같습니다
