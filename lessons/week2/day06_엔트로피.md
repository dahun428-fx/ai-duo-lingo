## 1. 개념 (8분)

### 1-1. 정보량 = 놀람의 크기
- "내일 해가 뜬다" (p ≈ 1) → 하나도 안 놀람 → 정보 거의 0
- "내일 서울에 눈이 1미터 온다" (p 아주 작음) → 엄청 놀람 → 정보 많음

이걸 식으로:
$$I(x) = -\log_2 p(x) \quad \text{(단위: 비트, bit)}$$

| p | −log₂ p | 해석 |
|---|---|---|
| 1 | 0 | 확실한 일, 정보 없음 |
| 1/2 | 1 | 동전 앞뒤 하나 = 1비트 |
| 1/4 | 2 | |
| 1/8 | 3 | 예/아니오 질문 3번 분량 |

**왜 로그?** 독립인 두 사건의 정보량이 **더해지게** 하려고. p(A,B) = p(A)p(B) → −log p(A,B) = −log p(A) − log p(B). (Day 05의 "곱 → 합")

### 1-2. 엔트로피 = 평균 놀람
$$H(p) = -\sum_x p(x)\log_2 p(x)$$
가능한 결과마다 "놀람 × 그 결과가 나올 확률"을 더한 것, 즉 **놀람의 기댓값**입니다.

### 1-3. 언제 크고 언제 작은가
- **최소 (0):** 한 결과의 확률이 1 → 결과를 이미 앎
- **최대:** 모든 결과가 똑같이 그럴듯함 (균등분포). 결과가 n개면 $\log_2 n$
- **직관:** 엔트로피 = **불확실성**. "다음에 뭐가 나올지 얼마나 모르는가"

### 1-4. 언어 모델과 연결
모델이 다음 단어로 80,000개 단어에 균등하게 확률을 주면 엔트로피는 $\log_2 80000 ≈ 16.3$비트. 학습된 모델은 "the 다음엔 명사가 오겠지" 같은 지식으로 불확실성을 확 줄입니다. 학습 = 엔트로피(정확히는 내일 배울 크로스엔트로피)를 줄이는 과정!

> 📌 자연로그(ln)를 쓰면 단위가 "nat"이 됩니다. 딥러닝 코드는 대부분 자연로그를 씁니다. 비트와 nat은 상수배 차이일 뿐 (1 nat ≈ 1.443 bit).

## 2. 예제 따라하기 (6분)

**① 공정한 동전** p = [0.5, 0.5]
H = −(0.5×log₂0.5 + 0.5×log₂0.5) = −(0.5×(−1) + 0.5×(−1)) = **1비트**

**② 찌그러진 동전** p = [0.9, 0.1] (log₂0.9 ≈ −0.152, log₂0.1 ≈ −3.322)
H = −(0.9×(−0.152) + 0.1×(−3.322)) = 0.137 + 0.332 = **0.469비트**
→ 결과가 거의 예측되니 불확실성이 절반 이하로.

**③ 주사위** p = [1/6]×6
H = log₂6 ≈ **2.585비트**

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. 확률 1/16인 사건이 일어났을 때 정보량은 몇 비트?
2. p = [0.25, 0.25, 0.25, 0.25]의 엔트로피는?
3. p = [0.5, 0.25, 0.25]의 엔트로피는? (log₂ 값은 −1, −2, −2)
4. p = [1, 0, 0]의 엔트로피는? (약속: 0 × log 0 = 0)
5. 다음 두 모델 중 "the cat sat on the ___" 다음 단어에 대해 엔트로피가 더 낮은 쪽은? 그게 꼭 좋은 걸까요?
   - A: [mat 0.7, floor 0.2, 기타 0.1]
   - B: [mat 0.34, floor 0.33, 기타 0.33]

### 💻 코드
```python
import numpy as np

def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                          # 0 * log 0 = 0 처리
    return -(p * np.log(p)).sum() / np.log(base) + 0.0   # +0.0: -0.0 표시 방지

for name, p in [("공정 동전", [0.5, 0.5]),
                ("찌그러진 동전", [0.9, 0.1]),
                ("주사위", [1/6] * 6),
                ("확실", [1, 0, 0])]:
    print(f"{name:8s} H = {entropy(p):.3f} bit")

# 동전 앞면 확률 q를 0~1로 바꾸며 엔트로피 관찰
for q in [0.01, 0.1, 0.3, 0.5, 0.7, 0.9, 0.99]:
    print(q, round(entropy([q, 1 - q]), 3))
```

**도전 과제**
- (a) 위 결과를 보고 "동전 엔트로피 곡선"을 노트에 손으로 그려 보세요 (가로 q, 세로 H). 어디서 최대인가요?
- (b) 한국어 문장 하나(예: "가나다라가나가가")의 글자 빈도로 확률분포를 만들고 엔트로피를 구해 보세요. (힌트: `from collections import Counter`)
- (c) `entropy([1/80000] * 80000)`이 `np.log2(80000)`과 같은지 확인하세요.
