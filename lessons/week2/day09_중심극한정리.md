## 1. 개념 (8분)

### 1-1. 기댓값과 분산
- **기댓값** $E[X]$: 무한히 반복했을 때의 평균
- **분산** $\text{Var}(X) = E[(X - E[X])^2]$: 평균에서 얼마나 흩어지나
- **표준편차** $\sigma = \sqrt{\text{Var}}$: 원래 단위로 본 흩어짐

주사위: E = 3.5, Var = 35/12 ≈ 2.917, σ ≈ 1.708 (표로 계산하는 과정은 [기댓값과 분산](#ev01))

### 1-2. 더하고 평균 내면 생기는 일 (독립일 때)
- 합: $\text{Var}(X_1 + \dots + X_n) = n\,\sigma^2$
- 평균: $\text{Var}(\bar X) = \sigma^2 / n$ → 표준편차는 $\sigma/\sqrt n$

**n개를 평균내면 흔들림이 √n분의 1로 줄어듭니다.** (4배 모으면 흔들림 절반)

### 1-3. 중심극한정리 (CLT)
> 독립이고 같은 분포를 따르며 **분산이 유한한**(값이 끝없이 튀지 않는) 무작위 값들을 충분히 많이 더하면(또는 평균 내면), **원래 분포 모양과 상관없이** 그 합은 **정규분포(종 모양)** 에 가까워진다.

$$\bar X \approx \mathcal N\Big(\mu,\ \frac{\sigma^2}{n}\Big)$$

주사위 하나는 평평한(균등) 분포인데, 주사위 30개의 평균은 3.5 근처에 몰린 종 모양이 됩니다.

### 1-4. 논문 연결 ① 초기화 (선택, 결과만 읽기)
모든 파라미터를 $U(-0.08, 0.08)$에서 뽑습니다. 균등분포 $U(-a, a)$(−a와 a 사이에서 아무 수나 똑같은 확률로 뽑기)의 분산은 $a^2/3$. 이 값은 증명 없이 결과만 쓰면 됩니다.
뉴런 하나의 입력은 $z = \sum_{i=1}^{1000} w_i x_i$, 즉 **무작위 값 1000개의 합** → CLT에 의해 z는 대략 정규분포!
분산 = 1000 × Var(w) × Var(x). 이 값이 너무 크면 tanh·sigmoid가 포화(평평한 끝)되어 학습이 안 되고, 너무 작으면 신호가 사라집니다. **초기화 범위(0.08)를 고르는 건 결국 "합의 분산"을 조절하는 일**이에요.

> **68-95-99.7 규칙.** 정규분포(종 모양)에서는 평균 ± 1σ 안에 약 68%, ± 2σ 안에 약 95%, ± 3σ 안에 약 99.7%가 들어갑니다. 그래서 2σ 넘게 위로 벗어나는 경우는 약 2.5%(어림으로 2~3%)뿐입니다.

### 1-5. 논문 연결 ② 미니배치 기울기
배치 128개 문장의 기울기를 더한 뒤 128로 나눕니다 (3.4절). 128개 기울기의 **평균** → CLT에 의해 "진짜 기울기" 주위의 정규분포를 따르고, 흔들림은 $1/\sqrt{128} ≈ 1/11.3$로 줄어듭니다. 그래서 일부 데이터만 봐도 꽤 믿을 만한 방향을 얻습니다.

## 2. 예제 따라하기 (6분)

**① 표본평균의 흔들림:** 주사위 σ ≈ 1.708
- 주사위 4개 평균의 σ = 1.708/√4 ≈ **0.854**
- 주사위 100개 평균의 σ = 1.708/10 ≈ **0.171** → 평균이 대략 3.5 ± 0.34(2σ) 안에 95% 확률로 들어옴

**② 논문 초기화의 분산:** a = 0.08
- Var(w) = 0.08²/3 = 0.0064/3 ≈ **0.00213**, σ_w ≈ 0.046
- 입력 x들이 분산 1이라고 하면, z = Σ₁₀₀₀ wᵢxᵢ의 분산 ≈ 1000 × 0.00213 = **2.13**, σ_z ≈ **1.46**
- → z는 대략 N(0, 1.46²). 약 96%가 −3 ~ 3 안에 들어옴. tanh는 |z|가 2를 넘으면 이미 평평해지기 시작하므로, "포화가 전혀 없다"가 아니라 "출력이 ±1에 완전히 붙어 버리지는 않는다" 정도로 읽으세요. (입력의 분산이 1이라는 것은 계산을 쉽게 하려는 가정입니다.)

### 💻 코드: CLT를 눈으로 보기
```python
import numpy as np
rng = np.random.default_rng(0)

def text_hist(x, bins=15, width=40):
    counts, edges = np.histogram(x, bins=bins)
    for c, e in zip(counts, edges):
        print(f"{e:7.2f} | " + "#" * int(width * c / counts.max()))

# 1) 주사위 1개 vs 주사위 30개의 평균
one = rng.integers(1, 7, size=100_000)
mean30 = rng.integers(1, 7, size=(100_000, 30)).mean(axis=1)
print("주사위 1개"); text_hist(one, bins=6)
print("\n주사위 30개 평균"); text_hist(mean30)
print("예측 σ:", 1.708 / np.sqrt(30), " 실제 σ:", mean30.std())

# 2) 논문 초기화: z = Σ w_i x_i
W = rng.uniform(-0.08, 0.08, size=(5000, 1000))   # 뉴런 5000개
x = rng.standard_normal(1000)
z = W @ x
print("\n초기화 후 z 분포 (σ 예측 ≈ 1.46):", z.std().round(3)); text_hist(z)
```
