## 1. 개념 (8분)

> 오늘부터는 딥러닝 관례대로 **자연로그(ln)** 를 씁니다 (단위 nat).

### 1-1. 두 분포 비교하기
- **p**: 진짜 분포 (정답)
- **q**: 모델이 예측한 분포

$$H(p, q) = -\sum_x p(x)\log q(x)$$

엔트로피 식에서 log 안만 q로 바뀌었습니다. 뜻: "**실제로는 p를 따라 일이 벌어지는데, 나는 q라고 믿고 있을 때** 느끼는 평균 놀람."

### 1-2. 핵심 성질
$$H(p, q) \ge H(p), \qquad \text{등호는 } q = p \text{ 일 때만}$$
모델이 진짜 분포와 정확히 같아질 때 크로스엔트로피가 가장 작습니다. → **크로스엔트로피를 줄이면 모델이 진짜에 가까워진다.** 이것이 학습의 원리!

### 1-3. KL 발산 = "추가로 놀란 양" (선택)
$$D_{KL}(p\,\|\,q) = H(p, q) - H(p) = \sum_x p(x)\log\frac{p(x)}{q(x)} \ \ge 0$$
진짜 분포를 몰라서 생기는 **낭비(추가 놀람)**. p가 고정이면 H(p)는 상수라서, **크로스엔트로피 최소화 = KL 최소화**입니다.
주의: KL은 거리처럼 쓰지만 대칭이 아닙니다. $D_{KL}(p\|q) \ne D_{KL}(q\|p)$.

### 1-4. 정답이 원-핫일 때 (분류·언어모델의 실제 상황)
학습 데이터에서 다음 단어 정답은 하나, 예를 들어 "mat". 그러면 p = [0, ..., 1(mat), ..., 0].
$$H(p, q) = -\big(0 + \dots + 1\cdot\log q(\text{mat}) + \dots + 0\big) = -\log q(\text{mat})$$
→ **"정답 단어에 준 확률의 음의 로그."** 정답에 1을 주면 손실 0, 0에 가깝게 주면 손실 → ∞.

### 1-5. 논문의 학습 목표 다시 쓰기
Day 03 식 (1) + Day 05 로그:
$$\log p(T\mid S) = \sum_{t=1}^{T'} \log p(y_t\mid v, y_{<t})$$
그러니까
$$-\log p(T\mid S) = \sum_t \underbrace{-\log p(y_t\mid v, y_{<t})}_{t\text{번째 단어의 크로스엔트로피}}$$
$y_{<t}$는 "t번째보다 앞의 단어들 전부" ($y_1, \dots, y_{t-1}$)를 짧게 쓴 것입니다.

논문이 말하는 "로그 확률을 최대화"는 **"모든 위치의 크로스엔트로피 합을 최소화"** 와 같은 말입니다. 맨 위 식 읽기: $(T,S)\in S$는 "학습 데이터 S에 들어 있는 문장 쌍 (T, S) 하나하나에 대해"(∈는 "~에 속한다"), $|S|$는 그 쌍의 개수입니다. 그래서 $\frac{1}{|S|}\sum$는 모든 문장 쌍의 로그 확률 **평균**입니다 ([준비 5](#prep05)). 같은 글자 S가 원문 문장과 데이터셋을 함께 가리키는 건 논문 표기 그대로라 헷갈려도 정상입니다.

이 이름이 **음의 로그 가능도 (NLL, negative log-likelihood)** 이고, PyTorch의 `CrossEntropyLoss`가 정확히 이것을 계산합니다.

## 2. 예제 따라하기 (6분)

어휘 [mat, floor, dog], 정답 "mat" → p = [1, 0, 0]

| 모델 | q | 크로스엔트로피 = −ln q(mat) |
|---|---|---|
| 좋은 모델 | [0.7, 0.2, 0.1] | −ln 0.7 ≈ **0.357** |
| 애매한 모델 | [0.34, 0.33, 0.33] | −ln 0.34 ≈ **1.079** |
| 틀린 확신 | [0.05, 0.05, 0.9] | −ln 0.05 ≈ **2.996** |

"틀린 확신"이 가장 크게 벌받습니다. 어제의 질문 "낮은 엔트로피가 좋은가?"에 대한 답: **확신 자체가 아니라, 정답에 확신해야 좋다.**

## 3. 능동 연습 (10분)

### ✏️ 손계산 (ln 0.5 ≈ −0.693, ln 0.9 ≈ −0.105, ln 0.1 ≈ −2.303, ln 0.25 ≈ −1.386)
1. 정답 원-핫 [0, 1], 예측 q = [0.5, 0.5]일 때 크로스엔트로피는?
2. 같은 정답, 예측 q = [0.1, 0.9]일 때는? q = [0.9, 0.1]일 때는?
3. 번역 "Je t'aime <EOS>"(3토큰)의 각 정답 확률이 0.5, 0.9, 0.25였다면 문장의 −log p(T|S)는?
4. p = [0.5, 0.5], q = [0.9, 0.1]일 때 H(p, q)와 D_KL(p‖q)를 구하세요. (H(p) = ln 2 ≈ 0.693)

### 💻 코드
```python
import numpy as np

def cross_entropy(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    return -(p * np.log(q)).sum()

def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -(p * np.log(p)).sum()

def kl(p, q):
    return cross_entropy(p, q) - entropy(p)

target = [1, 0, 0]
for q in [[0.7, 0.2, 0.1], [0.34, 0.33, 0.33], [0.05, 0.05, 0.9]]:
    print(q, "CE =", round(cross_entropy(target, q), 3))

# H(p,q) >= H(p) 확인: q를 무작위로 많이 뽑아 보기
rng = np.random.default_rng(0)
p = np.array([0.6, 0.3, 0.1])
qs = rng.dirichlet([1, 1, 1], size=10000)      # 무작위 확률분포 1만 개
ces = np.array([cross_entropy(p, q) for q in qs])
print("H(p) =", round(entropy(p), 4), "  최소 CE =", round(ces.min(), 4),
      "  그때의 q =", qs[ces.argmin()].round(2))
```

**도전 과제 (선택: 시간이 남을 때만)**
- (a) `kl(p, q)`와 `kl(q, p)`를 몇 쌍 계산해서 대칭이 아님을 확인하세요.
- (b) 문장 손실 함수 만들기: 각 위치의 예측분포 리스트 `Q`와 정답 인덱스 리스트 `y`를 받아 $-\sum_t \log Q[t][y_t]$를 돌려주는 `sentence_nll(Q, y)`를 작성하세요. 3번 문제로 검증!
- (c) q(정답)을 0.001 ~ 1로 바꾸며 −ln q를 출력해 보고, 손실 곡선을 노트에 그리세요.
