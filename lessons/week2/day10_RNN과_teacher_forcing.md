## 1. 개념 A: RNN 한 스텝 (4분)

문장은 길이가 제각각이라, **같은 계산을 단어마다 반복**하면서 "기억(은닉 상태) h"를 갱신합니다.
$$h_t = \tanh(W_h\,h_{t-1} + W_x\,x_t + b)$$
- $x_t$: t번째 단어 벡터 (Day 01)
- $h_{t-1}$: 지금까지 읽은 내용의 요약 (기억)
- $W_h, W_x, b$: **모든 스텝이 공유**하는 파라미터 (Day 02의 `Wx+b`가 두 개 더해진 것)
- tanh: 값을 −1 ~ 1로 눌러 주는 비선형 함수

인코더는 이걸 입력 문장 끝까지 반복하고, 마지막 h가 **v**가 됩니다. 디코더는 v에서 시작해 같은 방식으로 h를 갱신하며, 각 h에서 소프트맥스로 다음 단어를 예측합니다.

> 논문은 단순 RNN 대신 **LSTM**을 씁니다. 긴 문장에서 기억이 사라지는 문제를 막기 위해 "게이트"를 더한 RNN이에요 (Day 12). 오늘의 손계산 원리는 똑같습니다.

## 2. 개념 B: Teacher Forcing (5분)

디코더는 "앞 단어를 보고 다음 단어"를 예측합니다. 그럼 **학습할 때 앞 단어로 무엇을 넣을까요?**

| 방식 | 디코더 입력으로 넣는 앞 단어 | 언제 |
|---|---|---|
| **Teacher forcing** | **정답** 문장의 앞 단어 $y_{t-1}$ | 학습 |
| Free running (자기회귀) | **모델이 방금 만든** 단어 $\hat y_{t-1}$ | 추론(실제 번역) |

비유: 받아쓰기 연습에서 학생이 한 글자 틀려도 **선생님이 정답 글자를 알려주고** 다음 글자를 쓰게 하는 것. 그래서 "teacher forcing".

**장점**
1. 앞에서 틀린 게 뒤로 번지지 않아 학습이 안정적이고 빠르다.
2. 모든 위치의 입력을 미리 알기 때문에 위치별 손실을 한 번에 계산할 수 있다.
3. 수학적으로 정확하다: 식 (1)의 $p(y_t\mid v, y_{<t})$는 *정답* 앞 단어를 조건으로 하므로, $\log p(T\mid S)$를 계산하는 것 자체가 teacher forcing이다.

> 📌 논문 본문에 "teacher forcing"이라는 단어가 직접 나오지는 않습니다. 하지만 3.2절의 학습 목표(정답 번역 T의 로그 확률 최대화)를 계산하는 표준 방법이 바로 teacher forcing입니다. (용어는 Williams & Zipser, 1989에서 유래)

> 📌 `<BOS>`(문장 시작 표시)에 대해: 논문은 `<BOS>`를 따로 두지 않고 `<EOS>` 하나를 문장의 끝이자 디코더의 시작 신호로 씁니다. 이 교재는 읽기 쉽도록 시작 표시 `<BOS>`를 따로 둡니다.

**약점: Exposure bias (노출 편향)**
학습 때는 항상 정답 앞 단어만 봤는데, 실제 번역할 때는 자기가 만든 (틀릴 수도 있는) 단어를 봅니다. 한 번 틀리면 **처음 보는 상황**에 빠져 오류가 연쇄적으로 번질 수 있어요. 이 문제를 학습 방식에서 직접 줄이려는 시도가 scheduled sampling(Bengio 외, 2015)입니다. 논문이 추론 때 쓰는 **빔 서치**(3.2절, Day 15)는 노출 편향을 고치는 방법은 아니고, 후보를 여러 개 들고 가서 한 번의 나쁜 선택에 덜 휘둘리게 하는 탐색 방법입니다.

## 3. 예제 따라하기 (6분): RNN 두 스텝

은닉 2차원, 입력은 숫자 하나(1차원). b = 0.
```
W_x = [[ 1],      W_h = [[0.5, 0  ],      h_0 = [0, 0]
       [-1]]             [0,   0.5]]
```
입력 x₁ = 1, x₂ = 2

**스텝 1:** W_h h₀ = [0, 0], W_x x₁ = [1, −1]
h₁ = tanh([1, −1]) ≈ **[0.762, −0.762]** (tanh 값표: tanh(0.5) ≈ 0.462, tanh(1) ≈ 0.762, tanh(2) ≈ 0.964, 음수는 부호만 반대. [준비 6](#prep06))

**스텝 2:** W_h h₁ = [0.381, −0.381], W_x x₂ = [2, −2]
합 = [2.381, −2.381] → h₂ = tanh(...) ≈ **[0.983, −0.983]**

h₂에는 x₁과 x₂의 정보가 함께 섞여 있습니다. 이게 "기억"입니다.

## 4. 능동 연습 (10분)

### ✏️ 손계산
1. 위 예제에서 x₃ = −1일 때 h₃를 구하세요. (tanh(−0.508) ≈ −0.469)
2. 정답 번역이 "나는 밥을 먹었다 <EOS>"입니다. Teacher forcing으로 학습할 때 디코더의 각 스텝 **입력**과 **예측 목표**를 표로 쓰세요. (첫 입력은 시작 기호 `<BOS>`)
3. 위 2번에서 모델이 첫 스텝에 "나는" 대신 "너는"을 예측했다고 합시다. Teacher forcing이면 두 번째 스텝 입력은? Free running이면?

### 💻 코드 ① RNN 스텝
```python
import numpy as np

W_x = np.array([[1.0], [-1.0]])
W_h = np.array([[0.5, 0.0], [0.0, 0.5]])
h = np.zeros(2)
for t, x in enumerate([1.0, 2.0, -1.0], start=1):
    h = np.tanh(W_h @ h + W_x @ np.array([x]))
    print(f"h_{t} =", h.round(3))
```

### 💻 코드 ② Teacher forcing vs Free running
간단한 "디코더"를 표 하나로 흉내 냅니다: 앞 단어 → 다음 단어 확률. 이 모델은 **"나는" 다음을 살짝 틀리게** 배웠습니다.
```python
import numpy as np

V = ["<BOS>", "나는", "밥을", "빵을", "먹었다", "<EOS>"]
#        <BOS>  나는  밥을  빵을  먹었다 <EOS>
P = {"<BOS>":  [0.00, 0.90, 0.04, 0.03, 0.02, 0.01],
     "나는":   [0.00, 0.00, 0.45, 0.50, 0.04, 0.01],   # 실수: 빵을 > 밥을
     "밥을":   [0.00, 0.02, 0.03, 0.03, 0.90, 0.02],
     "빵을":   [0.00, 0.02, 0.03, 0.55, 0.38, 0.02],   # 빵을 다음에 또 빵을...
     "먹었다": [0.00, 0.03, 0.02, 0.02, 0.03, 0.90]}

target = ["나는", "밥을", "먹었다", "<EOS>"]

# (1) Teacher forcing: 입력은 항상 정답 앞 단어
prev, loss = "<BOS>", 0.0
for y in target:
    q = P[prev][V.index(y)]
    loss += -np.log(q)
    print(f"입력 {prev:6s} → 정답 {y:6s}  q={q:.2f}  -log q={-np.log(q):.3f}")
    prev = y                                   # ← 정답을 다음 입력으로!
print("teacher forcing 문장 손실:", round(loss, 3))

# (2) Free running: 입력은 모델이 직접 고른 단어 (greedy = 매번 argmax)
prev, out = "<BOS>", []
for _ in range(8):
    nxt = V[int(np.argmax(P[prev]))]
    out.append(nxt)
    if nxt == "<EOS>":
        break
    prev = nxt                                 # ← 내 예측을 다음 입력으로!
print("free running 결과:", " ".join(out))
```

**관찰 질문**
- Teacher forcing 손실 계산에서는 "나는" 다음 실수가 손실을 조금 키울 뿐, 뒤 단어들은 정상적으로 평가됩니다. 
- Free running에서는 무슨 일이 생겼나요? 한 번의 실수가 어떻게 번졌는지 설명해 보세요. 이것이 **exposure bias**입니다.

**도전 과제 (선택: 시간이 남을 때만)**
- (a) `P["나는"]`의 0.45와 0.50을 바꿔(밥을 0.50, 빵을 0.45) 다시 실행하세요. free running 결과는?
- (b) 학습이 teacher forcing 손실을 줄인다면 `P["나는"]`의 "밥을" 확률은 올라갈까요 내려갈까요? Day 08의 기울기 q − y로 설명해 보세요.
- (c) **Greedy 대신 상위 2개 후보를 계속 들고 가면** 어떨까요? 노트에 "나는 밥을…"과 "나는 빵을…" 두 갈래를 그리고 각 경로의 확률 곱을 비교해 보세요. (→ Day 15 빔 서치 예습)
