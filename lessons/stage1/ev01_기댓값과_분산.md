## 1. 개념 (8분)

### 1-1. 기댓값 = 오래 반복하면 평균적으로 나오는 값
동전을 던져 앞면이면 1000원, 뒷면이면 0원을 받는 게임. 한 번 할 때 평균 얼마를 받을까요?

| 결과 | 받는 돈 x | 확률 p | x × p |
|---|---|---|---|
| 앞면 | 1000 | 0.5 | 500 |
| 뒷면 | 0 | 0.5 | 0 |
| | | **합** | **500** |

기댓값은 **500원**. 한 번에 500원을 받는 일은 없지만, 100번 하면 대략 5만 원을 받습니다. 그래서 이 게임의 **공정한 참가비는 500원**입니다. 카지노는 이 값보다 비싸게 받아 돈을 법니다. "1000원 내고 주사위 6이 나오면 5000원" 게임의 기댓값은 5000 × 1/6 ≈ 833원이라, 한 판마다 손님이 평균 167원을 잃어요.

$$E[X] = \sum_x x \cdot p(x)$$

읽는 법: "가능한 값마다 (값 × 그 확률)을 모두 더하라". 준비편에서 배운 Σ 그대로입니다. 대문자 **X**는 "아직 정해지지 않은 결과"(확률변수, 예: 던지기 전의 동전), 소문자 **x**는 그 결과가 가질 수 있는 구체적인 값(1000, 0)입니다.

### 1-2. 왜 "가중" 평균인가
확률이 다르면 자주 나오는 값에 더 큰 무게를 줍니다. 앞면 확률이 0.9인 동전이면 1000 × 0.9 + 0 × 0.1 = 900원. 모든 확률이 같으면 보통 평균과 같아집니다.

### 1-3. 분산 = 평균에서 얼마나 멀리 퍼지나
두 반의 시험 점수 평균이 둘 다 70점이어도
- A반: 69, 70, 71 (모여 있음)
- B반: 40, 70, 100 (퍼져 있음)

퍼진 정도를 재는 방법:
1. 각 값이 평균에서 얼마나 떨어졌는지 구한다 (편차)
2. 편차를 **제곱**한다 (음수와 양수가 서로 지워지지 않게)
3. 그 제곱들의 **기댓값**을 구한다 → **분산** $\text{Var}(X)$

**표준편차** σ = 분산의 제곱근. 단위를 원래 값과 같게 되돌린 것입니다.

## 2. 예제 따라하기 (6분): 주사위 하나

눈 1~6이 각각 확률 1/6입니다.

**기댓값**
$$E[X] = (1 + 2 + 3 + 4 + 5 + 6) \times \frac{1}{6} = \frac{21}{6} = 3.5$$

**분산** (평균 3.5에서 떨어진 정도를 제곱)

| 눈 x | x − 3.5 | (x − 3.5)² |
|---|---|---|
| 1 | −2.5 | 6.25 |
| 2 | −1.5 | 2.25 |
| 3 | −0.5 | 0.25 |
| 4 | 0.5 | 0.25 |
| 5 | 1.5 | 2.25 |
| 6 | 2.5 | 6.25 |
| | **합** | **17.5** |

각 눈의 확률이 1/6이니 17.5 × 1/6 = **2.917** (= 35/12). 표준편차는 √2.917 ≈ **1.71**.

주사위 눈은 평균 3.5에서 대략 ±1.7 정도 퍼져 있다는 뜻입니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. 이길 확률 0.2로 5000원, 질 확률 0.8로 0원인 게임의 기댓값은?
2. 값 [2, 4, 6]이 각각 확률 1/3일 때 기댓값은?
3. 2번의 분산을 표로 구하세요.
4. A반 69, 70, 71과 B반 40, 70, 100 (각 학생 확률 1/3) 중 분산이 큰 반은? 직접 계산해 보세요.
5. 분산이 9이면 표준편차는?
6. 날씨 앱: 내일 비 올 확률 0.3, 비가 오면 우산 판매 100개, 안 오면 20개. 판매량의 기댓값은?

> **(선택) 평균을 내면 퍼짐이 줄어든다.** 주사위 하나의 표준편차는 약 1.71이지만, 주사위 100개를 던져 평균을 내면 표준편차가 $1.71 / \sqrt{100} = 0.171$로 10분의 1이 됩니다. 일반적으로 n개 평균의 표준편차는 $\sigma / \sqrt{n}$. 2단계 중심극한정리에서 이 식을 다시 만납니다.

### 🔗 앞으로 이렇게 씁니다
- **엔트로피 (2단계)**: "놀람"의 기댓값. 놀람 값 × 그 확률을 모두 더한 것
- **초기화 (2단계)**: 신경망의 시작 숫자를 "평균 0, 분산이 아주 작은" 무작위 수로 뽑습니다. 분산이 크면 계산이 폭발합니다

### 💻 코드 (선택)
```python
xs = [1, 2, 3, 4, 5, 6]
p = 1 / 6
E = sum(x * p for x in xs)
Var = sum((x - E) ** 2 * p for x in xs)
print(E, Var, Var ** 0.5)     # 3.5 2.916... 1.707...
```
