## 1. 개념 (8분)

### 1-1. 직교: 내적이 0
두 벡터가 수직일 때 **직교**한다고 합니다. 판별법은 하나입니다.

$$a \cdot b = 0 \iff a \perp b$$

읽는 법: ⊥는 "수직이다"라는 뜻이고, 가운데 화살표는 "왼쪽이 참이면 오른쪽도 참, 거꾸로도 참"이라는 뜻입니다. 즉 내적이 0이면 수직이고, 수직이면 내적이 0입니다.

[1, 2] · [2, −1] = 2 − 2 = 0 → 직교. 직교하는 두 방향은 **서로 전혀 관계가 없는** 방향입니다. 동쪽으로 아무리 가도 북쪽으로는 한 발짝도 안 간 것과 같습니다.

### 1-2. 사영: 그림자 내리기
정오의 햇빛이 바닥에 수직으로 내리쬘 때, 비스듬한 막대의 **그림자**를 떠올리세요. 벡터 b를 벡터 a의 방향으로 내린 그림자가 **사영**입니다.

$$p = \frac{a \cdot b}{a \cdot a}\, a$$

읽는 법
1. $a \cdot b$: b가 a 방향으로 얼마나 가는지
2. $a \cdot a$로 나눔: a를 길게 잡으면 $a \cdot b$도 덩달아 커집니다. 그림자는 a의 길이와 상관없어야 하니, a의 길이 제곱($a \cdot a$)으로 나눠 그 영향을 지웁니다
3. 그 숫자를 a에 곱함: a 방향의 벡터로 만듦

### 1-3. 남은 부분은 직교한다
b에서 그림자 p를 뺀 **나머지** $e = b - p$는 a와 직교합니다. 그래서 b는 두 조각으로 깔끔하게 쪼개집니다.

$$b = \underbrace{p}_{\text{a 방향}} + \underbrace{e}_{\text{a와 직교}}$$

### 1-4. 사영 = 가장 가까운 점
a 방향의 직선 위에 있는 점들 중 **b에 가장 가까운 점**이 p입니다. 길에서 벗어난 집까지 가장 짧은 길은 길에 수직으로 내린 선인 것과 같습니다.

이것이 **최소제곱법**의 원리입니다. 데이터에 딱 맞는 직선이 없을 때, "오차(나머지 e)가 가장 짧아지는" 답을 고릅니다.

### 1-5. 직교하는 기저는 편하다
[기저](#vs01)가 서로 직교하고 길이가 1이면(**정규직교 기저**), 좌표 구하기가 내적 한 번으로 끝납니다. 연립방정식을 풀 필요가 없습니다.

[1, 0]과 [0, 1]이 바로 그런 기저입니다. [3, 5]의 첫 좌표 = [3, 5] · [1, 0] = 3.

> (선택) 직교하지 않는 기저를 직교하게 고치는 방법이 **그람-슈미트**입니다. 둘째 벡터에서 "첫째 벡터 방향의 그림자"를 빼면 됩니다. 1-3의 나머지 e가 바로 그것입니다.

## 2. 예제 따라하기 (6분)

**문제.** b = [2, 3]을 a = [1, 1] 방향으로 사영하세요.

1. a · b = 1 × 2 + 1 × 3 = **5**
2. a · a = 1 + 1 = **2**
3. p = (5 ÷ 2) × [1, 1] = **[2.5, 2.5]**

**나머지:** e = [2, 3] − [2.5, 2.5] = **[−0.5, 0.5]**

**직교 확인:** e · a = −0.5 + 0.5 = **0** ✓

[2, 3] = [2.5, 2.5] + [−0.5, 0.5]. 대각선 방향 조각과 그에 수직인 조각으로 나뉘었습니다.

**쉬운 경우.** b = [3, 4]를 a = [1, 0]에 사영하면 a · b = 3, a · a = 1 → p = [3, 0]. 세로 성분을 지운 것, 말 그대로 바닥에 내린 그림자입니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. [1, 2]와 [2, −1]은 직교하나요?
2. [1, 1]과 [1, 2]는 직교하나요?
3. b = [4, 2]를 a = [1, 0] 방향으로 사영하면?
4. b = [3, 1]을 a = [1, 1] 방향으로 사영하면?
5. 4번의 나머지 e = b − p는? e · a가 0인지 확인하세요.
6. b = [2, 2]를 a = [1, −1] 방향으로 사영하면? 결과가 뜻하는 바는?

### 🧩 미니 챌린지
점 세 개 (1, 1), (2, 2), (3, 2)를 지나는 직선 y = k × x는 없습니다. x = [1, 2, 3], y = [1, 2, 2]로 놓고 y를 x 방향으로 사영하면 가장 잘 맞는 k가 나옵니다. k = (x · y) ÷ (x · x)를 계산해 보세요.

### 💻 코드 (선택)
```python
import numpy as np
a, b = np.array([1, 1]), np.array([2, 3])
p = (a @ b) / (a @ a) * a
e = b - p
print(p, e, e @ a)                     # [2.5 2.5] [-0.5  0.5] 0.0

x, y = np.array([1, 2, 3]), np.array([1, 2, 2])
print((x @ y) / (x @ x))               # 0.7857...  가장 잘 맞는 기울기
```
