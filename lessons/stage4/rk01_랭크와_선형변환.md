## 1. 개념 (8분)

### 1-1. 행렬은 변환 기계
[Day 02](#day02)에서 행렬 × 벡터를 계산으로 배웠습니다. 오늘은 그림으로 봅니다. 행렬 A는 평면의 모든 점을 **다른 자리로 옮기는 기계**입니다.

| 행렬 | 하는 일 |
|---|---|
| [[2, 0], [0, 3]] | 가로로 2배, 세로로 3배 늘이기 |
| [[0, −1], [1, 0]] | 반시계 방향으로 90도 돌리기 |
| [[1, 0], [0, 0]] | 바닥(가로축)으로 납작하게 누르기 |

### 1-2. 열을 읽으면 변환이 보인다
비밀 하나: **행렬의 첫째 열은 [1, 0]이 가는 곳, 둘째 열은 [0, 1]이 가는 곳**입니다.

A = [[0, −1], [1, 0]]이면
- [1, 0] → 첫째 열 [0, 1] (오른쪽을 보던 화살표가 위로)
- [0, 1] → 둘째 열 [−1, 0] (위를 보던 화살표가 왼쪽으로)

그래서 90도 회전입니다. 나머지 벡터는 이 둘의 선형결합이니 따라서 정해집니다.

### 1-3. 랭크: 출력이 차지하는 차원
A = [[1, 2], [2, 4]]를 봅시다. 열이 [1, 2]와 [2, 4]. 둘째 열이 첫째의 2배라서 [종속](#vs01)입니다.

이 기계는 평면의 어떤 점을 넣어도 **[1, 2] 방향의 직선 위**로만 보냅니다. 2차원을 넣었는데 1차원만 나옵니다.

**랭크** = 독립인 열의 개수 = 출력이 실제로 차지하는 차원 수.

| 행렬 | 랭크 | 출력 |
|---|---|---|
| [[2, 0], [0, 3]] | 2 | 평면 전체 |
| [[1, 2], [2, 4]] | 1 | 직선 |
| [[0, 0], [0, 0]] | 0 | 점 하나 |

### 1-4. 납작해지면 잃는 것: 영공간
랭크가 모자라면 서로 다른 입력이 같은 출력으로 겹칩니다. 특히 **0으로 가 버리는 입력**이 생깁니다.

[[1, 2], [2, 4]] × [2, −1] = [2 − 2, 4 − 4] = [0, 0] (첫째 열 2개에서 둘째 열 1개를 빼면 0이 되기 때문입니다)

0으로 가는 입력들의 모임을 **영공간**이라고 합니다. 입력 차원 = 랭크 + 영공간의 차원. 여기서는 2 = 1 + 1. 사진을 찍으면 3차원이 2차원으로 눌리며 깊이 정보가 사라지는 것과 같습니다.

### 1-5. 행렬식: 넓이가 몇 배가 되나 (2×2)
$$\det \begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc$$

변환 뒤에 넓이가 몇 배가 되는지입니다.
- [[2, 0], [0, 3]]: 2 × 3 − 0 = 6배
- [[1, 2], [2, 4]]: 4 − 4 = **0**. 직선으로 눌려 넓이가 사라짐

**행렬식이 0이면 랭크가 모자라고, 랭크가 모자라면 행렬식이 0입니다.** 둘은 같은 말입니다. 이때는 변환을 되돌릴 수 없습니다. 찌그러뜨린 캔을 다시 펴도 원래 모양을 알 수 없는 것과 같아요. (되돌리는 행렬을 역행렬이라고 부르는데, 이름만 알아 두세요.)

## 2. 예제 따라하기 (6분)

**문제.** A = [[3, 1], [2, 4]]

1. [1, 0]은 어디로 가나요? → 첫째 열 **[3, 2]**
2. [0, 1]은? → 둘째 열 **[1, 4]**
3. 행렬식은? → 3 × 4 − 1 × 2 = **10**. 넓이가 10배
4. 랭크는? → 행렬식이 0이 아니니 열이 독립 → **2**

**문제.** B = [[1, 2, 3], [2, 4, 6]] (2행 3열)의 랭크는?

둘째 행이 첫째 행의 2배입니다. 열로 봐도 [1, 2], [2, 4], [3, 6]이 모두 [1, 2]의 배수. 독립인 것은 하나 → **랭크 1**. 3차원 입력을 받아 직선 하나로 보냅니다.

> 랭크는 열로 세든 행으로 세든 같습니다. 그리고 행 수와 열 수 중 작은 쪽을 넘을 수 없습니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
1. [[2, 0], [0, 3]] × [1, 1]은?
2. [[1, 0], [0, 0]] × [3, 5]는? 어떤 변환인가요?
3. [[0, −1], [1, 0]] × [2, 0]은?
4. [[2, 1], [4, 2]]의 행렬식과 랭크는?
5. [[1, 3], [2, 5]]의 행렬식과 랭크는?
6. 1000차원 벡터를 받아 1000차원을 내는 행렬의 랭크가 8이라면, 출력은 실제로 몇 차원 안에 있나요?

### 🧩 미니 챌린지
[1, 0]에 90도 회전 행렬 [[0, −1], [1, 0]]을 곱하고, 나온 결과에 한 번 더 곱해 보세요. 화살표는 어디를 보나요? 계산하기 전에 그림으로 먼저 맞혀 보세요.

### 💻 코드 (선택)
```python
import numpy as np
A = np.array([[1, 2], [2, 4]])
print(np.linalg.matrix_rank(A))        # 1
print(np.linalg.det(A))                # 0.0
print(A @ np.array([2, -1]))           # [0 0]

R = np.array([[0, -1], [1, 0]])
print(R @ R)                           # [[-1  0] [ 0 -1]]  180도 회전
```

## 📝 한 줄 정리
행렬은 공간을 옮기는 기계이고, 랭크는 그 출력이 실제로 차지하는 차원 수다. 랭크가 모자라면 공간이 납작해지고 정보가 사라진다.
