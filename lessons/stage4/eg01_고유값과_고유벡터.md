# 5단계. 고유값과 고유벡터

**복습 (1분):** [[2, 0], [0, 3]] × [1, 0]은? (답: [2, 0]. [랭크와 선형변환](#rk01))

## 1. 개념 (8분)

### 1-1. 대부분의 벡터는 방향이 틀어진다
행렬 A = [[2, 1], [1, 2]]에 [1, 0]을 넣으면 [2, 1]이 나옵니다. 오른쪽을 보던 화살표가 비스듬히 위로 틀어졌습니다. 보통은 이렇게 **방향이 바뀝니다.**

### 1-2. 그런데 방향이 그대로인 벡터가 있다
같은 A에 [1, 1]을 넣어 봅시다.

[[2, 1], [1, 2]] × [1, 1] = [3, 3] = **3 × [1, 1]**

방향은 그대로, 길이만 3배가 됐습니다. 이런 벡터가 **고유벡터**, 그 배수가 **고유값**입니다.

$$A v = \lambda v$$

- v: 고유벡터 (방향이 안 바뀌는 특별한 벡터)
- λ (람다): 고유값 (늘어나는 배수)

지구본을 돌릴 때 다른 점은 모두 움직여도 **자전축 위의 점은 제자리**인 것처럼, 많은 변환에는 이런 "흔들리지 않는 축"이 있습니다. (평면을 90도 돌리는 회전처럼 없는 변환도 있습니다.)

### 1-3. 고유값이 말해 주는 것
| 고유값 λ | 그 방향에서 일어나는 일 |
|---|---|
| 1보다 큼 | 늘어남 |
| 0과 1 사이 | 줄어듦 |
| 음수 | 뒤집힘 (크기는 부호를 뗀 값으로 봅니다) |
| 0 | 납작하게 눌려 사라짐 ([랭크](#rk01)가 모자람) |

### 1-4. 같은 행렬을 여러 번 곱하면
고유벡터 방향에서는 행렬 곱셈이 **그냥 숫자 곱셈**이 됩니다.

$$A^{10} v = \lambda^{10} v$$

λ = 0.9면 $0.9^{10} \approx 0.35$로 줄고, λ = 1.1이면 $1.1^{10} \approx 2.6$으로 붑니다. [기울기 소실과 폭발](#gv01)에서 "같은 수를 계속 곱한다"고 했던 그 수의 정체가 **고유값**입니다.

### 1-5. 2×2 행렬의 고유값 구하기
A = [[a, b], [c, d]]의 두 고유값 $\lambda_1, \lambda_2$는 다음을 만족합니다.

- **합** = 대각합(왼쪽 위에서 오른쪽 아래로 내려가는 대각선 숫자의 합) = a + d
- **곱** = 행렬식 = ad − bc

"더해서 a + d, 곱해서 ad − bc인 두 수"를 찾으면 됩니다.

> (선택) 이 규칙이 왜 성립하는지는 이차방정식이 필요해서 여기서는 건너뜁니다. 지금은 "더해서 대각합, 곱해서 행렬식"만 쓰면 충분합니다.

## 2. 예제 따라하기 (6분)

**문제.** A = [[2, 1], [1, 2]]의 고유값과 고유벡터.

**고유값**
- 합 = 2 + 2 = 4
- 곱 = 2 × 2 − 1 × 1 = 3
- 더해서 4, 곱해서 3인 두 수 → **3과 1**

**고유벡터 확인**
- v = [1, 1]: A v = [2 + 1, 1 + 2] = [3, 3] = 3 × [1, 1] → λ = **3** ✓
- v = [1, −1]: A v = [2 − 1, 1 − 2] = [1, −1] = 1 × [1, −1] → λ = **1** ✓

이 행렬은 [1, 1] 대각선 방향으로 3배 늘이고, [1, −1] 방향은 그대로 두는 변환입니다. 복잡해 보이던 행렬이 **기저를 고유벡터로 바꾸니** "한쪽은 3배, 한쪽은 1배"로 단순해졌습니다.

두 고유벡터의 내적: 1 − 1 = 0. [직교](#or01)합니다. 대칭 행렬(왼쪽 위에서 오른쪽 아래로 가는 대각선을 따라 접으면 마주 보는 숫자가 같은 행렬. 여기서는 오른쪽 위 1과 왼쪽 아래 1)에서는 늘 이렇습니다.

## 3. 능동 연습 (10분)

### ✏️ 손계산
A = [[4, 1], [2, 3]]

1. A × [1, 1]은? [1, 1]은 고유벡터인가요? 고유값은?
2. A × [1, −2]는? 고유벡터인가요? 고유값은?
3. A × [1, 0]은? 고유벡터인가요?
4. A의 대각합과 행렬식으로 고유값 두 개를 검산하세요.
5. [[2, 0], [0, 3]]의 고유값과 고유벡터는? (계산 없이 보이나요?)
6. 고유값이 0.5인 방향으로 같은 행렬을 4번 곱하면 길이는 몇 배가 되나요?

### 🧩 미니 챌린지
RNN이 스텝마다 곱하는 행렬의 고유값이 0.9와 0.5라고 합시다. 50스텝 뒤 두 방향의 신호는 각각 얼마나 남을까요? 어느 쪽 정보가 먼저 사라지나요?

### 💻 코드 (선택)
```python
import numpy as np
A = np.array([[2, 1], [1, 2]])
vals, vecs = np.linalg.eigh(A)   # eigh: 대칭 행렬용. 고유값을 작은 것부터 줍니다
print(vals)                       # [1. 3.]
print(vecs)                       # 열마다 고유벡터 (길이 1로 맞춰져 있음)

v = np.array([1, 1])
print(A @ v)                      # [3 3]
print(np.linalg.matrix_power(A, 10) @ v, 3 ** 10)   # [59049 59049] 59049
```

## 📝 한 줄 정리
고유벡터는 변환해도 방향이 그대로인 벡터, 고유값은 그 방향으로 늘어나는 배수다. 같은 행렬을 거듭 곱하면 고유값의 거듭제곱이 결과를 좌우한다.

**미니 챌린지**
0.9⁵⁰ ≈ 0.005, 0.5⁵⁰ ≈ 0.000000000000001. 고유값이 작은 방향의 정보가 훨씬 먼저 사라집니다. 가장 큰 고유값이 "기억이 얼마나 오래 가는지"를 정합니다.

1. 행렬을 곱해도 방향이 바뀌지 않고 길이만 바뀌는 벡터입니다.

4. 합은 대각합(a + d), 곱은 행렬식(ad − bc)
